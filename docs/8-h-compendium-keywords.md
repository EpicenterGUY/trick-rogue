# 8-H 도감 / 키워드 도움말

## 완료 범위

- 기존 맵의 임시 `카드풀` 진입을 통합 `도감`으로 교체한다.
- 시작 화면, 맵, 전투 화면에서 도감을 열 수 있다.
- 도감은 별도 복제 데이터가 아니라 현재 실제 시스템 레지스트리를 직접 읽는다.

## 도감 탭

- 카드
  - 전체
  - 순수
  - 일반 효과
  - pack01
  - pack02
- 유물
- 계약·금기
- 특성
- 필드
- 상태
- 빌드 시너지

카드 탭은 표준 52슬롯과 현재 활성 네임드 카드군을 모두 표시한다. 각 카드는 현재 8-C 보상 후보 카탈로그에 실제 포함되는지도 함께 표시한다.

상태 탭은 구현된 상태뿐 아니라 아직 규칙이 확정되지 않은 등록 상태도 숨기지 않고 `규칙 미확정`으로 표시한다.

## 키워드 도움말

한 개의 `KEYWORD_DEFINITIONS` 사전을 공유한다. 카드 상세, 카드 보상, 상점, 도감처럼 기존 `showModal`을 쓰는 UI와 전투 카드 상세에서 같은 정의를 재사용한다.

핵심 용어는 굵게 표시하고 클릭/탭하면 기존 모달을 닫지 않는 작은 설명창을 띄운다. 마우스 환경에서는 `title` 설명도 제공한다.

초기 등록 용어에는 다음이 포함된다.

- 트럼프
- 적용 숫자 / 트릭값 / 인쇄값
- 쇼다운 / 쇼다운 위력 / 족보
- 우세
- 리버 / 리버 적중
- 칩
- 순수 카드
- 예약 / 기억
- 표식 / 흉터 / 보호막 / 출혈 / 재생 / 취약
- 계약 / 금기
- 필드
- 손패 / 드로우
- 골드
- 폴드

## 최신 규칙 보호

- 트럼프는 기본 `적용 숫자 +3`이며 자동 승리/우선권이 아니다.
- 우세는 명시적으로 부여되는 조건부 쇼다운 상태이며 무늬 수 비교로 자동 발생하지 않는다.
- 리버 적중은 4번째 트릭 뒤 고정한 후보와 실제 5번째 인쇄 카드가 정확히 일치해야 한다.
- 폐기된 별도 전술 덱은 도감이나 키워드 시스템으로 복원하지 않는다.
