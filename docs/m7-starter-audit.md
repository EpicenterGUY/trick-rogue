# M7 스타터 12장 구조 / 공통지역 자동 감사

기준: 2026-08-27
버전: `M7-1`

## 목적

스타터를 클래스처럼 강화하지 않고 **첫 지역 선택 전에 빌드의 씨앗을 제공하는 12장 시작점**으로 유지한다.

M7의 실제 체감 판정 전에 코드로 확인 가능한 구조적 조건을 먼저 고정한다.

## 스타터 구조

노출 스타터는 4종을 유지한다.

- 정석 (`common`)
- 승부사 (`gambler`)
- 변칙 (`trickster`)
- 생존자 (`survivor`)

각 스타터는 정확히 다음 구조를 사용한다.

- 순수 카드 8장
- 공용 `general/common` 효과 카드 4장
- 총 12장
- 스타터 전용 카드 획득 제한 없음
- 스타터 전용 지역 없음

구버전 무소속/저격수/사진가 스타터는 저장 호환용 보관 상태를 유지하며 새 런 노출 대상으로 되돌리지 않는다.

## 효과 카드 4장의 역할 감사

각 스타터의 4장은 M6 `systemTags`를 기준으로 아래 세 역할에 최소 하나씩 연결되어야 한다.

### 트릭 조작

- 적용값 증가
- 적용값 감소
- 우세 개입

### 손패·정보

- 손패
- 예측

### 자원·생존

- 칩
- 회복
- 보호막
- 상태

이 검사는 “정확히 카드 한 장씩 역할을 배정한다”는 뜻이 아니다. 한 카드가 둘 이상의 시스템을 연결하는 것은 허용하며 오히려 연결 카드 역할을 인정한다.

## 스타터 개성 신호

자동 감사에서는 각 스타터의 기존 방향과 연결되는 시스템 태그가 시작 효과 4장 안에 최소 하나 존재하는지만 확인한다.

- 정석: 손패 / 예측 / 족보
- 승부사: 칩 / 적용값 감소
- 변칙: 적용값 감소 / 쇼다운 개입 / 족보
- 생존자: 보호막 / 손패 / 회복 / 상태

이 조건은 체감상 개성이 충분하다는 판정이 아니다. 단순히 스타터 설명과 카드 데이터가 완전히 분리되는 회귀를 막는 안전장치다.

## 지역 강제 방지 자동 가드

현재 3지역의 M6 보상 태그를 사용해 각 스타터 4장의 지역 연결도를 계산한다.

자동 조건:

- 유랑극장으로 이어지는 효과 카드가 최소 1장
- 안개 관측소로 이어지는 효과 카드가 최소 1장
- 황야 전선으로 이어지는 효과 카드가 최소 1장
- 어느 한 지역에도 효과 카드 4장 전부가 동시에 테마 카드가 되지 않음

따라서 스타터 단계에서 특정 지역과 데이터 연결고리가 완전히 끊기거나 4장 전부가 한 지역 성향으로 굳는 회귀를 CI에서 잡는다.

단, **실제 플레이에서 특정 지역이 무조건 정답으로 느껴지는지**는 수치·보상·적 구성까지 포함한 체감 문제이므로 자동 완료 처리하지 않는다.

## 공통지역 감사

첫 지역을 고르기 전 사용하는 공용 효과 카드 보상 풀도 같은 기준으로 확인한다.

- 트릭 조작 카드 존재
- 손패·정보 카드 존재
- 자원·생존 카드 존재
- 현재 3지역 각각으로 이어지는 M6 태그 카드 존재

이 검사는 공통지역이 첫 지역 선택 전에 덱을 바꿀 **구조적 선택지**를 갖는다는 것만 보장한다.

실제 한 런에서 공통지역 종료 시 “첫 지역 선택에 영향을 주는 덱 변화가 생겼다”는 체감 판정은 직접 플레이가 필요하다.

## 스타터 간 중복 가드

두 스타터가 시작 효과 카드 4장 중 3장 이상을 공유하면 시작 씨앗 구분이 지나치게 약해진 것으로 보고 자동 감사에서 실패한다.

현재 허용 상한은 스타터 쌍당 공통 효과 카드 2장이다.

## 자동 검증이 보장하는 것

- 노출 스타터 4종 유지
- 각 스타터 정확히 `순수 8 + 효과 4 = 12장`
- 시작 효과 카드가 모두 `general/common`
- 시작 효과 카드의 M6 시스템 태그 1~3개 유지
- 세 기본 역할의 공백 방지
- 현재 3지역으로의 최소 연결고리 유지
- 특정 한 지역에 시작 효과 4/4가 몰리는 데이터 회귀 방지
- 스타터 쌍의 효과 카드 과도한 중복 방지
- 다른 스타터 카드 획득 차단 없음
- 공통지역 보상 풀의 역할/지역 연결고리 유지

## M7 완료 경계

아래 항목은 자동 테스트만으로 닫지 않는다.

- P1-3 대표 조합 실제 플레이 체감 판정
- 네 스타터의 효과 카드 역할이 실제 플레이에서 중복되거나 비는지 최종 판정
- 공통지역 종료 시 덱 변화가 실제 첫 지역 선택에 영향을 주는지 확인
- 특정 스타터가 실제로 특정 일반지역을 강제하는지 확인
- `7순수 + 5효과` 실험 필요 여부 결정

따라서 `M7-1`은 **구조/데이터 감사 기반**이며 M7 전체의 인간 플레이 완료 판정이 아니다.
