# M10 6지역 빌드 조합 플레이테스트

기준: 2026-08-28

M10의 목적은 6개 일반지역을 두 곳 고르는 현재 런 구조에서, **지역 선택이 실제 빌드 방향을 바꾸되 특정 지역·스타터·특성·필드가 자동 정답이 되지 않는지** 확인하는 것이다.

자동 계측은 판단을 대신하지 않는다. `run.runResult.buildAudit`와 결과창의 `M10` 요약은 기록 누락을 줄이기 위한 도구이며, 최종 판정은 실제 플레이 체감으로 남긴다.

## 자동 기록되는 항목

- 스타터 ID / 이름
- 특성 ID / 이름
- 보유 필드, 현재 대기 필드, 전투에서 실제 소비한 필드 목록
- 방문한 두 지역과 지역 조합 `pairKey`
- 각 지역에서 선택한 분기와 분기 태그
- 최종 덱 크기
- 최종 덱의 순수 카드 / 효과 카드 장수
- 효과 카드의 시스템 태그별 장수
- 카드 ID별 최종 보유 장수

런 종료 시 같은 정보가 `run.runResult.buildAudit`에 남고 DEV 콘솔에도 `[M10 build audit]`로 출력된다.

## 사람이 반드시 판정할 항목

각 런에서 아래를 짧게 기록한다.

1. 첫 지역을 고른 뒤 덱 방향이 실제로 달라졌는가.
2. 두 번째 지역이 첫 지역 빌드를 확장하거나 비트는 선택을 만들었는가.
3. 제시된 보상 중 사실상 고를 것이 없는 순간이 있었는가.
4. 반대로 지역/스타터/특성/필드 때문에 생각 없이 누르는 자동 선택이 있었는가.
5. 순수 카드가 끝까지 쇼다운 재료 또는 빌드 구성 요소로 의미가 있었는가.
6. 필드가 유랑극장 전용 시스템처럼 느껴지지 않았는가.
7. 지역 보상 65% 공용 / 35% 테마 경향이 빌드를 강제하지 않으면서 차이를 만들었는가.
8. 시스템 연결 카드가 서로 다른 지역 빌드를 이어 주는 역할을 했는가.

## M10 판정 규칙

- 한 런의 강한 조합만 보고 즉시 수치를 너프하지 않는다.
- 같은 문제가 서로 다른 스타터 또는 서로 다른 지역 조합에서도 반복되는지 확인한다.
- 특정 지역의 테마 태그 비중이 높다는 사실 자체는 문제가 아니다. **다른 선택이 사라지는지**를 본다.
- 특정 스타터가 한 지역과 잘 맞는 것은 허용한다. 그 조합이 다른 선택을 압도해서 사실상 고정 루트가 되는지는 별도로 본다.
- 순수 카드 비율은 정답 수치가 없다. 최종 덱에서 순수 카드가 남아 있어도 의미가 없었다면 실패로 기록한다.
- 필드는 획득 횟수보다 실제 전투에서 사용했을 때 선택과 판단을 만들었는지 본다.

## M10 완료 조건

- [ ] 15개 지역 조합을 포함한 대표 런 기록이 쌓였다.
- [ ] 지나치게 약하거나 강한 지역 / 분기 / 보스를 조정했다.
- [ ] 스타터 / 특성 / 필드의 자동 정답 후보를 정리했다.
- [ ] 순수 카드와 시스템 연결 카드가 6지역 환경에서도 역할을 가진다고 판단했다.
- [ ] 2차 지역 확장(M12)으로 넘어가도 된다고 판단했다.
