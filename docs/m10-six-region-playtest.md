# M10 6지역 빌드 조합 플레이테스트

기준: 2026-08-29

M10의 목적은 6개 일반지역을 두 곳 고르는 현재 런 구조에서, **지역 선택이 실제 빌드 방향을 바꾸되 특정 지역·스타터·특성·필드가 자동 정답이 되지 않는지** 확인하는 것이다.

자동 계측은 판단을 대신하지 않는다. `run.runResult.buildAudit`와 결과창의 `M10` 요약은 기록 누락을 줄이기 위한 도구이며, 최종 판정은 실제 플레이 체감으로 남긴다.

## 현재 M10 지원 상태

자동/DEV 지원은 main에 구현되어 있다.

- `run.runResult.buildAudit`에 스타터·특성·필드·지역·분기·덱·시스템 태그 기록
- 실제 카드 생성기의 순수 카드 판정과 스타터 `12장 = 순수 8 + 효과 4` 회귀 검증
- DEV 대표 5런 프리셋
- 목표 지역쌍과 실제 방문 지역쌍 일치/불일치 판정
- `고를 카드 없음 / 자동 선택 / 빌드 전환 / 순수 카드 체감 / 필드 체감 / 자유 메모` 기록
- 전체 15개 지역쌍 DEV 시작 버튼
- 목표 일치 + 두 지역 모두 완료한 표본만 `0/15 → 15/15` 커버리지에 누적
- 조합별 실행 횟수, 승/패, 체감 메모 수, 최근 결과 저장

관련 PR: #166, #167, #168, #169, #170, #171

**이 도구들이 들어갔다고 M10이 완료된 것은 아니다. 실제 사람이 15개 지역쌍을 플레이하고 체감 판정을 남겨야 한다.**

## DEV 플레이테스트 시작 방법

1. 게임을 `?dev=1`로 연다.
2. `DEV` 패널의 `M10 대표 5런` 또는 `M10 전체 15조합`에서 목표 런을 시작한다.
3. 스타터와 특성은 표본 값으로 고정되지만, **지역은 직접 선택한다.**
4. 목표 지역 두 곳을 실제로 진행한다.
5. 플레이 도중 필요한 순간에 체감 기록 버튼과 자유 메모를 사용한다.
6. 두 지역을 모두 완료하고 런이 종료되면 목표 지역쌍 일치 여부와 커버리지를 확인한다.

커버리지에는 아래 조건을 모두 만족한 런만 들어간다.

- M10 표본 런일 것
- 실제 방문 지역쌍이 목표 지역쌍과 일치할 것
- 목표 두 지역을 모두 완료했을 것

따라서 목표와 다른 지역을 탔거나 두 번째 지역 도중 패배/중단된 런은 **체감 참고 자료는 될 수 있어도 15/15 완료 표본으로는 세지 않는다.**

## 자동 기록되는 항목

- 스타터 ID / 이름
- 특성 ID / 이름
- 보유 필드, 현재 대기 필드, 전투에서 실제 소비한 필드 목록
- 방문한 두 지역과 지역 조합 `pairKey`
- 각 지역에서 선택한 분기와 분기 태그
- 최종 덱 크기
- 최종 덱의 순수 카드 / 효과 카드 장수
- 효과 카드의 시스템 태그별 장수
- 카드 ID별 최종 보유 장수
- M10 목표 지역쌍 / 실제 지역쌍 / 목표 일치 여부
- 체감 메모 유형별 횟수와 기록 당시 방문 지역·덱 크기·런 단계

런 종료 시 같은 정보가 `run.runResult.buildAudit`에 남고 DEV 콘솔에도 `[M10 build audit]`로 출력된다.

## 사람이 반드시 판정할 항목

각 런에서 아래를 짧게 기록한다.

1. 첫 지역을 고른 뒤 덱 방향이 실제로 달라졌는가.
2. 두 번째 지역이 첫 지역 빌드를 확장하거나 비트는 선택을 만들었는가.
3. 제시된 보상 중 사실상 고를 것이 없는 순간이 있었는가.
4. 반대로 지역/스타터/특성/필드 때문에 생각 없이 누르는 자동 선택이 있었는가.
5. 순수 카드가 끝까지 쇼다운 재료 또는 빌드 구성 요소로 의미가 있었는가.
6. 필드가 유랑극장 전용 시스템처럼 느껴지지 않았는가.
7. 지역 보상 65% 공용 / 35% 테마 경향이 빌드를 강제하지 않으면서 차이를 만들었는가.
8. 시스템 연결 카드가 서로 다른 지역 빌드를 이어 주는 역할을 했는가.

## 1차 세션 — 대표 5런

15개를 한 번에 몰아서 하지 않고 먼저 아래 5런을 진행한다. 이 5런은 6지역 전체와 스타터 4종을 빠르게 한 번씩 훑는 **문제 탐색용 1차 표본**이다.

| 런 | DEV 프리셋 | 스타터 | 특성 | 목표 지역쌍 | 1차 관찰 포인트 |
|---:|---|---|---|---|---|
| 1 | `m10-01` | 정석 | 예측 계열 | 유랑극장 + 안개 관측소 | 필드/슬롯과 정보/손패가 자연스럽게 이어지는가 |
| 2 | `m10-02` | 승부사 | 빈손 계열 | 황야 전선 + 침몰 카지노 | 칩·낮은 숫자·위험 선택이 자동 정답 루트를 만들지 않는가 |
| 3 | `m10-03` | 생존자 | 재기 계열 | 붉은 병동 + 폐품 시장 | 생존/상태와 덱 재구성이 지나치게 안정적인 조합이 되지 않는가 |
| 4 | `m10-04` | 변칙 | 무늬 계열 | 유랑극장 + 침몰 카지노 | 변칙 요소가 선택을 늘리는지 RNG 의존만 늘리는지 |
| 5 | `m10-05` | 정석 | 순수 계열 | 안개 관측소 + 폐품 시장 | 순수 카드가 제거 재료가 아니라 실제 판단 자원으로 남는가 |

### 1차 세션 판정 후 행동

- 같은 문제가 2개 이상 런에서 반복되면 **M10 밸런스 수정 후보**로 올린다.
- 한 런에서만 강했던 조합은 즉시 너프하지 않고 나머지 10조합에서 재확인한다.
- `고를 카드 없음` 또는 `자동 선택`이 반복되면 해당 카드 한 장보다 **보상 가중치 / 스타터 / 특성 / 필드 / 지역 규칙의 조합 문제**인지 먼저 본다.
- 1차 5런에서 진행을 막는 버그가 발견되면 나머지 10런보다 먼저 수정한다.

## M10 판정 규칙

- 한 런의 강한 조합만 보고 즉시 수치를 너프하지 않는다.
- 같은 문제가 서로 다른 스타터 또는 서로 다른 지역 조합에서도 반복되는지 확인한다.
- 특정 지역의 테마 태그 비중이 높다는 사실 자체는 문제가 아니다. **다른 선택이 사라지는지**를 본다.
- 특정 스타터가 한 지역과 잘 맞는 것은 허용한다. 그 조합이 다른 선택을 압도해서 사실상 고정 루트가 되는지는 별도로 본다.
- 순수 카드 비율은 정답 수치가 없다. 최종 덱에서 순수 카드가 남아 있어도 의미가 없었다면 실패로 기록한다.
- 필드는 획득 횟수보다 실제 전투에서 사용했을 때 선택과 판단을 만들었는지 본다.
- 자동 커버리지 15/15는 **M10 완료 조건이 아니다.** 사람 판정과 필요한 수정이 끝나야 한다.

## M10 완료 조건

- [ ] 15개 지역 조합을 포함한 대표 런 기록이 쌓였다.
- [ ] 지나치게 약하거나 강한 지역 / 분기 / 보스를 조정했다.
- [ ] 스타터 / 특성 / 필드의 자동 정답 후보를 정리했다.
- [ ] 순수 카드와 시스템 연결 카드가 6지역 환경에서도 역할을 가진다고 판단했다.
- [ ] 2차 지역 확장(M12)으로 넘어가도 된다고 판단했다.
