# 트릭로그 최신 통합 규칙안 — 트럼프 개편 적용본

> 기준일: 2026-08-23  
> 이 문서를 현재 트릭로그의 최신 기준안으로 간주한다. 과거 규칙과 충돌하면 이 문서를 우선한다.

## 최우선 변경사항

- 기본 손패 3장
- 5트릭 = 1세트
- 별도 전술 카드 시스템 없음
- 모든 플레이 카드는 일반 52장 트럼프 규격
- **트럼프는 비트럼프를 무조건 이기지 않음**
- **현재 트럼프 무늬 카드의 트릭 적용 숫자 +3**
- 모든 트릭 승패는 최종 적용 숫자로 판정
- 트릭 승리 시 칩 +1
- 칩으로 손패 조절 가능
- 쇼다운은 포커 족보 중심
- 기존 상시 쇼다운 우세 시스템 삭제
- 우세는 조건부 폭딜 상태/카드 효과로 사용
- 일반전은 짧게, 엘리트/보스에서는 장기전 가능

---

## 1. 게임 핵심

트릭로그는 트럼프 카드 기반 로그라이크 카드게임이다.

매 트릭 플레이어는 손패 3장 중 1장을 선택한다.

핵심 고민은 다음 두 선택의 충돌이다.

- 지금 트릭을 이기기 좋은 카드를 낼 것인가?
- 5장 뒤 쇼다운 족보를 위해 더 좋은 카드를 낼 것인가?

핵심 축:

- 트럼프 = 현재 트릭에서의 임시 숫자 보정
- 칩 = 현재의 승리를 미래 선택권으로 바꾸는 자원
- 포커 족보 = 5트릭 동안 준비하는 쇼다운의 핵심 화력
- 네임드 효과 = 위 시스템을 비틀거나 연결하는 요소

## 2. 카드 규격

모든 플레이 카드는 일반적인 52장 트럼프 규격만 사용한다.

무늬:

- ♠ / ♥ / ♦ / ♣

랭크:

- 2~10 / J / Q / K / A

특수 숫자나 특수 무늬는 기본적으로 사용하지 않는다.

사용하지 않는 예:

- 숫자 0
- 숫자 15 이상
- 음수
- 소수점
- ? 무늬
- 무늬 없음
- 5번째 특수 수트

특수함은 카드 규격이 아니라 카드 효과로 구현한다.

예:

- 철갑탄 ♠7
- 불사조 ♥4
- 재귀 함수 ♣8

즉 `트럼프 카드는 평범하지만 효과가 특이하다`를 기본 철학으로 한다.

## 3. 순수 카드 / 네임드 카드

순수 카드:

- 효과가 없는 일반 트럼프 카드
- 족보 구성에 안정적
- 특정 순수 카드 시너지의 대상

네임드 카드:

- 일반 숫자와 무늬를 그대로 가짐
- 고유 효과가 붙음

순수 카드는 게임에서 유지한다. 네임드 카드만 많은 덱이 항상 최적이 되지 않도록 한다.

## 4. 손패

기본 최대 손패는 3장이다.

전투 시작:

- 덱 셔플
- 3장 드로우

매 트릭:

1. 손패 3장 중 1장 선택
2. 카드 사용
3. 트릭 해결
4. 사용한 카드를 쇼다운 슬롯에 둠
5. 카드 1장 드로우
6. 다시 손패 3장

3장은 `현재 트릭 / 미래 족보 / 제3의 선택` 사이의 고민을 만들기 위한 기본값이다.

일부 카드/유물/적 효과로 일시적으로 손패 2~4장은 허용 가능하다.

## 5. 5트릭 = 1세트

5번의 트릭이 끝나면 쇼다운이 발생한다.

중요:

- 5트릭 = 전투 전체가 아님
- 5트릭 = 1세트

권장 전투 길이:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

한 세트는 짧고 빠르지만 강한 적과의 전투는 여러 세트까지 이어질 수 있다.

## 6. 초반 적 체력

초반 일반 적은 체력을 낮게 잡는다.

목표:

- 초반 잡몹 → 첫 쇼다운에서 대부분 처치 가능
- 강한 잡몹 → 좋은 쇼다운이면 1세트, 나쁘면 2세트
- 엘리트 → 보통 2세트 이상
- 보스 → 장기전

초반 난이도는 높은 체력보다 간단하고 읽기 쉬운 적 기믹으로 만든다.

## 7. 트럼프 — 최신 확정 규칙

기존 규칙인 `한쪽 카드만 트럼프라면 숫자와 상관없이 트럼프가 승리`는 폐기한다.

매 세트 시작 시 ♠ ♥ ♦ ♣ 중 한 무늬를 무작위로 트럼프로 지정하고 공개한다. 해당 세트의 5트릭 동안 고정한다.

현재 트럼프 무늬 카드는 트릭에서:

- **적용 숫자 +3**

예:

이번 트럼프가 ♠일 때:

- ♠3 → 적용 숫자 6
- ♥K → 적용 숫자 13
- 결과: ♥K 승리

다른 예:

- ♠10 → 적용 숫자 13
- ♥Q → 적용 숫자 12
- 결과: ♠10 승리

트럼프는 절대 승리권이 아니라 현재 트릭에서의 강력한 숫자 보정이다.

## 8. 트럼프 개편 이유

기존 `트럼프 무조건 승리` 규칙은 다음 문제가 있었다.

- 숫자 강화 효과를 무력화하기 쉬움
- J/Q/K/A의 높은 숫자 가치가 지나치게 흔들림
- 트럼프가 있으면 다른 카드 효과가 무의미해질 수 있음
- 카드 설계 시 예외 처리가 많아짐

새 규칙에서는 트럼프, 카드 효과, 상태 효과가 모두 `적용 숫자`라는 하나의 체계에서 경쟁한다.

예:

결투가 ♠J, 기본 숫자 11, 카드 효과 +3, 트럼프 아님 → 적용 숫자 14.

상대 ♥Q, 기본 숫자 12, ♥가 현재 트럼프 → 적용 숫자 15.

결과는 상대 승리다. 카드 효과가 무효화된 것이 아니라 숫자 경쟁에서 1 차이로 진 것이다.

## 9. 트릭 판정

트릭 승패 판정은 하나의 숫자 체계로 통일한다.

권장 순서:

1. 카드 기본 숫자 확인
2. 카드 효과에 따른 적용 숫자 변화
3. 트럼프라면 적용 숫자 +3
4. 기타 상태/필드 보정
5. 최종 적용 숫자 비교
6. 높은 쪽 승리
7. 같으면 무승부

따라서 별도의 `트럼프 우선 판정` 단계는 존재하지 않는다.

## 10. 원래 값 / 적용 값

원래 값:

- 카드에 인쇄된 원래 숫자와 무늬

적용 값:

- 현재 트릭에서 효과/트럼프/상태 등에 의해 변화한 값

트릭 승패는 적용 값을 사용한다.

쇼다운 포커 족보는 기본적으로 원래 값을 사용한다.

예:

♠7이 현재 트럼프라면 트릭에서는 적용 숫자 10이지만 쇼다운에서는 기본적으로 여전히 ♠7이다.

단 카드에 명시적으로 `쇼다운 숫자 +1`, `쇼다운에서 Q로 취급`, `쇼다운 무늬 변경` 등이 있으면 예외 가능하다.

## 11. 트릭 승리 보상

기본:

- 트릭 승리 → 칩 +1

트릭 자체의 기본 피해는 없거나 매우 작게 유지한다.

트릭의 주요 역할:

- 칩 확보
- 카드 효과 촉발
- 미래 쇼다운 준비

쇼다운의 주요 역할:

- 큰 피해

특정 네임드 카드만 `트릭 승리 시 즉시 피해 3` 같은 추가 효과를 가질 수 있다.

## 12. 칩

별도 전술 카드 시스템은 존재하지 않는다.

칩은 모든 플레이어가 사용하는 공용 전투 자원이다.

추천 최대 칩은 5이며 플레이테스트로 5~7 사이에서 조정 가능하다.

- 같은 전투에서는 세트가 바뀌어도 유지
- 전투 종료 시 초기화
- 런 전체 화폐와 별개

## 13. 칩 기본 사용처

공용 행동 `손패 교환`:

- 칩 2 소비
- 손패 카드 1장을 덱 맨 아래로 보냄
- 그 후 카드 1장 드로우
- 트릭은 소비하지 않음
- 트릭당 최대 1회 권장

핵심 순환:

`트릭 승리 → 칩 획득 → 손패 조절 → 쇼다운 족보 개선`

## 14. 칩 관련 카드

카드 효과로 칩을 다양하게 활용할 수 있다.

예:

- 칩 1 소비 → 적용 숫자 +3
- 칩이 3 이상이면 추가 효과
- 쇼다운 시 남은 칩에 비례해 위력 증가
- 칩을 전부 소비하고 강한 효과
- 칩이 정확히 0일 때 보너스
- 세트 종료 시 칩 투자
- 다음 세트 이자 획득

칩 특화 빌드도 가능하다.

## 15. 쇼다운

5번째 트릭 종료 후 사용한 카드 5장이 쇼다운을 구성한다.

기본 족보:

스트레이트 플러시 > 포카드 > 풀하우스 > 플러시 > 스트레이트 > 트리플 > 투페어 > 페어 > 하이카드

A-2-3-4-5 스트레이트를 인정한다.

추천 처리 순서:

1. 5장 확정
2. 쇼다운 전 효과
3. 슬롯 / 숫자 / 무늬 조정
4. 포커 족보 판정
5. 정산 효과
6. 기본 위력 계산
7. 배율 효과 계산
8. 최종 피해
9. 세트 종료 효과
10. 적 생존 시 다음 세트

## 16. 상시 쇼다운 우세 시스템 제거

기존 `우세 무늬 추첨 → 카드 수 비교 → 우세 판정 → 기본 추가 피해`는 상시 기본 규칙에서 제거한다.

게임의 기본 축은 이미:

- 트럼프 = 현재 트릭
- 족보 = 미래 쇼다운

로 충분하다.

## 17. 우세의 새로운 역할

`우세`라는 용어 자체는 유지할 수 있다. 하지만 기본 시스템이 아니라 특정 조건으로 얻는 폭딜 상태로 사용한다.

권장:

- 우세 = 이번 쇼다운 최종 위력 ×1.25
- 쇼다운 종료 후 제거

우세 획득 예:

- 기세: 3트릭 연속 승리 시 우세
- 왕관: 5번째 트릭에서 특정 조건으로 승리 시 우세
- 역전: 초반에 밀리다가 후반 연승 성공 시 우세

중요:

- 트럼프 ≠ 우세
- 트럼프 = 적용 숫자 +3을 주는 세트 규칙
- 우세 = 특정 카드/조건으로 획득하는 폭딜 상태

## 18. 쇼다운 폭딜

추천 구조:

`족보 기본 위력 + 카드 시너지 + 상태/계약 보너스 = 기본 쇼다운 위력`

그 후 리버 완성, 우세, 전승, 강한 계약 성공 등 희귀 조건에 최종 배율을 적용한다.

테스트용 족보 위력:

- 하이카드 5
- 페어 10
- 투페어 14
- 트리플 18
- 스트레이트 24
- 플러시 26
- 풀하우스 32
- 포카드 42
- 스트레이트 플러시 60

## 19. 리버 완성

5번째 카드가 들어오면서 이전에는 없던 족보가 처음 완성되면 `리버 완성`으로 판정한다.

권장:

- 최종 위력 ×1.25

목적은 5번째 트릭에서 `이 한 장이 들어오면 터진다`는 긴장과 쾌감을 강화하는 것이다.

## 20. 큰 피해 체감

권장 체감 범위:

- 평범한 쇼다운: 10~30
- 잘 풀린 쇼다운: 30~50
- 강한 시너지: 50~80
- 매우 잘 맞은 고점: 100+

큰 숫자는 여러 조건이 겹쳤을 때만 폭발적으로 나오도록 한다.

## 21. 압승

강한 쇼다운 피해가 초반 적에게 낭비되는 느낌을 줄 수 있으므로 압승 판정을 둔다.

- 적 남은 체력의 150% 이상 피해 → 압승
- 200% 이상 → 대압승

보상 후보:

- 추가 골드
- 보상 선택 개선
- 작은 다음 전투 보너스

주목적은 경제적 보상보다 강한 쇼다운의 성취감이다.

## 22. 속도전

일반전에서는 빠른 빌드가 강할 수 있다.

예:

- 선봉: 첫 세트 동안 강화
- 속전속결: 첫 쇼다운 위력 증가, 이후 효과 없음
- 초동: 전투 첫 트릭 승리 보상 강화

## 23. 장기전

엘리트와 보스에서는 장기전 빌드가 작동한다.

예:

- 예열: 쇼다운 종료마다 전투 동안 강화
- 적응: 이미 상대했던 숫자를 다시 만나면 강화
- 흉터: 쇼다운 피해를 받을 때 누적, 이후 공격력 증가
- 복리: 칩을 세트 사이에서 불림
- 기억: 이전 세트 정보 활용

장기전 카드도 첫 세트에서 최소한의 기능은 가져야 한다.

## 24. 보스

보스는 체력만 높은 적으로 만들지 않는다.

세트가 진행되면서 다음과 같은 변화가 가능하다.

- 패턴 변경
- 플레이어 사용 무늬 학습
- 자주 사용한 숫자 구간 학습
- 트럼프 관련 대응
- 필드 생성
- 강제 계약
- 히든 카드

장기전에서는 플레이어도 적응하고 보스도 플레이어를 학습한다.

## 25. 필드

필드는 매 전투 기본으로 존재하지 않는다.

특정 네임드 카드, 엘리트, 보스, 이벤트 등이 생성한다.

필드는 일시적으로 규칙을 변화시키는 특수 요소다.

예:

- 무법지대: 이번 세트 트럼프 보너스 없음
- 과충전 구역: 트럼프 보너스가 +3 대신 +5
- 감쇠 지대: 트럼프 보너스가 +3 대신 +1
- 뒤집힌 세계: 낮은 적용 숫자가 승리
- 좁은 테이블: 최대 손패 -1

새 트럼프 규칙이 단순한 숫자 보정이므로 필드가 트럼프 수치 자체를 조정하기 쉽다.

## 26. 네임드 카드 설계 시 주의

새 트럼프 규칙에서는 단순 숫자 증가 카드도 정상적으로 작동한다.

예:

결투가 ♠J — `상대가 페이스카드라면 적용 숫자 +3.`

트럼프 여부와 카드 효과가 모두 숫자 보정으로 합쳐지므로 `상대가 트럼프면 예외` 같은 문장을 카드마다 넣을 필요가 크게 줄어든다.

단 지나치게 큰 숫자 버프는 트럼프 +3과 겹쳐 폭발할 수 있으므로 수치 밸런스를 확인한다.

## 27. 효과 지속 구분

- [트릭] 현재 또는 가까운 트릭까지만 지속
- [세트] 현재 5트릭 동안 지속
- [전투] 여러 세트 동안 지속
- [런] 전투 종료 후에도 지속

카드 설명에서 지속 범위를 명확하게 표기한다.

## 28. 고급 효과

다음은 기본 규칙이 아니라 카드 효과를 위한 시스템이다.

- 촉발
- 예약
- 기억
- 표식
- 계약
- 과열
- 적응
- 빚
- 흉터

복잡성은 기본 규칙보다 카드 효과에서 나오게 한다.

## 29. 전술 카드

별도의 전술 카드 시스템은 현재 없다.

존재하지 않는 것:

- 전술 덱
- 전술 손패
- 전술 드로우
- 전술 장착

구버전 코드/카드에 전술 관련 효과가 있다면 최신 규칙에 맞춰 리워크한다.

## 30. 전체 세트 흐름

### 세트 시작

트럼프 무늬 공개 → 손패 3장

### 트릭

카드 1장 선택 → 필요하면 칩으로 손패 교환 → 카드 효과 계산 → 트럼프 카드면 적용 숫자 +3 → 최종 적용 숫자 비교 → 승리 시 칩 +1 → 효과 처리 → 쇼다운 슬롯 적재 → 1장 드로우

위 흐름을 5번 반복한다.

### 쇼다운

5장 확정 → 쇼다운 전 효과 → 족보 계산 → 카드 시너지 → 리버 완성/우세/계약 등의 고점 조건 → 최종 위력 → 피해

적 생존 시 다음 세트, 적 처치 시 전투 종료.

## 31. 핵심 밸런스 철학

트럼프는 강하지만 절대적이지 않아야 한다.

- 낮은 트럼프 카드: 현재 트릭에서 경쟁력을 얻음
- 높은 비트럼프 카드: 여전히 충분히 이길 수 있음
- 카드 숫자 강화: 트럼프와 동일한 적용 숫자 체계에서 정상 작동

플레이어는 `트럼프니까 무조건 낸다`가 아니라 다음을 계산한다.

- 트럼프 +3까지 포함하면 지금 승리할 수 있는가?
- 이 카드를 지금 쓰는 것이 쇼다운 족보보다 가치 있는가?

## 32. 현재 최신 확정/권장 사항

1. 기본 손패 3장.
2. 모든 카드는 일반 52장 트럼프 규격.
3. 5트릭 = 1세트.
4. 초반 일반 적은 낮은 체력.
5. 일반전은 빠르게 끝나는 것이 기본.
6. 엘리트/보스는 여러 세트의 장기전 가능.
7. 세트 시작 시 트럼프 공개.
8. **트럼프 무늬 카드의 적용 숫자 +3.**
9. **트럼프면 무조건 승리 규칙 폐기.**
10. 모든 트릭 승패는 최종 적용 숫자 비교.
11. 트릭 승리 시 칩 +1.
12. 칩은 세트 사이 유지.
13. 칩 2로 손패 카드 1장 교환 권장.
14. 별도 전술 카드 시스템 없음.
15. 쇼다운은 포커 족보 중심.
16. 상시 쇼다운 우세 시스템 없음.
17. 우세는 특정 조건에서 얻는 폭딜 상태.
18. 리버 완성 등으로 쇼다운 폭딜 쾌감 강화.
19. 속도전/장기전 빌드 모두 허용.
20. 기본 규칙은 단순하게, 복잡성은 카드에서 만든다.

## 33. 한 줄 설명

트릭로그는 손패 3장 중 한 장을 선택해, 세트마다 지정되는 트럼프 무늬의 +3 보정을 활용하며 짧은 트릭을 싸우고, 승리로 얻은 칩으로 손패를 조절하면서 5장의 포커 족보를 완성해 쇼다운에서 큰 피해를 터뜨리는 트럼프 로그라이크다.

트럼프는 절대 승리권이 아니라 현재 트릭에서의 강력한 숫자 보정이며, 일반전은 빠르게 끝나지만 엘리트와 보스에서는 여러 세트에 걸친 장기전 빌드도 가능하다.

> `트럼프 무늬는 비트럼프를 무조건 이긴다.`

> **현재 트럼프 무늬의 카드는 트릭에서 적용 숫자 +3.**
