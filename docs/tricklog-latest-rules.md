# 트릭로그 최신 통합 규칙안

> 기준일: 2026-08-23  
> 이 문서를 현재 트릭로그의 최신 기준안으로 간주한다. 과거 규칙과 충돌하면 이 문서를 우선한다.

## 최우선 주의사항

- 별도 전술 카드 시스템은 현재 없다.
- 기본 손패는 3장이다.
- 모든 플레이 카드는 일반 52장 트럼프 규격만 사용한다.
- 기존의 상시 쇼다운 우세 시스템은 기본 규칙에서 제거한다.
- 우세는 특정 조건/효과로만 획득하는 희귀 쇼다운 폭딜 상태로 사용한다.
- 5트릭은 전투 전체가 아니라 1세트다.
- 일반전은 짧게, 엘리트/보스는 여러 세트에 걸친 장기전이 가능하도록 설계한다.
- 쇼다운의 큰 피해는 `족보 + 덧셈 시너지 + 희귀 배율 + 압승 연출`로 만든다.

## 0. 게임의 핵심 정체성

트릭로그는 트럼프 카드 기반 로그라이크 카드게임이다.

플레이어는 매 트릭 손패 3장 중 1장을 선택하며, 핵심 고민은 항상 다음 두 선택의 충돌이어야 한다.

- 지금 트릭을 이기기 좋은 카드를 낼 것인가?
- 5장 뒤 쇼다운의 포커 족보를 위해 더 좋은 카드를 낼 것인가?

핵심 구조:

- 트럼프 = 현재의 힘
- 칩 = 현재 승리를 미래의 선택권으로 바꾸는 자원
- 포커 족보 = 미래의 기본 화력
- 우세 = 특정 조건을 달성했을 때의 희귀 폭딜 상태
- 네임드 효과 = 위 규칙들을 비틀고 연결하는 요소

기본 규칙은 단순하게 유지하고 복잡성은 카드 효과, 적, 보스, 필드 등이 만든다.

## 1. 카드 기본 규격

모든 플레이 카드는 일반적인 52장 트럼프 규격을 따른다.

- 무늬: ♠ / ♥ / ♦ / ♣
- 숫자: 2~10 / J / Q / K / A

사용하지 않는 것:

- 0
- 15 이상
- 음수
- 소수점 숫자
- 특수 무늬
- 무늬 없음
- ? 무늬

특수함은 비표준 숫자/무늬가 아니라 카드 효과로 구현한다.

## 2. 순수 카드 / 네임드 카드

순수 카드:

- 일반 트럼프 카드
- 고유 효과 없음
- 안정적인 족보 구성 재료

네임드 카드:

- 일반 트럼프 숫자/무늬를 그대로 가짐
- 고유 효과가 추가됨

순수 카드는 삭제하지 않는다. 순수 카드가 존재해야 효과 없는 카드 연계, 과도한 효과 의존 방지, 덱 제거/압축의 가치, 안정적인 족보 구성이 살아난다. 완전한 네임드 덱이 항상 정답이 되지 않도록 한다.

## 3. 전투 덱과 손패

보유한 플레이 카드 전체가 전투 덱이다.

전투 시작:

- 덱 셔플
- 카드 3장 드로우
- 기본 최대 손패 3장

매 트릭:

1. 손패 3장 중 카드 1장 선택
2. 카드 사용
3. 트릭 처리
4. 사용한 카드는 현재 세트의 쇼다운 슬롯에 들어감
5. 카드 1장 드로우
6. 다시 손패 3장 유지

장기전에서 덱이 비면 버린 카드 더미를 다시 섞어 드로우 덱으로 사용한다. 따라서 같은 네임드 카드가 한 전투에서 다시 등장할 수 있다.

카드/유물/적 효과로 최대 손패가 일시적으로 2~4장이 되는 것은 허용할 수 있지만 기본값은 3장이다.

## 4. 5트릭 = 1세트

5번의 트릭이 끝나면 쇼다운이 발생한다.

중요: 5트릭은 전투 종료가 아니라 1세트다.

권장 전투 길이:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

한 세트는 빠르게 끝나되 강한 적과의 전투는 여러 세트에 걸칠 수 있다.

## 5. 초반 적 체력과 전투 템포

초반 일반 적의 체력은 낮게 설계한다.

- 초반 잡몹: 첫 쇼다운에서 대부분 처치
- 강한 잡몹: 쇼다운이 좋으면 1세트, 망하면 2세트
- 엘리트: 보통 2세트 이상
- 보스: 장기전

초반 난이도는 체력 뻥튀기보다 간단한 적 기믹으로 만든다.

## 6. 트럼프

매 세트 시작 시 ♠ ♥ ♦ ♣ 중 하나를 무작위로 트럼프 무늬로 정하고 즉시 공개한다. 해당 세트 5트릭 동안 고정한다.

트릭 판정:

1. 한쪽만 트럼프 → 트럼프 카드 승리
2. 둘 다 트럼프 → 높은 적용 숫자 승리
3. 둘 다 비트럼프 → 높은 적용 숫자 승리
4. 적용 숫자도 같음 → 무승부

트럼프는 현재 트릭에서의 힘이며 쇼다운에서 자동으로 강해지지 않는다.

## 7. 트럼프를 유지하는 이유

트럼프가 없으면 높은 숫자 카드가 너무 단순하게 강해지기 쉽다. 트럼프가 있으면 낮은 숫자도 현재 트릭에서 가치가 생겨 현재 트릭 승리와 미래 쇼다운 준비 사이 갈등이 생긴다.

트릭 승리 보상이 지나치게 강하면 무조건 트럼프부터 내는 게임이 되므로 기본 보상은 작고 명확하게 유지한다.

## 8. 원래 값 / 적용 값

모든 카드에는 원래 값과 적용 값이 있다.

- 원래 값: 카드에 실제로 인쇄된 숫자와 무늬
- 적용 값: 효과로 일시 변경된 숫자와 무늬

트릭 승패는 적용 값 기준이다.

쇼다운 포커 족보는 기본적으로 원래 값 기준이다.

단, 카드에 명시적으로 쇼다운 숫자/무늬 변경이 적혀 있다면 쇼다운 값도 변경할 수 있다.

## 9. 트릭 승리의 기본 보상

추천 기본 규칙:

- 트릭 승리 → 칩 +1
- 트릭 승리 자체의 기본 피해는 없거나 매우 작게 유지

역할 구분:

- 트릭 → 칩 확보 / 카드 효과 촉발 / 쇼다운 준비
- 쇼다운 → 주력 피해

직접 트릭 피해는 특정 네임드 효과로만 제공할 수 있다.

## 10. 칩

별도 전술 카드 시스템은 없다. 칩은 플레이어가 항상 사용할 수 있는 공용 전투 자원이다.

추천 기본 최대 칩: 5

플레이테스트로 5~7 범위 조정 가능하다.

- 같은 전투에서는 세트가 넘어가도 유지
- 전투가 끝나면 초기화
- 런 전체 화폐와는 별개

## 11. 칩의 기본 공용 사용처

### 손패 교환

- 칩 2 소비
- 손패 카드 1장을 덱 맨 아래로 보냄
- 카드 1장 드로우
- 트릭을 소비하지 않음
- 트릭당 최대 1회 권장

이 구조로 현재 트릭 승리가 미래 쇼다운 선택권으로 전환된다.

## 12. 칩 관련 카드 설계

기본 칩 사용처는 단순하게 두고 네임드 카드가 칩을 다양하게 활용한다.

예:

- 칩 1 소비 → 적용 숫자 +3
- 칩 3 이상이면 추가 효과
- 남은 칩 수만큼 쇼다운 강화
- 칩 전부 소비
- 칩이 정확히 0일 때 발동
- 쇼다운 종료 시 칩 투자
- 다음 세트 이자 지급
- 트릭 패배 시 칩 보상

## 13. 쇼다운

5번째 트릭 종료 후 사용한 5장이 쇼다운 슬롯에 확정된다.

기본 포커 족보:

스트레이트 플러시 > 포카드 > 풀하우스 > 플러시 > 스트레이트 > 트리플 > 투페어 > 페어 > 하이카드

A-2-3-4-5 스트레이트를 인정한다.

최신 처리 순서:

1. 쇼다운 5장 확정
2. 쇼다운 전 카드 효과
3. 슬롯 / 숫자 / 무늬 변경
4. 포커 족보 판정 및 족보 기본 위력 생성
5. 카드 효과 / 상태 / 계약 / 조건의 덧셈 보너스 정산
6. 리버 완성 / 우세 / 전승 / 고난도 계약 등 희귀 배율 판정
7. 최종 위력 계산
8. 피해
9. 압승/대압승 판정과 연출
10. 세트 종료 효과
11. 적 생존 시 다음 세트

쇼다운이 주력 피해 구간이다.

## 14. 기존 상시 쇼다운 우세 시스템

기존의 무늬 수 비교 기반 상시 우세 판정과 기본 보너스는 기본 규칙에서 제거한다.

사용하지 않는 기본 흐름:

`무늬 수 비교 → 자동 우세 → 기본 +3 보너스`

이유:

- 트럼프 = 현재 트릭 목표
- 포커 족보 = 미래 쇼다운 목표

이미 두 축이 충분히 명확하므로 상시 우세까지 기본으로 넣으면 세 번째 축을 계속 관리해야 한다.

## 15. 우세는 희귀 폭딜 상태로 재활용

우세 개념 자체는 버리지 않는다. 카드, 필드, 적, 보스, 유물, 계약 등이 특정 조건을 통해 만들어내는 희귀 상태로 사용한다.

권장 기본 효과:

- `우세`: 이번 쇼다운 최종 위력 ×1.25
- 쇼다운 종료 후 제거

예:

- 기세: 3트릭 연속 승리 시 우세 획득
- 왕관: 5번째 트릭 승리 시 우세 획득
- 역전: 첫 2트릭 패배 후 나머지 3트릭 전승 시 우세 획득
- 반격: 특정 열세 조건 극복 시 우세 획득

중요:

- 트럼프 ≠ 우세
- 트럼프 = 기본 트릭 규칙
- 우세 = 명시적 조건으로 획득하는 쇼다운 폭딜 상태
- 우세를 사용하지 않는 덱은 우세를 전혀 신경 쓰지 않아도 된다.

## 16. 세트 사이 유지되는 요소

지속 시간을 명확히 구분한다.

- 트릭: 현재 또는 가까운 트릭까지만 지속
- 세트: 현재 5트릭 동안 유지, 쇼다운 후 기본 초기화
- 전투: 여러 세트에 걸쳐 유지
- 런: 전투 이후에도 유지되는 희귀 효과

## 17. 속도전 빌드

짧은 일반전을 빠르게 끝내는 카드군을 허용한다.

예:

- 선봉: 첫 세트 적용 숫자 증가
- 속전속결: 첫 쇼다운 위력 대폭 증가
- 초동: 전투 첫 트릭 승리 시 추가 칩
- 마감: 첫 쇼다운 특정 족보 이상이면 추가 피해

## 18. 장기전 빌드

엘리트/보스에서는 시간이 갈수록 강해지는 카드도 가능하다.

예:

- 예열
- 적응
- 흉터
- 복리
- 기억

장기전 카드는 첫 세트에서도 최소한의 기능이 있어야 한다. 일반전에서는 완전 무효, 보스에서만 과도하게 강한 구조는 피한다.

## 19. 장기전 보스

보스는 체력만 높은 적으로 만들지 않는다. 여러 세트에 걸쳐 패턴 변경, 플레이어 학습, 트럼프 대응, 무늬/숫자 카운터, 필드 생성, 강제 계약, 히든 카드 등을 활용한다.

플레이어도 보스를 학습하고 보스도 플레이어를 학습하는 구조를 지향한다.

## 20. 필드

필드는 기본적으로 항상 존재하지 않는다.

특정 카드, 보스, 엘리트, 이벤트 등이 생성한다.

필드는 게임 규칙을 일시적으로 바꾸는 특수 요소이며 자주 나오기보다 가끔 룰 자체를 뒤집는 상황으로 사용한다.

예:

- 무법지대: 이번 세트 트럼프 없음
- 뒤집힌 세계: 비트럼프끼리는 낮은 숫자가 승리
- 좁은 테이블: 최대 손패 -1

## 21. 고급 효과 키워드

다음은 기본 규칙이 아니라 카드 효과를 위한 시스템으로 사용한다.

- 촉발
- 예약
- 기억
- 표식
- 계약
- 과열
- 적응

복잡성은 카드에서 나오게 한다.

## 22. 긴장감 / 심장 쫄리는 요소

기본 규칙을 더 복잡하게 만들기보다 플레이어가 위험을 알고 욕심낼 수 있는 선택으로 긴장감을 만든다.

원칙:

- 랜덤이 플레이어를 일방적으로 죽이지 않는다.
- 랜덤은 위험한 상황을 만든다.
- 플레이어가 그 위험을 받아들일지 선택한다.

## 23. 전술 카드 시스템

별도의 전술 카드 덱은 현재 사용하지 않는다.

없음:

- 전술 카드 드로우
- 전술 손패
- 전술 덱
- 전술 카드 장착 시스템

구버전 코드/효과에 전술 카드 드로우 등이 남아 있다면 최신 규칙에 맞춰 리워크한다.

기존 전술 카드 아이디어는 일반 네임드 카드, 칩 공용 행동, 카드 효과, 유물, 필드 등으로 재활용한다.

## 24. 카드 이름 방향

앞으로 카드 이름은 가능하면 다음 방향으로 통일한다.

- 명사형
- 짧고 직관적
- 2~5음절 중심
- 아이콘 하나로 표현하기 쉬움
- 효과나 테마가 어느 정도 연상됨

예:

- 검은 탄환 → 철갑탄
- 비열한 승부사 → 야바위꾼
- 날 선 유리 → 유리파편
- 매복한 관측자 → 감시자
- 응급 보호구 → 비상방패

불사조, 재귀 함수, 배터리 1%처럼 개성이 강하고 직관적인 이름은 유지 가능하다.

## 25. 전체 전투 흐름

전투 시작:

덱 셔플 → 손패 3장 → 세트 트럼프 공개 → 칩 초기 상태

각 트릭:

적 정보 확인 → 필요하면 칩으로 손패 교환 → 손패에서 1장 선택 → 양측 카드 공개 → 트럼프 판정 → 적용 숫자 판정 → 승리 시 칩 +1 → 카드 효과 → 쇼다운 슬롯 적재 → 카드 1장 드로우

5트릭 후 쇼다운:

5장 확정 → 쇼다운 전 효과 → 슬롯/숫자/무늬 조작 → 포커 족보 계산 → 덧셈 보너스 정산 → 희귀 배율 판정 → 최종 위력 → 피해 → 압승 판정 → 세트 종료 처리

적이 죽으면 전투 종료. 적이 생존하면 새 트럼프를 공개하고 다음 세트로 진행한다.

## 26. 핵심 밸런스 원칙

좋은 선택은 당장의 최고 선택과 미래의 최고 선택이 항상 같지 않아야 한다.

플레이어가 매 트릭 `트릭을 챙길까?`와 `쇼다운을 챙길까?`를 고민하게 만드는 것이 핵심이다.

큰 쇼다운 피해도 단순 랜덤이 아니라 플레이어가 준비한 조건들이 마지막에 겹쳐서 발생해야 한다.

## 27. 현재 가장 중요한 규칙 결정

1. 기본 손패 3장 유지
2. 5트릭 = 1세트
3. 일반전은 대부분 1세트로 짧게
4. 초반 일반 적 체력은 낮게
5. 엘리트/보스에서는 여러 세트 장기전 허용
6. 매 세트 트럼프 공개
7. 트럼프는 트릭에서만 강함
8. 트릭 승리 → 칩 +1
9. 칩은 전투 중 세트 사이 유지
10. 칩 2로 손패 1장 교환을 기본 공용 행동으로 권장
11. 쇼다운은 포커 족보 중심
12. 기존 상시 쇼다운 우세 시스템은 기본 규칙에서 제거
13. 우세는 명시적 조건으로만 획득하며 권장 기본 효과는 이번 쇼다운 최종 위력 ×1.25
14. 리버 완성은 권장 기본 효과로 쇼다운 최종 위력 ×1.25
15. 배율은 어려운 조건/희귀 효과에만 제한적으로 사용
16. 압승/대압승은 과잉 피해를 성취감과 소규모 보상으로 전환
17. 별도 전술 카드 시스템 없음
18. 모든 카드는 일반 52장 트럼프 규격
19. 복잡성은 기본 규칙보다 카드 효과에서 나오게 한다
20. 속도전 빌드와 장기전 빌드 모두 가능하게 한다

## 28. 한 줄 게임 설명

트릭로그는 손패 3장 중 한 장을 골라 트럼프가 적용되는 짧은 트릭을 싸우고, 승리로 얻은 칩을 이용해 손패를 조정하면서 5장의 포커 족보를 완성해 쇼다운에서 큰 피해를 주는 트럼프 로그라이크다.

일반전은 한 번의 쇼다운으로 빠르게 끝날 수 있지만, 엘리트와 보스에서는 여러 세트가 이어지며 기억·적응·계약·상태·누적 성장 등을 활용한 장기전 빌드도 가능하다.

## 29. 이후 설계에서 지켜야 할 사항

- 구버전 전술 카드 시스템을 임의로 되살리지 않는다.
- 상시 쇼다운 우세를 확정 규칙처럼 사용하지 않는다.
- 우세는 자동 무늬 비교가 아니라 명시적 조건/효과로만 획득한다.
- 특수 숫자 0/15나 특수 무늬를 기본 카드에 넣지 않는다.
- 기본 손패를 임의로 4~5장으로 늘리지 않는다.
- 모든 일반전을 장기전으로 만들지 않는다.
- 트릭 승리와 쇼다운의 역할이 겹치지 않게 한다.
- 높은 숫자가 항상 정답이 되지 않도록 트럼프를 활용한다.
- 카드 효과가 기본 규칙보다 복잡성을 담당하게 한다.
- 카드 설계 시 `현재 트릭 vs 미래 쇼다운`의 선택을 최우선으로 본다.
- 큰 피해는 원인을 플레이어가 이해할 수 있게 단계별로 표시한다.

# 30. 쇼다운 폭딜 / 우세 개편 상세 규칙

이 장은 쇼다운 폭딜과 우세에 대한 최신 상세안이다. 앞선 일반 규칙보다 더 구체적인 내용이 충돌하면 이 장을 우선한다.

## 30.1 상시 쇼다운 우세 제거

매 쇼다운마다 자동으로 무늬를 비교해 우세를 판정하고 기본 위력 보너스를 주는 시스템은 사용하지 않는다.

즉 다음은 기본 규칙이 아니다.

`우세 무늬 추첨 → 양측 무늬 수 비교 → 우세 판정 → 기본 보너스`

상시 우세를 제거해 기본 관리 축을 `트럼프`와 `포커 족보`에 집중한다.

## 30.2 우세 = 희귀한 쇼다운 폭딜 상태

우세는 특정 조건이나 카드 효과로만 획득한다.

권장 기본 효과:

`우세: 이번 쇼다운 최종 위력 ×1.25. 쇼다운 종료 후 제거.`

우세를 만드는 예:

- 기세: 3트릭 연속 승리 시 우세 획득
- 왕관: 5번째 트릭에서 승리하면 우세 획득
- 역전: 첫 2트릭 패배 후 이후 3트릭을 모두 승리하면 우세 획득
- 반격: 특정 열세 조건을 극복하면 우세 획득

우세 빌드는 존재하지만 일반 플레이어는 우세를 상시 추적하지 않아도 된다.

## 30.3 쇼다운 피해 구조

쇼다운 피해는 다음 세 층으로 계산한다.

1. 족보 기본 위력
2. 카드 효과 / 상태 / 계약 / 조건의 덧셈 보너스
3. 희귀한 최종 배율

공식 개념:

`족보 기본 위력 + 덧셈 보너스 = 쇼다운 기본 위력`

그 뒤:

`쇼다운 기본 위력 × 희귀 배율들 = 최종 쇼다운 위력`

족보가 기본 화력, 카드 시너지가 덧셈, 고난도 조건이 최종 배율을 담당한다.

## 30.4 족보 기본 위력 예시

아래 수치는 밸런스 테스트용 예시이며 확정값이 아니다.

| 족보 | 예시 기본 위력 |
| --- | ---: |
| 하이카드 | 5 |
| 페어 | 10 |
| 투페어 | 14 |
| 트리플 | 18 |
| 스트레이트 | 24 |
| 플러시 | 26 |
| 풀하우스 | 32 |
| 포카드 | 42 |
| 스트레이트 플러시 | 60 |

높은 족보일수록 확실하게 큰 피해가 나도록 차이를 둔다.

## 30.5 리버 완성

5번째 카드가 들어오면서 4장 시점에는 존재하지 않던 포커 족보가 새로 완성되었다면 `리버 완성`으로 취급한다.

권장 효과:

`리버 완성: 쇼다운 최종 위력 ×1.25`

예:

4트릭 종료 카드가 `6 / 7 / 8 / K`이고 5번째 카드가 `9`라서 처음으로 스트레이트가 완성되면 리버 완성이다.

목적은 5번째 트릭의 긴장감과 마지막 한 장으로 족보를 완성하는 쾌감을 강화하는 것이다.

## 30.6 트릭 성적은 선택적 고점 보상

트릭 승리의 기본 보상은 그대로 `칩 +1`이다.

트릭 성적이 좋을 때 쇼다운에 작은 추가 보너스를 주는 것은 허용한다.

예시:

- 3승 이상: 쇼다운 위력 소폭 증가
- 4승: 추가 보너스
- 5전 전승: 최종 위력 ×1.5

단 전승 보상은 고점 보상이지 기본 플레이의 필수 조건이 아니다. 트릭 성적 보상이 지나치게 강해져 포커 족보보다 트럼프 카드 제출이 항상 우선되는 상황을 피한다.

## 30.7 배율 효과는 희귀하게 사용

권장 예:

- 리버 완성: ×1.25
- 우세: ×1.25
- 어려운 계약 성공: ×1.25~1.5
- 5전 전승: ×1.5
- 극히 어려운 특수 조건: ×2

대부분의 일반 카드 효과는 `+3`, `+5`, `+8` 같은 덧셈 보너스로 처리한다.

배율은 어려운 조건, 희귀 카드, 위험 감수, 보스 특수 상황 등에서만 사용한다.

## 30.8 폭딜 예시

예:

- 스트레이트 기본 위력: 24
- 카드 효과: +12
- 트릭 성적: +4
- 계약 성공: +8

덧셈 합계: 48

그 뒤:

- 리버 완성 ×1.25
- 우세 ×1.25

최종 위력: 75

이처럼 여러 조건이 한 번에 맞아떨어졌을 때 평소보다 훨씬 큰 숫자가 터져야 한다.

큰 피해가 나왔을 때 플레이어가 `족보`, `덧셈 효과`, `배율 효과` 각각의 기여를 이해할 수 있어야 한다.

## 30.9 피해 숫자의 체감 범위

권장 체감 범위:

- 평범한 쇼다운: 10~30
- 잘 풀린 쇼다운: 30~50
- 강한 시너지: 50~80
- 아주 잘 맞은 고점: 100+

매번 큰 숫자가 나오면 큰 숫자의 의미가 사라진다. 평소에는 비교적 작은 숫자가 나오다가 여러 조건이 겹친 순간 70, 90, 100+가 터지게 한다.

## 30.10 압승 시스템

초반 일반 적의 낮은 체력 때문에 강한 쇼다운 피해가 단순 낭비로 느껴지는 것을 막기 위해 `압승` 결과를 사용할 수 있다.

권장 판정 예:

- 적 남은 체력의 150% 이상 피해: 압승
- 적 남은 체력의 200% 이상 피해: 대압승

예:

적 남은 체력 15에 쇼다운 피해 42 → 대압승

보상은 지나치게 크지 않게 한다.

예:

- 소량 추가 골드
- 보상 선택지 소폭 개선
- 다음 전투의 작은 보너스
- 기타 소규모 런 보상

압승의 핵심 목적은 강한 족보로 약한 적을 박살낸 성취감을 보존하는 것이다.

## 30.11 쇼다운 폭딜 연출

폭딜 쾌감은 수치만으로 만들지 않는다.

높은 족보 / 리버 완성 / 우세 / 계약 성공 등이 발생하면 다음과 같은 순차 연출을 권장한다.

1. 카드 5장 순차 점등
2. 족보 이름 크게 표시
3. 리버 완성 표시
4. 적용된 덧셈 보너스 표시
5. 적용된 배율 표시
6. 최종 피해 숫자를 크게 표시
7. 적 체력바 빠르게 감소
8. 피해량에 맞는 화면 흔들림 / 타격음
9. 압승이면 별도 마무리 연출

예시 표시:

`STRAIGHT`

`리버 완성 ×1.25`

`우세 ×1.25`

`계약 성공 +8`

`75 DAMAGE`

`대압승!`

## 30.12 최종 쇼다운 쾌감 구조

쇼다운 폭딜은 네 층으로 구성한다.

1. 포커 족보 → 기본 피해
2. 네임드 카드 시너지 → 추가 위력
3. 리버 완성 / 계약 / 전승 / 우세 → 고난도 조건 및 희귀 배율
4. 압승 연출 → 큰 피해의 성취감

기존 상시 쇼다운 우세가 담당하던 `조건이 겹쳐 큰 피해가 터지는 재미`는 이제 `족보 + 시너지 + 배율 + 압승` 구조가 담당한다.

## 30.13 각 시스템의 최종 역할

- 트럼프 = 현재 트릭의 힘
- 칩 = 현재 승리를 미래의 선택권으로 바꾸는 자원
- 족보 = 쇼다운 기본 화력
- 우세 = 특정 조건 달성 시 얻는 희귀 폭딜 상태
- 리버 완성 = 마지막 카드로 족보를 완성했을 때의 쾌감 보너스
- 압승 = 큰 피해를 낭비하지 않고 성취감으로 바꾸는 결과

역할을 겹치게 만들지 않는다.

## 30.14 가장 중요한 디자인 원칙

큰 피해는 `운 좋게 떴다`가 아니라 다음 감각이어야 한다.

> 내가 여러 조건을 준비했고, 그 조건들이 마지막 쇼다운에서 한꺼번에 터졌다.

트릭로그의 쇼다운은 5트릭 동안 준비한 결과가 한 번에 폭발하는 순간이어야 한다.
