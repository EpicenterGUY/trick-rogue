# 트릭로그 최신 통합 규칙안 — 검토 보완 적용본

> 기준일: 2026-08-23  
> 이 문서를 현재 트릭로그의 최상위 기준안으로 간주한다. 과거 규칙과 충돌하면 이 문서를 우선한다.

## 폐기된 구버전 규칙

다음 요소는 다시 사용하지 않는다.

- 별도 전술 카드 시스템
- 트럼프 무늬가 비트럼프를 무조건 이기는 규칙
- 매 쇼다운마다 자동 판정되는 상시 우세 시스템
- 특수 숫자 / 특수 무늬 기본 카드

---

## 0. 게임 핵심 정체성

트릭로그는 트럼프 카드 기반 로그라이크 카드게임이다.

플레이어는 매 트릭 손패 3장 중 1장을 선택한다.

핵심 고민은 다음 두 선택의 충돌이다.

- 지금 트릭을 이기기 좋은 카드를 낼 것인가?
- 5장 뒤 쇼다운 족보에 필요한 카드를 낼 것인가?

주요 축:

- 트럼프 = 현재 트릭의 숫자 보정
- 칩 = 현재 트릭 승리를 미래 선택권으로 바꾸는 자원
- 포커 족보 = 쇼다운 기본 화력
- 네임드 카드 효과 = 기본 규칙을 연결하거나 비트는 요소
- 우세 / 계약 / 리버 적중 = 조건을 성공했을 때 쇼다운 폭딜을 만드는 고점 요소

## 1. 카드 기본 규격

모든 플레이 카드는 일반 52장 트럼프 규격만 사용한다.

무늬:

- ♠ / ♥ / ♦ / ♣

랭크:

- 2~10 / J / Q / K / A

트릭 숫자값:

- J = 11
- Q = 12
- K = 13
- A = 14

적용 숫자는 14를 넘어갈 수 있다.

예: 트럼프 A는 트릭에서 14 + 3 = 17이지만 쇼다운에서는 기본적으로 다시 A로 취급한다.

사용하지 않는 것:

- 0
- 15 같은 특수 인쇄 랭크
- 음수 랭크
- 소수점 랭크
- 무늬 없음
- 특수 무늬
- 다섯 번째 수트

특수함은 카드 규격이 아니라 카드 효과로 구현한다.

## 2. 순수 카드 / 네임드 카드

순수 카드:

- 고유 효과 없음
- 일반적인 트럼프 카드
- 안정적인 족보 구성 재료
- 순수 카드 전용 시너지 대상 가능

네임드 카드:

- 일반 숫자와 무늬를 그대로 가짐
- 고유 효과가 붙음

순수 카드는 게임에서 유지한다. 네임드 카드만 많은 덱이 항상 최적이 되지 않도록 한다.

## 3. 전투 덱

보유한 플레이 카드가 전투 덱을 구성한다.

시작 덱 크기는 우선 약 10~14장 범위에서 테스트한다.

초기 권장 테스트값:

- 12장 전후

너무 큰 덱은 원하는 카드와 족보를 만들 통제감이 약해지고, 너무 작은 덱은 같은 카드 반복이 과해진다.

덱 압축 / 카드 추가 / 제거가 실제 빌드 전략이 되도록 한다.

## 4. 손패

기본 최대 손패:

- 3장

전투 시작:

1. 덱 셔플
2. 3장 드로우

매 트릭:

1. 손패 확인
2. 필요하면 칩 공용 행동 사용
3. 카드 1장 선택
4. 트릭 해결
5. 사용한 카드를 쇼다운 슬롯에 놓음
6. 카드 1장 드로우
7. 다시 기본 손패 3장 유지

카드 / 유물 / 적 / 필드 효과로 일시적으로 2~4장이 되는 것은 가능하다.

## 5. 5트릭 = 1세트

한 세트는 정확히 5트릭이다.

각 트릭에서 사용한 카드가 쇼다운 슬롯 1~5에 순서대로 들어간다.

5번째 트릭 종료 후 쇼다운한다.

중요:

- 5트릭 = 전투 종료가 아님
- 5트릭 = 1세트

적이 살아 있으면 다음 세트로 넘어간다.

## 6. 전투 길이

목표 전투 템포:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

초반 일반 적은 첫 쇼다운에서 대부분 처치할 수 있을 정도로 체력을 낮게 잡는다.

초반 난이도는 HP를 과도하게 올리기보다 간단한 적 기믹으로 만든다.

## 7. 트럼프

매 세트 시작 시 ♠ / ♥ / ♦ / ♣ 중 하나를 무작위로 현재 트럼프로 지정하고 즉시 공개한다.

해당 세트 5트릭 동안 유지한다.

최신 규칙:

- 현재 트럼프 무늬 카드는 트릭 적용 숫자 +3

예: 현재 트럼프 ♠

- ♠3 → 6
- ♥K → 13
- 결과: ♥K 승리

다른 예:

- ♠10 → 13
- ♥Q → 12
- 결과: ♠10 승리

구버전의 `한쪽만 트럼프라면 숫자와 관계없이 트럼프 승리` 규칙은 폐기한다.

## 8. 트럼프 판정 시점

카드 효과로 무늬가 변경될 수 있다면 최종 적용 무늬를 먼저 확정한 뒤 트럼프 여부를 판정한다.

권장 계산 순서:

1. 원래 숫자 / 무늬 확인
2. 카드 효과에 의한 무늬 변경
3. 최종 무늬가 현재 트럼프인지 확인
4. 트럼프라면 적용 숫자 +3
5. 기타 숫자 변화 효과 적용
6. 상태 / 필드 보정 적용
7. 최종 적용 숫자 비교

같으면 무승부다.

모든 트릭 승패는 하나의 `최종 적용 숫자` 체계로 처리한다.

## 9. 원래 값 / 적용 값

원래 값:

- 카드에 인쇄된 숫자와 무늬

적용 값:

- 현재 트릭에서 카드 효과 / 트럼프 / 상태 / 필드에 의해 변경된 값

트릭 승패는 적용 값을 사용한다.

쇼다운 포커 족보는 기본적으로 원래 값을 사용한다.

예: ♠7이 트럼프라서 트릭에서 10으로 싸웠더라도 쇼다운에서는 다시 ♠7이다.

단 카드에 명시적으로 `쇼다운에서 8로 취급`, `쇼다운 무늬를 ♥로 취급` 등이 있다면 예외다.

## 10. 적 정보 공개 방식

적 카드가 완전히 공개된 상태에서 플레이어가 선택하면 트릭이 단순 계산 문제가 될 수 있다. 반대로 아무 정보도 없으면 운 영향이 과해질 수 있다.

기본적으로 적은 부분 정보만 예고한다.

예:

- 낮음: 2~6
- 중간: 7~10
- 높음: J~A
- 현재 카드가 트럼프인지 여부

정찰 / 예측 카드가 정확한 숫자와 무늬를 추가로 확인하게 한다.

권장 트릭 순서:

적 예고 확인 → 필요하면 칩으로 손패 교환 → 카드 선택 확정 → 양측 카드 공개 → 트릭 해결

## 11. 트릭 승리 보상

기본:

- 승리 → 칩 +1
- 무승부 → 기본 칩 없음
- 패배 → 기본 칩 없음

트릭 자체는 기본적으로 큰 피해를 주지 않는다.

트릭 역할:

- 칩 획득
- 효과 촉발
- 쇼다운 준비

쇼다운 역할:

- 주력 피해

특정 네임드 카드는 예외적으로 트릭 승리 시 즉시 피해 등을 가질 수 있다.

## 12. 칩

칩은 전투 전용 공용 자원이다.

별도의 전술 카드 시스템은 없다.

권장 최대 칩:

- 5

이는 플레이테스트용 기준값이며 필요하면 5~7 사이에서 조정할 수 있다.

- 같은 전투에서는 세트 사이 유지
- 전투 종료 시 초기화
- 런 전체 화폐와 별개

## 13. 칩 기본 공용 행동

기본 행동 `손패 교환`:

- 칩 2 소비
- 손패 카드 1장을 덱 맨 아래로 보냄
- 그 후 카드 1장 드로우
- 트릭을 소비하지 않음
- 트릭당 최대 1회 권장

핵심 순환:

`트릭 승리 → 칩 획득 → 나쁜 손패 수정 → 좋은 쇼다운 족보에 접근`

즉 현재의 승리를 미래 선택권으로 변환한다.

## 14. 칩 밸런스 원칙

`트릭은 져도 되고 족보만 만들면 된다`는 느낌이 강해도 즉시 트릭 패배 피해 같은 기본 규칙을 추가하지 않는다.

먼저 다음을 조정한다.

- 칩 활용처 강화
- 칩 관련 네임드 카드 강화
- 손패 교환 가치 조정
- 칩 상한 조정

기본 규칙은 가능하면 단순하게 유지한다.

## 15. 세트 종료 후 카드 처리

쇼다운 종료 후:

- 이번 세트 쇼다운에 사용한 5장 → 버린 카드 더미
- 현재 손패에 남아 있는 카드 → 그대로 유지

다음 세트 시작 시 손패를 전부 새로 뽑지 않는다.

손패 3장이 다음 세트까지 이어지고 새 트럼프가 공개된다.

드로우 덱도 그대로 이어서 사용한다.

드로우 덱이 비면:

- 버린 카드 더미를 셔플
- 새 드로우 덱 생성

이를 통해 `이 카드를 다음 세트까지 들고 갈 것인가?`라는 장기적인 손패 관리가 가능해진다.

## 16. 쇼다운

5번째 트릭 종료 후 사용한 5장으로 포커 족보를 판정한다.

기본 족보:

스트레이트 플러시 > 포카드 > 풀하우스 > 플러시 > 스트레이트 > 트리플 > 투페어 > 페어 > 하이카드

A-2-3-4-5 스트레이트를 인정한다.

## 17. 쇼다운 처리 순서

권장 순서:

1. 5장 확정
2. 쇼다운 전 효과
3. 쇼다운 숫자 / 무늬 / 슬롯 조정
4. 포커 족보 판정
5. 정산 효과
6. 기본 위력 계산
7. 덧셈 보너스 합산
8. 배율 보너스 계산
9. 최종 피해
10. 세트 종료 효과
11. 적 생존 여부 확인
12. 생존 시 다음 세트

## 18. 양측 쇼다운 공격 순서

플레이어와 적 모두 5장의 쇼다운을 구성하는 방향을 권장한다.

피해 처리 순서:

1. 플레이어 쇼다운 피해를 적에게 적용
2. 적 사망 여부 확인
3. 적이 살아 있다면 적 쇼다운 피해를 플레이어에게 적용

플레이어가 쇼다운에서 적을 처치하면 적의 쇼다운 공격은 발생하지 않는다.

목적:

- 좋은 족보로 적 공격 자체를 끊는 쾌감
- 초반 1세트 처치의 명확한 보상
- 상호 동시 사망 같은 애매한 상황 감소

## 19. 쇼다운 기본 위력

테스트용 출발값:

- 하이카드 5
- 페어 10
- 투페어 14
- 트리플 18
- 스트레이트 24
- 플러시 26
- 풀하우스 32
- 포카드 42
- 스트레이트 플러시 60

수치는 플레이테스트로 조정 가능하다.

## 20. 쇼다운 피해 구조

권장 계산 구조:

`족보 기본 위력 + 카드 효과 + 상태 효과 + 계약 등의 덧셈 보너스 = 기본 쇼다운 위력`

그 후 희귀한 배율 보너스를 적용한다.

즉 `기본 화력 → 덧셈 시너지 → 배율 폭발` 순서다.

## 21. 리버 시스템 — 최신 수정본

구버전의 `5번째 카드로 족보가 완성되면 무조건 리버 완성` 규칙은 사용하지 않는다.

4번째 트릭 종료 시 현재 4장 기준으로 특정 카드가 들어오면 족보가 개선되는 `리버 후보`가 존재하는지 계산한다.

예:

- 6 / 7 / 8 / 9 → 5 또는 10이 들어오면 스트레이트
- ♥가 4장 → ♥ 카드가 들어오면 플러시

5번째 카드가 실제로 그 리버 후보 조건을 만족시켰다면 `리버 적중`이 발동한다.

권장 효과:

- 추가 배율 +25%

핵심은 `5번째 카드였기 때문`이 아니라, 4장 시점에서 보였던 완성 가능성을 실제 마지막 카드로 맞혔을 때 보상하는 것이다.

## 22. 리버 정보 표시

4번째 트릭 종료 후 가능한 리버 후보를 UI에 보여준다.

예:

- `스트레이트 가능: 5 / 10`
- `♥가 들어오면 플러시`

목적은 랜덤 결과가 아니라 플레이어가 위험과 가능성을 알고 선택하게 하는 것이다.

## 23. 상시 우세 시스템 제거

기존 `우세 무늬 추첨 → 무늬 개수 비교 → 자동 우세 판정` 구조는 사용하지 않는다.

게임 기본 축은 다음 두 개로 유지한다.

- 트럼프 = 현재 트릭
- 족보 = 미래 쇼다운

## 24. 우세의 최신 역할

우세는 조건부 폭딜 상태로만 사용한다.

권장:

- 우세 = 이번 쇼다운 추가 배율 +25%
- 쇼다운 종료 후 제거

예:

- 기세: 3트릭 연속 승리 시 우세
- 역전: 특정 열세 상황을 뒤집으면 우세
- 최후의 왕: 저체력 조건에서 우세

트럼프와 우세는 완전히 다른 개념이다.

## 25. 배율 중첩 규칙

일반 배율 효과를 전부 곱셈으로 연쇄 적용하지 않는다.

예:

- 리버 +25%
- 우세 +25%
- 계약 +50%

총 추가 배율은 +100%이고 최종 배율은 ×2.0이다.

계산 방식:

`최종 배율 = 기본 ×1 + 일반 추가 배율 총합`

즉 `1.25 × 1.25 × 1.5` 같은 연쇄 곱셈은 사용하지 않는다.

권장 일반 배율 상한:

- ×2.0~×2.5

특정 희귀 카드 / 유물 / 보스 조건만 명시적으로 이 상한을 초과할 수 있다.

## 26. 폭딜 체감

권장 체감 범위:

- 평범한 쇼다운: 10~30
- 잘 풀린 쇼다운: 30~50
- 강한 시너지: 50~80
- 고점 성공: 100+

큰 숫자는 항상 나오지 않게 한다. 여러 조건을 준비하고 마지막에 겹쳤을 때만 크게 터지게 한다.

## 27. 압승

강한 쇼다운이 초반 적에게 낭비되는 느낌을 줄이기 위해 압승 개념을 사용할 수 있다.

예:

- 적 남은 체력의 150% 이상 피해 → 압승
- 200% 이상 → 대압승

보상 후보:

- 추가 골드
- 보상 선택 개선
- 다음 전투 소규모 보너스

핵심은 경제적 이득보다 큰 피해의 연출과 성취감이다.

## 28. 속도전 빌드

짧은 일반전을 빠르게 끝내는 카드군이 존재할 수 있다.

예:

- 선봉: 첫 세트 강화
- 속전속결: 첫 쇼다운 위력 증가
- 초동: 전투 첫 트릭 승리 시 추가 칩

속도전 빌드는 일반전에 강하고 보스 초반 페이즈를 빠르게 넘길 수 있다.

## 29. 장기전 빌드

엘리트 / 보스의 여러 세트를 활용하는 장기전 카드군도 존재한다.

예:

- 예열: 쇼다운 종료마다 전투 동안 성장
- 적응: 이미 본 적 숫자에 강해짐
- 흉터: 쇼다운 피해를 받을수록 성장
- 복리: 남은 칩을 다음 세트에 투자
- 기억: 이전 세트 정보 활용

장기전 카드도 첫 세트에서 최소한의 기능을 가져야 한다.

## 30. 보스

보스는 단순 고체력 적이 아니다.

세트 진행에 따라 다음을 사용할 수 있다.

- 패턴 변경
- 플레이어 자주 쓰는 무늬 기록
- 숫자 구간 학습
- 트럼프 보정 변화
- 필드 생성
- 강제 계약
- 정보 은폐
- 페이즈 변화

플레이어도 보스를 학습하고 보스도 플레이어 패턴에 대응하게 한다.

## 31. 필드

필드는 기본적으로 매 전투 존재하지 않는다.

특정 네임드 카드 / 적 / 엘리트 / 보스 / 이벤트가 생성한다.

필드는 기본 규칙 하나를 강하게 비트는 특수 요소다.

예:

- 과충전 구역: 트럼프 +3 → +5
- 감쇠 지대: 트럼프 +3 → +1
- 무법지대: 이번 세트 트럼프 보너스 없음
- 좁은 테이블: 최대 손패 -1
- 뒤집힌 세계: 특정 조건에서 낮은 적용 숫자가 승리

필드는 자주 나오기보다 등장했을 때 플레이 감각이 확실히 달라져야 한다.

## 32. 효과 지속 시간

- [트릭] 현재 또는 가까운 트릭까지만 지속
- [세트] 현재 5트릭 동안 지속
- [전투] 여러 세트에 걸쳐 지속
- [런] 전투 종료 후에도 유지되는 희귀 효과

카드 설명에서 지속 범위를 명확하게 작성한다.

## 33. 고급 카드 효과

다음은 기본 규칙이 아니라 카드 효과용 시스템으로 사용한다.

- 촉발
- 예약
- 기억
- 표식
- 계약
- 과열
- 적응
- 빚
- 흉터
- 공명
- 왜곡

복잡성은 기본 규칙보다 카드 효과에서 발생하게 한다.

## 34. 전술 카드 시스템

별도의 전술 카드 시스템은 존재하지 않는다.

존재하지 않는 것:

- 전술 덱
- 전술 손패
- 전술 드로우
- 전술 카드 장착

구버전 전술 카드 아이디어는 필요하면 네임드 카드 / 유물 / 필드 / 칩 공용 행동으로 재활용한다.

## 35. 전체 전투 흐름

### 전투 시작

전투 덱 셔플 → 손패 3장 → 첫 세트 트럼프 공개

### 트릭 시작

적 행동 일부 예고 → 플레이어 정보 확인 → 필요하면 칩 2로 손패 교환 → 카드 1장 선택 → 양측 카드 공개 → 무늬 변경 등 효과 처리 → 트럼프 +3 적용 → 기타 숫자 / 상태 / 필드 보정 → 최종 적용 숫자 비교 → 승리 시 칩 +1 → 트릭 효과 처리 → 사용 카드 쇼다운 슬롯 적재 → 카드 1장 드로우

이 흐름을 5번 반복한다.

### 4번째 트릭 종료

현재 4장으로 가능한 리버 후보를 계산하고 표시한다.

### 5번째 트릭

카드 선택 → 리버 후보 적중 여부 확인

### 쇼다운

5장 확정 → 쇼다운 전 효과 → 숫자 / 무늬 / 슬롯 변화 → 족보 계산 → 정산 효과 → 족보 기본 위력 → 덧셈 보너스 → 리버 / 우세 / 계약 등의 추가 배율 합산 → 최종 배율 1회 적용 → 플레이어 쇼다운 피해 → 적 사망 확인 → 적 생존 시 적 쇼다운 피해

### 세트 종료

쇼다운 카드 5장 → 버린 카드 더미

손패 3장 → 유지

적 사망 → 전투 종료

적 생존 → 다음 세트 트럼프 공개 → 다음 세트 시작

## 36. 가장 중요한 디자인 원칙

좋은 선택에서 `지금 가장 강한 카드`와 `쇼다운에 가장 좋은 카드`가 항상 같지 않아야 한다.

예: 현재 트럼프 ♠, 손패 ♠4 / ♥8 / ♦9

- ♠4는 트릭에서 7로 싸워 현재 승리에 유리할 수 있음
- ♥8은 미래 무늬 구성에 중요할 수 있음
- ♦9는 스트레이트 구성에 중요할 수 있음

플레이어는 매 트릭 다음을 고민해야 한다.

- 트릭을 챙길까?
- 족보를 챙길까?
- 칩을 써서 손패를 바꿀까?
- 리버 가능성을 남길까?

## 37. 최신 권장 기준 요약

1. 기본 손패 3장.
2. 시작 덱 약 12장부터 테스트.
3. 모든 카드는 일반 52장 규격.
4. 5트릭 = 1세트.
5. 일반 적은 대부분 짧은 전투.
6. 초반 적 체력은 낮게.
7. 엘리트 / 보스는 여러 세트.
8. 매 세트 트럼프 공개.
9. 트럼프 무늬는 적용 숫자 +3.
10. 트럼프 무조건 승리 규칙 없음.
11. 모든 트릭은 최종 적용 숫자 비교.
12. 트릭 승리 시 칩 +1.
13. 칩 최대 5부터 테스트.
14. 칩 2로 손패 1장 교환.
15. 쇼다운은 원래 값 중심.
16. 플레이어 쇼다운 피해를 먼저 처리.
17. 적이 살아 있을 때만 적 쇼다운 공격.
18. 세트 종료 후 사용한 5장은 버림.
19. 남은 손패는 다음 세트까지 유지.
20. 상시 우세 없음.
21. 우세는 +25% 추가 배율 상태.
22. 리버는 4장 시점의 후보를 5번째 카드로 실제 적중했을 때만 발동.
23. 배율은 연쇄 곱셈이 아니라 추가 배율 합산 후 1회 적용.
24. 일반 배율 상한은 ×2~×2.5 정도 권장.
25. 필드는 특수 상황에서만 등장.
26. 별도 전술 카드 시스템 없음.
27. 복잡성은 기본 규칙이 아니라 카드 효과에서 만든다.

## 38. 한 줄 설명

트릭로그는 손패 3장 중 한 장을 선택해 세트마다 지정되는 트럼프의 +3 숫자 보정을 활용하며 현재 트릭을 싸우고, 승리로 얻은 칩으로 손패를 조절하면서 5장의 포커 족보와 리버 가능성을 준비해 쇼다운에서 시너지와 조건부 배율을 한꺼번에 폭발시키는 트럼프 기반 로그라이크 카드게임이다.

## 구현 지시

이후 카드 / 적 / 보스 / 유물 / 필드 / 코드 설계에서는 이 문서를 최신 기준으로 사용한다.

특히 다음 구버전 규칙을 되살리지 않는다.

- 트럼프 무조건 승리
- 상시 쇼다운 우세
- 별도 전술 카드 시스템
- 특수 숫자 / 특수 무늬 기본 카드

숫자값, 칩 상한, 족보 피해 등은 플레이테스트로 조정 가능한 밸런스 수치이며 핵심 구조와 혼동하지 않는다.
