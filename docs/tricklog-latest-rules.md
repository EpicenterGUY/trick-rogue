# 트릭로그 최신 통합 규칙안

> 기준일: 2026-08-23  
> 이 문서를 현재 트릭로그의 최신 기준안으로 간주한다. 과거 규칙과 충돌하면 이 문서를 우선한다.

## 최우선 주의사항

- 별도 전술 카드 시스템은 현재 없다.
- 기본 손패는 3장이다.
- 모든 플레이 카드는 일반 52장 트럼프 규격만 사용한다.
- 기존의 상시 쇼다운 우세 시스템은 기본 규칙에서 제거하는 방향이다.
- 5트릭은 전투 전체가 아니라 1세트다.
- 일반전은 짧게, 엘리트/보스는 여러 세트에 걸친 장기전이 가능하도록 설계한다.

## 0. 게임의 핵심 정체성

트릭로그는 트럼프 카드 기반 로그라이크 카드게임이다.

플레이어는 매 트릭 손패 3장 중 1장을 선택하며, 핵심 고민은 항상 다음 두 선택의 충돌이어야 한다.

- 지금 트릭을 이기기 좋은 카드를 낼 것인가?
- 5장 뒤 쇼다운의 포커 족보를 위해 더 좋은 카드를 낼 것인가?

핵심 구조:

- 트럼프 = 현재의 힘
- 칩 = 현재 승리를 미래의 선택권으로 바꾸는 자원
- 포커 족보 = 미래의 힘
- 네임드 효과 = 위 규칙들을 비틀고 연결하는 요소

기본 규칙은 단순하게 유지하고 복잡성은 카드 효과, 적, 보스, 필드 등이 만든다.

## 1. 카드 기본 규격

모든 플레이 카드는 일반적인 52장 트럼프 규격을 따른다.

- 무늬: ♠ / ♥ / ♦ / ♣
- 숫자: 2~10 / J / Q / K / A

사용하지 않는 것:

- 0
- 15 이상
- 음수
- 소수점 숫자
- 특수 무늬
- 무늬 없음
- ? 무늬

특수함은 비표준 숫자/무늬가 아니라 카드 효과로 구현한다.

## 2. 순수 카드 / 네임드 카드

순수 카드:

- 일반 트럼프 카드
- 고유 효과 없음
- 안정적인 족보 구성 재료

네임드 카드:

- 일반 트럼프 숫자/무늬를 그대로 가짐
- 고유 효과가 추가됨

순수 카드는 삭제하지 않는다. 순수 카드가 존재해야 효과 없는 카드 연계, 과도한 효과 의존 방지, 덱 제거/압축의 가치, 안정적인 족보 구성이 살아난다. 완전한 네임드 덱이 항상 정답이 되지 않도록 한다.

## 3. 전투 덱과 손패

보유한 플레이 카드 전체가 전투 덱이다.

전투 시작:

- 덱 셔플
- 카드 3장 드로우
- 기본 최대 손패 3장

매 트릭:

1. 손패 3장 중 카드 1장 선택
2. 카드 사용
3. 트릭 처리
4. 사용한 카드는 현재 세트의 쇼다운 슬롯에 들어감
5. 카드 1장 드로우
6. 다시 손패 3장 유지

장기전에서 덱이 비면 버린 카드 더미를 다시 섞어 드로우 덱으로 사용한다. 따라서 같은 네임드 카드가 한 전투에서 다시 등장할 수 있다.

카드/유물/적 효과로 최대 손패가 일시적으로 2~4장이 되는 것은 허용할 수 있지만 기본값은 3장이다.

## 4. 5트릭 = 1세트

5번의 트릭이 끝나면 쇼다운이 발생한다.

중요: 5트릭은 전투 종료가 아니라 1세트다.

권장 전투 길이:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

한 세트는 빠르게 끝나되 강한 적과의 전투는 여러 세트에 걸칠 수 있다.

## 5. 초반 적 체력과 전투 템포

초반 일반 적의 체력은 낮게 설계한다.

- 초반 잡몹: 첫 쇼다운에서 대부분 처치
- 강한 잡몹: 쇼다운이 좋으면 1세트, 망하면 2세트
- 엘리트: 보통 2세트 이상
- 보스: 장기전

초반 난이도는 체력 뻥튀기보다 간단한 적 기믹으로 만든다.

## 6. 트럼프

매 세트 시작 시 ♠ ♥ ♦ ♣ 중 하나를 무작위로 트럼프 무늬로 정하고 즉시 공개한다. 해당 세트 5트릭 동안 고정한다.

트릭 판정:

1. 한쪽만 트럼프 → 트럼프 카드 승리
2. 둘 다 트럼프 → 높은 적용 숫자 승리
3. 둘 다 비트럼프 → 높은 적용 숫자 승리
4. 적용 숫자도 같음 → 무승부

트럼프는 현재 트릭에서의 힘이며 쇼다운에서 자동으로 강해지지 않는다.

## 7. 트럼프를 유지하는 이유

트럼프가 없으면 높은 숫자 카드가 너무 단순하게 강해지기 쉽다. 트럼프가 있으면 낮은 숫자도 현재 트릭에서 가치가 생겨 현재 트릭 승리와 미래 쇼다운 준비 사이 갈등이 생긴다.

트릭 승리 보상이 지나치게 강하면 무조건 트럼프부터 내는 게임이 되므로 기본 보상은 작고 명확하게 유지한다.

## 8. 원래 값 / 적용 값

모든 카드에는 원래 값과 적용 값이 있다.

- 원래 값: 카드에 실제로 인쇄된 숫자와 무늬
- 적용 값: 효과로 일시 변경된 숫자와 무늬

트릭 승패는 적용 값 기준이다.

쇼다운 포커 족보는 기본적으로 원래 값 기준이다.

단, 카드에 명시적으로 쇼다운 숫자/무늬 변경이 적혀 있다면 쇼다운 값도 변경할 수 있다.

## 9. 트릭 승리의 기본 보상

추천 기본 규칙:

- 트릭 승리 → 칩 +1
- 트릭 승리 자체의 기본 피해는 없거나 매우 작게 유지

역할 구분:

- 트릭 → 칩 확보 / 카드 효과 촉발 / 쇼다운 준비
- 쇼다운 → 주력 피해

직접 트릭 피해는 특정 네임드 효과로만 제공할 수 있다.

## 10. 칩

별도 전술 카드 시스템은 없다. 칩은 플레이어가 항상 사용할 수 있는 공용 전투 자원이다.

추천 기본 최대 칩: 5

플레이테스트로 5~7 범위 조정 가능하다.

- 같은 전투에서는 세트가 넘어가도 유지
- 전투가 끝나면 초기화
- 런 전체 화폐와는 별개

## 11. 칩의 기본 공용 사용처

### 손패 교환

- 칩 2 소비
- 손패 카드 1장을 덱 맨 아래로 보냄
- 카드 1장 드로우
- 트릭을 소비하지 않음
- 트릭당 최대 1회 권장

이 구조로 현재 트릭 승리가 미래 쇼다운 선택권으로 전환된다.

## 12. 칩 관련 카드 설계

기본 칩 사용처는 단순하게 두고 네임드 카드가 칩을 다양하게 활용한다.

예:

- 칩 1 소비 → 적용 숫자 +3
- 칩 3 이상이면 추가 효과
- 남은 칩 수만큼 쇼다운 강화
- 칩 전부 소비
- 칩이 정확히 0일 때 발동
- 쇼다운 종료 시 칩 투자
- 다음 세트 이자 지급
- 트릭 패배 시 칩 보상

## 13. 쇼다운

5번째 트릭 종료 후 사용한 5장이 쇼다운 슬롯에 확정된다.

기본 포커 족보:

스트레이트 플러시 > 포카드 > 풀하우스 > 플러시 > 스트레이트 > 트리플 > 투페어 > 페어 > 하이카드

A-2-3-4-5 스트레이트를 인정한다.

추천 처리 순서:

1. 쇼다운 5장 확정
2. 쇼다운 전 카드 효과
3. 슬롯 / 숫자 / 무늬 변경
4. 포커 족보 판정
5. 정산 효과 처리
6. 최종 위력 계산
7. 피해
8. 세트 종료 효과
9. 적 생존 시 다음 세트

쇼다운이 주력 피해 구간이다.

## 14. 기존 상시 쇼다운 우세 시스템

기존의 무늬 수 비교 기반 상시 우세 판정과 기본 보너스는 기본 규칙에서 제거하는 방향으로 본다.

이유:

- 트럼프 = 현재 트릭 목표
- 포커 족보 = 미래 쇼다운 목표

이미 두 축이 충분히 명확하므로 상시 우세까지 기본으로 넣으면 세 번째 축을 계속 관리해야 한다.

## 15. 우세는 효과로 재활용

우세 개념 자체는 버리지 않는다. 카드, 필드, 적, 보스, 유물 등이 만들어내는 특수 상태/효과로 사용한다.

중요:

- 트럼프 ≠ 우세
- 트럼프 = 기본 트릭 규칙
- 우세 = 특정 효과가 만들어내는 상태/보너스

우세를 사용하지 않는 덱은 전혀 신경 쓰지 않아도 되는 구조를 목표로 한다.

## 16. 세트 사이 유지되는 요소

지속 시간을 명확히 구분한다.

- 트릭: 현재 또는 가까운 트릭까지만 지속
- 세트: 현재 5트릭 동안 유지, 쇼다운 후 기본 초기화
- 전투: 여러 세트에 걸쳐 유지
- 런: 전투 이후에도 유지되는 희귀 효과

## 17. 속도전 빌드

짧은 일반전을 빠르게 끝내는 카드군을 허용한다.

예:

- 선봉: 첫 세트 적용 숫자 증가
- 속전속결: 첫 쇼다운 위력 대폭 증가
- 초동: 전투 첫 트릭 승리 시 추가 칩
- 마감: 첫 쇼다운 특정 족보 이상이면 추가 피해

## 18. 장기전 빌드

엘리트/보스에서는 시간이 갈수록 강해지는 카드도 가능하다.

예:

- 예열
- 적응
- 흉터
- 복리
- 기억

장기전 카드는 첫 세트에서도 최소한의 기능이 있어야 한다. 일반전에서는 완전 무효, 보스에서만 과도하게 강한 구조는 피한다.

## 19. 장기전 보스

보스는 체력만 높은 적으로 만들지 않는다. 여러 세트에 걸쳐 패턴 변경, 플레이어 학습, 트럼프 대응, 무늬/숫자 카운터, 필드 생성, 강제 계약, 히든 카드 등을 활용한다.

플레이어도 보스를 학습하고 보스도 플레이어를 학습하는 구조를 지향한다.

## 20. 필드

필드는 기본적으로 항상 존재하지 않는다.

특정 카드, 보스, 엘리트, 이벤트 등이 생성한다.

필드는 게임 규칙을 일시적으로 바꾸는 특수 요소이며 자주 나오기보다 가끔 룰 자체를 뒤집는 상황으로 사용한다.

예:

- 무법지대: 이번 세트 트럼프 없음
- 뒤집힌 세계: 비트럼프끼리는 낮은 숫자가 승리
- 좁은 테이블: 최대 손패 -1

## 21. 고급 효과 키워드

다음은 기본 규칙이 아니라 카드 효과를 위한 시스템으로 사용한다.

- 촉발
- 예약
- 기억
- 표식
- 계약
- 과열
- 적응

복잡성은 카드에서 나오게 한다.

## 22. 긴장감 / 심장 쫄리는 요소

기본 규칙을 더 복잡하게 만들기보다 플레이어가 위험을 알고 욕심낼 수 있는 선택으로 긴장감을 만든다.

원칙:

- 랜덤이 플레이어를 일방적으로 죽이지 않는다.
- 랜덤은 위험한 상황을 만든다.
- 플레이어가 그 위험을 받아들일지 선택한다.

## 23. 전술 카드 시스템

별도의 전술 카드 덱은 현재 사용하지 않는다.

없음:

- 전술 카드 드로우
- 전술 손패
- 전술 덱
- 전술 카드 장착 시스템

구버전 코드/효과에 전술 카드 드로우 등이 남아 있다면 최신 규칙에 맞춰 리워크한다.

기존 전술 카드 아이디어는 일반 네임드 카드, 칩 공용 행동, 카드 효과, 유물, 필드 등으로 재활용한다.

## 24. 카드 이름 방향

앞으로 카드 이름은 가능하면 다음 방향으로 통일한다.

- 명사형
- 짧고 직관적
- 2~5음절 중심
- 아이콘 하나로 표현하기 쉬움
- 효과나 테마가 어느 정도 연상됨

예:

- 검은 탄환 → 철갑탄
- 비열한 승부사 → 야바위꾼
- 날 선 유리 → 유리파편
- 매복한 관측자 → 감시자
- 응급 보호구 → 비상방패

불사조, 재귀 함수, 배터리 1%처럼 개성이 강하고 직관적인 이름은 유지 가능하다.

## 25. 전체 전투 흐름

전투 시작:

덱 셔플 → 손패 3장 → 세트 트럼프 공개 → 칩 초기 상태

각 트릭:

적 정보 확인 → 필요하면 칩으로 손패 교환 → 손패에서 1장 선택 → 양측 카드 공개 → 트럼프 판정 → 적용 숫자 판정 → 승리 시 칩 +1 → 카드 효과 → 쇼다운 슬롯 적재 → 카드 1장 드로우

5트릭 후 쇼다운:

5장 확정 → 쇼다운 전 효과 → 슬롯/숫자/무늬 조작 → 포커 족보 계산 → 정산 효과 → 최종 위력 → 피해 → 세트 종료 처리

적이 죽으면 전투 종료. 적이 생존하면 새 트럼프를 공개하고 다음 세트로 진행한다.

## 26. 핵심 밸런스 원칙

좋은 선택은 당장의 최고 선택과 미래의 최고 선택이 항상 같지 않아야 한다.

플레이어가 매 트릭 `트릭을 챙길까?`와 `쇼다운을 챙길까?`를 고민하게 만드는 것이 핵심이다.

## 27. 현재 가장 중요한 규칙 결정

1. 기본 손패 3장 유지
2. 5트릭 = 1세트
3. 일반전은 대부분 1세트로 짧게
4. 초반 일반 적 체력은 낮게
5. 엘리트/보스에서는 여러 세트 장기전 허용
6. 매 세트 트럼프 공개
7. 트럼프는 트릭에서만 강함
8. 트릭 승리 → 칩 +1
9. 칩은 전투 중 세트 사이 유지
10. 칩 2로 손패 1장 교환을 기본 공용 행동으로 권장
11. 쇼다운은 포커 족보 중심
12. 기존 상시 쇼다운 우세 시스템은 기본 규칙에서 제거
13. 우세는 특정 카드/보스/필드의 효과로 재활용
14. 별도 전술 카드 시스템 없음
15. 모든 카드는 일반 52장 트럼프 규격
16. 복잡성은 기본 규칙보다 카드 효과에서 나오게 한다
17. 속도전 빌드와 장기전 빌드 모두 가능하게 한다

## 28. 한 줄 게임 설명

트릭로그는 손패 3장 중 한 장을 골라 트럼프가 적용되는 짧은 트릭을 싸우고, 승리로 얻은 칩을 이용해 손패를 조정하면서 5장의 포커 족보를 완성해 쇼다운에서 큰 피해를 주는 트럼프 로그라이크다.

일반전은 한 번의 쇼다운으로 빠르게 끝날 수 있지만, 엘리트와 보스에서는 여러 세트가 이어지며 기억·적응·계약·상태·누적 성장 등을 활용한 장기전 빌드도 가능하다.

## 29. 이후 설계에서 지켜야 할 사항

- 구버전 전술 카드 시스템을 임의로 되살리지 않는다.
- 상시 쇼다운 우세를 확정 규칙처럼 사용하지 않는다.
- 특수 숫자 0/15나 특수 무늬를 기본 카드에 넣지 않는다.
- 기본 손패를 임의로 4~5장으로 늘리지 않는다.
- 모든 일반전을 장기전으로 만들지 않는다.
- 트릭 승리와 쇼다운의 역할이 겹치지 않게 한다.
- 높은 숫자가 항상 정답이 되지 않도록 트럼프를 활용한다.
- 카드 효과가 기본 규칙보다 복잡성을 담당하게 한다.
- 카드 설계 시 `현재 트릭 vs 미래 쇼다운`의 선택을 최우선으로 본다.
