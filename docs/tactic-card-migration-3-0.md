# 전술 카드 → 일반 카드 마이그레이션 3-0

이 문서는 별도 전술 덱/손패/UI를 제거하기 전에 기존 12종 전술을 일반 카드로 옮기기 위한 설계 기준을 고정한다.

중요: 이 단계에서는 런타임 동작을 바꾸지 않는다. `tactic-card-migration.js`의 숫자/무늬는 3-1 구현을 위한 후보 인쇄값이며, 실제 전술 시스템은 아직 유지한다.

## 직접 이관 가능한 6종

| 기존 전술 | 후보 카드 | 일반 카드 효과 |
| --- | --- | --- |
| 페인트 | 4♦ | 이 카드의 트릭 무늬를 현재 트럼프로 변경. 인쇄값/쇼다운값 유지 |
| 숫자 +2 | 3♠ | 이 카드의 트릭 숫자 +2 |
| 임시 장벽 | 6♠ | 사용 시 보호막 3 |
| 리버스 | 3♥ | 이번 트릭은 낮은 트릭 숫자가 승리 |
| 색칠공부 | 9♣ | 이 카드의 쇼다운 무늬를 현재 트럼프 무늬로 변경 |
| 가짜 신분증 | 10♥ | 이 카드의 쇼다운 숫자 +1 |

이 6종은 현재 공통 effect/action으로 표현할 수 있고, 별도 전술 비용/버튼 없이 카드의 `on_play` 효과로 옮길 수 있다.

## 추가 엔진 지원이 필요한 2종

### 드로우 · 6♣
기존 전술의 `카드 1장 즉시 드로우`를 일반 카드 `on_play`로 그대로 옮기면, 카드를 낸 뒤 손패 2장 → 1장 드로우 → 손패 3장이 되어 트릭 종료의 기본 보충과 결과가 같다. 즉 실질적 이득이 사라진다.

따라서 임시 손패 상한 또는 기본 보충 이후 추가 드로우가 필요하다. 후보 문구는 `이 카드를 낸 뒤 다음 트릭의 손패가 1장 많아지도록 추가 드로우한다.`

### 번 · 2♣
기존 전술은 손패에서 선택한 카드를 별도로 버린다. 일반 카드 사용 흐름에는 `내는 카드 외 다른 손패 카드`를 선택하는 단계가 없으므로 보조 타깃 선택 UI/컨텍스트를 먼저 추가해야 한다.

후보 문구는 `사용 시 손패에서 이 카드 외 1장을 선택해 버리고 칩 +1, 카드 1장을 뽑는다.`

## 새 규칙에 맞춰 재설계가 필요한 4종

### 정찰 · 9♦
현재 적 카드는 플레이어 선택 전에 기본 완전 공개된다. 기존 `예측 +1`을 그대로 유지하면 가치가 겹친다.

후보 역할: `다음 트릭의 적 카드를 현재 트릭 종료 전에 미리 공개한다.`

### 더블다운 · 2♥
기존 효과는 새 우세 규칙으로 폐기된 상태다.

후보 역할: `쇼다운에서 내가 우세 무늬를 2개 이상 확보했다면 쇼다운 위력 +6.`

기본 우세 보너스가 우세 무늬 수와 무관하게 +3 한 번뿐이므로, 복수 우세를 별도 빌드로 보상하는 카드로 사용한다. +6 수치는 3-1 전에 밸런스 확인한다.

### 기본에 충실 · 5♦
`순수 카드` gameplay type 제거 방침 때문에 기존 조건을 유지하지 않는다.

후보 역할: `이 카드에 다른 트릭 보정이 없다면 트릭 숫자 +2.`

### 무첨가 · 4♠
마찬가지로 순수 카드 타입 대신 실제 값 변경 여부를 본다.

후보 역할: `이 카드의 트릭값이 인쇄값과 같은 상태로 승리하면 칩 +2.`

## 후보 인쇄값 배치

- ♠: 숫자 +2 3♠ / 무첨가 4♠ / 임시 장벽 6♠
- ♥: 더블다운 2♥ / 리버스 3♥ / 가짜 신분증 10♥
- ♦: 페인트 4♦ / 기본에 충실 5♦ / 정찰 9♦
- ♣: 번 2♣ / 드로우 6♣ / 색칠공부 9♣

네 수트에 3장씩 배치하며 현재 pack01 네임드 10장의 인쇄 슬롯과 겹치지 않는다.

## 다음 단계

3-1에서는 직접 이관 가능한 6종만 일반 카드 정의로 실제 구현한다. 기존 전술 버전은 호환용으로 남겨 두고, 새 카드가 손패/트릭/쇼다운에서 정상 동작하는지 회귀 테스트한 뒤 3-2에서 드로우/번 엔진 지원과 나머지 재설계를 진행한다.
