# 통합 개선안 v2 — 50장 카드 감사

## 감사 기준

- 대상은 `core` 40장과 `pack01` 10장, 총 50장이다.
- 각 카드는 중복 없이 **그대로 사용 가능 / 우세 리워크 필요 / 손패 리워크 필요 / 장기전 리워크 필요 / 미구현** 중 하나로 분류했다.
- 우세 및 손패 리워크 대상은 효과를 임의로 바꾸지 않고 카드 정의의 `needsRework`로만 표시한다.
- `미구현`은 카드 텍스트가 존재하나 현재 `IMPLEMENTED_CARD_EFFECTS`에 실행 정의가 없는 경우다.
- `장기전 리워크 필요`는 여러 set에서 의미가 달라질 수 있어 지속 범위를 먼저 확정해야 하는 카드다.

## 요약

| 분류 | 수량 |
|---|---:|
| 그대로 사용 가능 | 19 |
