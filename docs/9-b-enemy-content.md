# 9-B 적 / 엘리트 / 보스 콘텐츠 확장

## 목표
- 8-B에서 생성만 하던 지역별 `enemyTag`를 실제 적 콘텐츠 선택에 연결한다.
- 기존 공용 적 3종을 제거하지 않고, 지역 전투에서 추가 적이 등장하도록 확장한다.
- 최신 규칙의 트럼프 적용값, 공개 쇼다운 무늬, 상태, 세트 지속, 보스 페이즈를 사용한다.
- 폐기된 전술 덱, 트럼프 자동 승리, 상시 무늬 우세는 사용하지 않는다.

## 추가 콘텐츠
- 일반 적 `가면 딜러`: 유랑극장 `trickster` 태그. 초반 낮은 패 위장 → 후반 고랭크/트럼프 압박.
- 일반 적 `안개 기록관`: 안개 관측소 `observer`/`disruptor` 태그. 공개된 쇼다운 무늬 추적과 자기 무늬 축적.
- 엘리트 `전선 집행관`: 지역 엘리트 전용. 세트 시작 보호막 2 + 플레이어 취약 1.
- 지역 보스 `삼면 딜러`: 지역 보스 전용. HP 66% / 33% 경계로 세트 시작 규칙이 강화되는 3페이즈.

## 선택 규칙
- 공통지역과 최종지역의 기존 적은 그대로 유지한다.
- 최종 보스 `탑의 감시자`는 교체하지 않는다.
- 일반전에서 대응 태그가 없으면 기존 `폐허 약탈자`가 계속 등장한다.
- 지역 엘리트와 지역 보스만 새 전용 콘텐츠로 교체한다.

## 기술 원칙
- 새 적 AI는 `EnemyBehavior`의 기존 공개정보 기반 컨텍스트와 가중치/무늬 선택기를 재사용한다.
- 플레이어 비공개 손패를 AI에 전달하지 않는다.
- 새 엘리트/지역 보스는 기존 `철갑 사냥꾼`/`탑의 감시자` 관리 규칙을 제거한 뒤 자기 규칙만 등록한다.
- 필드는 자동 생성하지 않는다.
