# M6 카드 시스템 태그 규격

기준: 2026-08-27
버전: `M6-1`

## 목적

지역 소속이나 카드팩 개념 대신, 카드가 실제로 어떤 전투 시스템에 개입하는지를 공통 데이터로 표현한다.

- 효과 카드 정의는 `systemTags` 1~3개를 가진다.
- 순수 카드는 보상 분류에서 `족보` 태그를 사용한다.
- 지역 보상 가중치와 카드 데이터는 같은 태그 집합을 읽는다.
- 한 카드는 여러 지역의 테마 후보가 될 수 있다.
- 태그는 카드 획득을 제한하지 않고 등장 가중치에만 사용한다.
- 기존 `buildTags`는 스타터/빌드 아이덴티티 분류용으로 유지하며 M6 시스템 태그와 역할을 섞지 않는다.

## 공식 태그 14종

1. `직접 피해` — 카드 효과로 적 HP를 직접 깎는다.
2. `회복` — 플레이어 HP를 회복한다.
3. `보호막` — 보호막을 얻거나 보호막과 직접 상호작용한다.
4. `칩` — 칩 획득·소비·변환에 직접 관여한다.
5. `예측` — 적 카드 공개, 예측 수치 등 미래 정보에 관여한다.
6. `적용값 증가` — 현재/다음 트릭의 적용 숫자를 올리거나 유리한 값으로 바꾼다.
7. `적용값 감소` — 적용 숫자를 낮추거나 비교 규칙을 뒤집는 등 낮은 값의 의미를 만든다.
8. `우세 개입` — 우세 상태/판정과 직접 상호작용한다.
9. `쇼다운 개입` — 쇼다운 최종 위력이나 쇼다운 슬롯 결과에 직접 개입한다.
10. `예약` — 이후 트릭/쇼다운에 발동할 효과를 예약한다.
11. `계약` — 계약 트리거·조건·효과에 관여한다.
12. `상태` — 출혈 등 상태를 부여·제거·참조한다.
13. `손패` — 드로우, 버림, 손패 용량 등 손패 구성에 개입한다.
14. `족보` — 순수 카드, 무늬 다양성, 쇼다운 카드 복사/변환 등 족보 구성에 관여한다.

## 지역 보상 프로필

현재 3지역은 카드 ID가 아니라 아래 시스템 태그를 읽는다.

### 유랑극장

- `적용값 증가`
- `적용값 감소`
- `우세 개입`
- `쇼다운 개입`
- `계약`

### 안개 관측소

- `예측`
- `손패`
- `예약`
- `족보`

### 황야 전선

- `직접 피해`
- `회복`
- `보호막`
- `칩`
- `상태`

## 보상 규칙

- 일반지역 기본 비율은 현재 `중립 65% / 지역 테마 35%`를 유지한다.
- 카드의 `systemTags` 중 하나라도 현재 지역 프로필과 일치하면 테마 후보가 된다.
- 둘 이상의 지역 프로필과 겹치는 카드는 여러 지역에서 테마 후보가 될 수 있다.
- 특정 지역과 태그가 맞지 않는 카드도 전체 카탈로그에서는 제거하지 않는다.
- 공통지역은 별도의 초반 카드 풀 규칙을 유지한다.
- 순수 카드는 `족보` 태그를 통해 같은 분류 체계에 포함된다.

## 데이터 규칙

- 카드당 대표 태그는 최소 1개, 최대 3개다.
- 공식 14종 외 문자열은 허용하지 않는다.
- 중복 태그를 허용하지 않는다.
- 새 효과 카드는 가능하면 효과의 `action`, `condition`, `trigger`, `handler`, `terms`를 통해 태그를 자동 추론할 수 있어야 한다.
- 자동 추론 결과가 카드의 핵심 선택을 제대로 표현하지 못할 때만 명시적 `systemTags`로 고정한다.

## 검증 범위

자동 회귀 테스트는 다음을 보장한다.

- 공식 태그 집합이 14종으로 고정된다.
- 현재 효과 카드 정의의 `systemTags`가 모두 1~3개다.
- 지역 프로필은 공식 태그만 사용한다.
- 새 카드가 카드 ID 등록 없이 효과 정의만으로 지역 테마 후보가 될 수 있다.
- 같은 카드가 둘 이상의 지역 테마 후보가 될 수 있다.
- 중립/테마 65/35 선택 규칙과 시드 기반 보상 재현성이 유지된다.
- 기존 카드 카탈로그와 효과 회귀가 M6 태그 전환 후에도 유지된다.

## M6 완료 경계

이 문서와 코드로 카드 데이터/지역 보상 가중치의 공통 태그 체계는 구현된다. 다만 ROADMAP의 마지막 M6 조건인 **M4 12장 실제 DEV 체감 판정 결과를 반영한 유지/재설계 범위 확정**은 자동 테스트로 대체하지 않는다. 해당 조건은 M4 실제 플레이 결과가 나온 뒤 별도로 닫는다.
