# M8 필드 카드 보유 / 예약 / 설치 UX

기준: 2026-08-27
버전: `M8-1`

## 확정 규칙

- 필드 카드는 일반 전투 덱과 분리된 별도 카드 타입이다.
- 런 중 명시적인 출처에서 필드를 획득해 `보유 필드 카드` 목록에 저장한다.
- 보유 필드 중 하나만 `다음 전투 필드`로 예약할 수 있다.
- 예약 슬롯은 1칸이다.
- 이미 다른 필드가 예약된 상태에서 다른 보유 필드를 누르면 `교체 예약`으로 처리한다.
- 예약은 해제할 수 있다.
- 예약 필드는 다음 전투 시작 시 한 번 설치되고 즉시 예약 목록에서 소비된다.
- 플레이어가 설치한 필드와 보스/엘리트의 고유 규칙은 별도 출처로 표시한다.

## 맵 UX

맵 화면에는 별도의 `필드 카드` 패널을 표시한다.

- 왼쪽: `다음 전투 필드` 1칸 슬롯
- 오른쪽: 가로 스크롤 가능한 `보유 필드 카드` 목록
- 예약된 카드는 `예약됨`
- 예약이 비어 있으면 다른 보유 카드는 `다음 전투 예약`
- 다른 필드가 이미 예약되어 있으면 `교체 예약`
- 예약 슬롯에서 `예약 해제` 가능

맵의 기존 `빌드` 배지에 필드 상태를 문자열로 덧붙이는 방식은 주 정보 표시로 사용하지 않는다. 필드 상태는 독립된 슬롯 UI에서 읽는다.

## 획득 UX

이벤트/상점 필드 선택지는 현재 상태를 함께 표시한다.

- `신규 보유 · 다음 전투 예약`
- `신규 보유 · 교체 예약`
- `보유 중 · 다음 전투 예약`
- `보유 중 · 교체 예약`
- `보유 중 · 예약됨`

기존 런 규칙과 저장 호환성을 위해 현재 획득 시 자동 예약 동작은 유지한다. 이후 맵의 보유 필드 목록에서 자유롭게 다른 필드로 교체할 수 있다.

## 전투 진입 UX

예약 필드가 실제 전투에 설치되면 `플레이어 필드 설치` 배너를 표시한다.

배너에는 다음을 표시한다.

- 필드 이름
- 필드가 바꾸는 규칙 설명
- 이벤트/상점/유물/계약 등 출처 구분

기존 `현재 전투 규칙` 버튼은 설치 이후에도 필드와 적/보스 고유 규칙을 별도 항목으로 보여준다.

## 자동 검증

- 보유 목록과 예약 슬롯이 동일한 `fieldLoadout` 데이터를 읽는지 확인
- 슬롯 수가 1개인지 확인
- 보유 필드 교체 예약과 예약 해제가 상태에 반영되는지 확인
- 신규/보유/예약/교체 상태 문구 회귀 확인
- 모바일 390×844 브라우저에서 실제 `교체 예약` 버튼 클릭
- 실제 전투 노드 클릭 후 예약 필드가 소비되고 전투 규칙에 설치되는지 확인
- 설치 배너가 실제 브라우저에 표시되는지 확인
- 기존 RUN V3 전체 브라우저 E2E 유지

## 완료 경계

자동 테스트는 필드의 **보유 → 예약 → 교체 → 설치** 흐름과 모바일 클릭 가능 여부를 검증한다.

현재 8종 필드 각각이 재미있는지, 수치 수정이 필요한지, 규칙 자체를 바꿔야 하는지, 삭제할지를 판단하는 작업은 실제 DEV 플레이 체감이 필요하다. 이 항목은 자동 테스트만으로 완료 처리하지 않는다.
