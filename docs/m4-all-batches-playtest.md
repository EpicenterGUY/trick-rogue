# M4 1~4차 12장 통합 체감 테스트

기준: 2026-08-26
기준 main: `b0ee44e8f1f9f9236f976008daa1f1f432d263c7`
목적: M4에서 추가한 12장을 같은 기준으로 실제 DEV 전투에 넣고 `유지 / 수치 수정 / 효과 수정 / 삭제`를 판정한다.

자동 테스트는 이미 카드별 동작을 검증한다. 이 문서는 **정답이 고정되는지, 선택이 생기는지, 체감이 재미있는지**만 본다.

## 공통 판정 기준

### 유지
- 같은 카드라도 상황에 따라 지금 내기 / 아끼기가 갈린다.
- 기존 트릭·칩·쇼다운·슬롯·리버 판단을 더 읽게 만든다.
- 순수 카드나 기존 공용 카드와 역할이 겹치지 않는다.

### 수치 수정
- 효과 구조는 재미있지만 보상/비용 때문에 선택이 너무 쉽게 고정된다.

### 효과 수정
- 카드의 이름과 방향은 좋지만 실제 선택이 거의 생기지 않는다.
- 다른 시스템과 연결점이 부족하다.

### 삭제
- 대부분의 상황에서 무조건 내거나 무조건 버린다.
- 기존 카드의 단순 상위호환/하위호환에 가깝다.

권장 경고선: 비슷한 상황을 5회 이상 봤을 때 4회 이상 같은 선택이 너무 명백하면 `수치 수정` 이상 후보로 본다.

## DEV 공통 준비

1. `?dev=1`로 실행한다.
2. 빠른 일반전을 시작한다.
3. 카드 검색/소환으로 테스트 카드를 손패에 넣는다.
4. 필요하면 같은 랭크/무늬 순수 카드도 같이 넣는다.
5. HP, 칩, 트럼프, 세트 전적, 쇼다운 슬롯을 강제로 맞춘다.
6. 카드별 최소 3개 상황을 각각 2~3회 반복한다.

## 1차

### 선지급 · ♠7
현재: 승리 시 피해 6 / 쇼다운 위력 -5.

테스트:
- 적 HP가 충분한 평상시: 순수 ♠7과 비교.
- 적 HP 6 이하 마무리: 즉시 피해가 패널티를 무시하게 만드는지 확인.
- 쇼다운 직전: -5 때문에 손패에서 지나치게 오래 묵히는지 확인.

관찰 포인트:
- 적 HP에 따라 판단이 실제로 바뀌는가.
- 마무리 상황에서 사실상 무조건 정답이 되는가.

초기 리스크: `중간`. 즉시 피해와 미래 손해의 교환은 좋지만 마무리에서는 패널티가 사라진다.

### 위로금 · ♥4
현재: 패배 시 칩 +2.

테스트:
- 칩 0~1: 일부러 질 이유가 생기는지.
- 칩 4~5: 보상 낭비가 선택을 바꾸는지.
- ♥ 트럼프: 이길 수 있는 카드가 되었을 때 패배 보상과 충돌하는지.

관찰 포인트:
- `어차피 질 카드 + 공짜 칩`이 되는가.
- 실제로 패배를 선택하는 순간이 있는가.

초기 리스크: `중간~높음`. 낮은 숫자 특성상 보상이 공짜처럼 느껴질 가능성이 있다.

### 마지막 한 수 · ♦8
현재: 5번 슬롯이면 쇼다운 위력 +5. 이 카드로 5번째 트릭에서 승리했다면 추가 +5.

테스트:
- 1~2트릭에 손에 잡혀 5번째까지 보존할지 고민하는 상황.
- 5번째 트릭에서 이 카드로 승리 / 패배한 경우를 각각 비교.
- 동일 쇼다운 구성에서 4번 슬롯 / 5번 슬롯 패배 / 5번 슬롯 승리 비교.

관찰 포인트:
- 단순히 5번 슬롯에 두는 것보다 실제 5번째 트릭 승리를 노리게 되는가.
- 총 +10 가능성이 여전히 초반부터 무조건 보존하게 만드는가.
- 5번째 트릭을 이길 수 없는 상황에서는 중간에 쓰는 선택도 자연스러운가.

초기 리스크: `개선 후 재검증`. 정적 +9는 제거했지만 슬롯 보존과 5번째 트릭 승리의 결합이 실제 선택을 만드는지 확인한다.

## 2차

### 영수증 · ♦2
현재: 낼 때 칩 전부 소비 / 쇼다운에서 소비 칩 1개당 +3.

테스트:
- 칩 1~2에서 사용.
- 칩 4~5에서 사용.
- 손패 교환 등 당장 칩을 쓰고 싶은 상황과 충돌시킨다.

관찰 포인트:
- 지금 칩을 포기하고 미래 쇼다운으로 옮기는 선택이 생기는가.
- 칩 5에서 +15가 너무 강해 무조건 저장하는가.

초기 리스크: `중간`. 구조는 좋지만 상한이 강할 수 있다.

### 거울 · ♥5
현재: 낼 때 직전 쇼다운 카드의 무늬 복사.

테스트:
- 직전 카드와 같은 무늬가 이미 충분할 때.
- 플러시/우세 후보를 만들 수 있을 때.
- 1번 슬롯에서 효과 없음.

관찰 포인트:
- 슬롯 순서를 실제로 재고하게 하는가.
- 숫자 5라는 약점이 충분한 대가가 되는가.

초기 리스크: `낮음`. 슬롯·무늬·족보를 직접 연결한다.

### 사기 주사위 · ♦6
현재: 기본 2~12 무작위. 같은 트릭에 칩 손패 교환을 사용했다면 7~12에서 무작위. 쇼다운은 인쇄 6.

테스트:
- 손패 교환 없이 굴려 2~12의 위험을 감수하는 상황.
- 칩 2를 내고 같은 트릭에 손패 교환 후 굴려 7~12 하한을 확보하는 상황.
- 교환한 다음 트릭에 다시 사용해 이전 교환이 하한 상승에 남지 않는지 체감 확인.
- 트럼프 ♦ / 비트럼프 각각 비교.

관찰 포인트:
- 칩과 손패 교환을 먼저 할지 아낄지 실제 선택이 생기는가.
- 손패 교환 자체의 가치까지 포함하면 2칩 비용 대비 7~12가 과하거나 약하지 않은가.
- 조절 수단을 추가한 뒤에도 결과가 지나치게 운에 좌우되는가.

초기 리스크: `개선 후 재검증`. 순수 RNG에서 칩·손패 조작으로 확률을 조절할 수 있게 했고 비용 대비 체감을 확인한다.

## 3차

### 시한폭탄 · ♠2
현재: 1~3트릭에 내면 두 트릭 뒤 피해 12 예약.

테스트:
- 1트릭에 사용 후 2~3트릭 진행.
- 3트릭에 사용.
- 4~5트릭 불발 상황.

관찰 포인트:
- 예약 뒤 두 트릭 동안 플레이가 실제로 달라지는가.
- 12 피해가 너무 커서 초반에 무조건 내는가.

초기 리스크: `높음`. 현재는 예약 뒤 플레이어 행동과 상호작용이 없다.

### 부도수표 · ♣Q
현재: 낼 때 적용 숫자 +8 / 쇼다운 -10.

테스트:
- 지금 반드시 이겨야 하는 트릭.
- 쇼다운 직전.
- 적 HP가 낮아 전투 종료가 가능한 상황.

관찰 포인트:
- 선지급과 판단이 사실상 같은가.
- +8이 너무 커서 쇼다운 손해를 무시하게 되는가.

초기 리스크: `높음`. 선지급과 유사한 `지금 이득 / 미래 손실` 구조다.

### 감염 카드 · ♣4
현재: 쇼다운에서 양옆 효과 카드 1장당 +4, 양쪽 모두면 총 +12.

테스트:
- 양옆 순수 카드.
- 한쪽 효과 카드.
- 양쪽 효과 카드.

관찰 포인트:
- 쇼다운 슬롯 계획을 실제로 바꾸는가.
- `효과 카드끼리 모으기`라는 폐쇄형 클래스 시너지처럼 느껴지는가.

초기 리스크: `중간~높음`. 슬롯 퍼즐은 좋지만 카드 타입 자체를 요구하는 점은 재검토 필요.

## 4차

### 도플갱어 · ♥K
현재: 직전 쇼다운 카드의 숫자와 무늬를 모두 복사.

테스트:
- 높은 숫자 카드 뒤.
- 낮은 숫자지만 원하는 무늬 카드 뒤.
- 1번 슬롯.

관찰 포인트:
- 직전 슬롯 선택을 읽게 만드는가.
- K라는 높은 인쇄값 때문에 트릭에서도 지나치게 안전한가.

초기 리스크: `낮음~중간`. 시스템 연결은 좋지만 기본 랭크가 강하다.

### 러시안 룰렛 · ♠10
현재: 1/6 실패 시 트릭 숫자 2, 나머지는 A.

테스트:
- 반드시 이겨야 하는 트릭.
- 져도 괜찮은 트릭.
- 트럼프 ♠ / 비트럼프 각각.

관찰 포인트:
- 성공 확률이 높아 사실상 A 카드처럼 쓰이는가.
- 실패 확률을 조절할 수 없어 선택보다 운만 남는가.

초기 리스크: `높음`. RNG를 조절하는 자원/정보 연결이 필요할 가능성이 크다.

### 블랙박스 · ♦10
현재: 이 카드로 무승부 기록 시 같은 세트 쇼다운 +15.

테스트:
- 적 숫자 10이 정확히 보이는 상황.
- 트럼프/효과 때문에 무승부를 피하게 되는 상황.
- 무승부 성공 후 쇼다운.

관찰 포인트:
- 무승부를 의도적으로 만들 수 있는가.
- +15가 낮은 발동 빈도에 비해 적절한가.

초기 리스크: `중간`. 조건은 재미있지만 무승부 조절 수단이 부족하면 운 의존이 된다.

## 우선 관찰 후보

실제 체감 전에 구조만 보고 우선 경계할 카드는 다음 6장이다.

1. 마지막 한 수 — `5번 슬롯 +5 / 5번째 트릭 승리 추가 +5`로 1차 개선 후에도 보존 정답이 과한지 재검증
2. 사기 주사위 — 같은 트릭 손패 교환 시 `7~12`로 1차 개선 후 2칩 비용과 안정성의 교환이 적절한지 재검증
3. 시한폭탄 — 예약 뒤 플레이와 상호작용 부족
4. 부도수표 — 선지급과 판단 구조 중복
5. 러시안 룰렛 — 성공률은 높지만 조절 수단 없음
6. 감염 카드 — 효과 카드 자체를 요구하는 폐쇄형 시너지 위험

이 목록은 **체감 테스트 결과가 아니라 테스트 우선순위**다.

## 종료 조건

- 12장 모두 최소 3개 상황을 실제 DEV 전투에서 확인한다.
- 각 카드에 `유지 / 수치 수정 / 효과 수정 / 삭제` 중 하나를 기록한다.
- 수정 카드가 있으면 한 번에 구조와 수치를 동시에 크게 바꾸지 않는다.
- 결과를 ROADMAP에 반영한 뒤 M4 5차 카드 추가 여부를 결정한다.
