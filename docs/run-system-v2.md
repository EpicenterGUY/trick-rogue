# 트릭로그 런 구조 개편안 — 최신 추가 규칙

> 기준일: 2026-08-23  
> 이 문서는 `docs/tricklog-latest-rules.md`의 전투 핵심 규칙은 유지하면서 **런 시작 방식, 진행 구조, 슬롯 조작, 폴드, 메타 성장**을 추가/수정한다.  
> 기존 프로토타입의 캐릭터 선택/액트 진행 구조와 충돌하면 이 문서를 우선한다.

## 1. 유지되는 전투 코어

다음은 변경하지 않는다.

- 기본 손패 3장
- 모든 플레이 카드는 일반 52장 트럼프 규격
- 5트릭 = 1세트
- 세트 시작 시 트럼프 무늬 공개
- 트럼프 무늬의 트릭 적용 숫자 +3
- 트릭 승패는 최종 적용 숫자 비교
- 트릭 승리 시 칩 +1
- 칩은 같은 전투의 세트 사이 유지, 전투 종료 시 초기화
- 칩 2로 손패 카드 1장을 드로우 덱 맨 아래로 보내고 1장 교환
- 쇼다운은 기본적으로 원래 숫자/무늬 사용
- 상시 쇼다운 우세 없음
- 우세는 명시적 조건부 쇼다운 추가 배율 상태
- 별도 전술 카드 시스템 없음
- 일반전은 짧게, 엘리트/보스는 장기전 가능

## 2. 런 시작 정체성

고정 캐릭터 선택을 런의 주축으로 사용하지 않는다.

최신 시작 구조:

`시작 카드군 선택 → 시작 특성 선택 → 런 시작`

런의 초기 정체성은 다음 두 요소가 만든다.

- 시작 카드군: 어떤 시너지 씨앗을 가진 12장 전후 덱으로 시작하는가
- 시작 특성: 이번 런의 기본 성향을 조금 바꾸는 단순 패시브

고정 캐릭터가 덱/패시브를 동시에 잠그지 않는다.

## 3. 시작 카드군

런 시작 시 스타터 덱 하나를 선택한다.

권장 크기:

- 약 12장
- 공통/순수 카드 7~8장
- 카드군 핵심 카드 4~5장

카드군은 완성형 빌드가 아니라 핵심 플레이를 맛보는 출발점이다.

예시 카드군 이름:

- 저격수
- 사진가
- 유랑극단
- 기타 테마 카드군

카드군은 클래스가 아니다. 저격수로 시작해도 사진가/필드/칩/순수/무소속 카드를 자유롭게 얻을 수 있다.

## 4. 무소속 스타터

특정 카드군에 속하지 않는 무소속 스타터를 유지한다.

역할:

- 기본 규칙 학습
- 자유로운 덱빌딩
- 초반 보상에 따라 방향 결정

전체 카드 풀에도 무소속 네임드와 순수 카드가 충분히 존재해야 한다.

## 5. 시작 특성

런 시작 전에 특성 1개를 선택한다.

권장 방식:

`무작위 특성 3개 제시 → 1개 선택 → 런 동안 유지`

특성은 단순하고 범용적이어야 하며 특정 카드군을 강제하지 않는다.

역할 구분:

- 특성 = 런 시작 시 기본 성향
- 카드 = 상황 해결/시너지 구성
- 유물 = 런 중 획득하며 플레이 규칙을 더 크게 변화

## 6. 카드군 혼합

카드군은 폐쇄형 직업이 아니라 강한 시너지 패키지다.

허용 예:

- 저격수 + 사진가
- 사진가 + 유랑극단
- 군대 지원 + 저격수

현재 카드군/방문 지역과 관련된 카드의 등장률을 조금 높일 수는 있지만 다른 카드군 획득을 막지 않는다.

## 7. 최신 전체 진행 흐름

기존 액트 프로토타입에 계속 덧붙이지 않고 최신 구조 기준으로 재설계한다.

`새 게임`
→ `시작 카드군 선택`
→ `시작 특성 선택`
→ `공통지역`
→ `지역 선택`
→ `지역 진행 / 지역 보스`
→ `다음 지역 선택`
→ `지역 진행 / 지역 보스`
→ `최종지역`
→ `최종 보스`
→ `런 종료`

## 8. 공통지역

모든 런은 짧은 공통지역에서 시작한다.

목적:

- 전투 규칙 적응
- 첫 카드 보상
- 첫 유물/핵심 카드 획득 가능
- 현재 덱 방향을 확인한 뒤 지역을 선택하게 함

권장 3~5노드.

예:

`일반전 → 이벤트 → 일반전 → 상점/캠프 → 관문 전투`

플레이어가 아무 정보 없이 첫 지역을 고르는 구조는 피한다.

## 9. 지역 선택

공통지역 이후 여러 지역 중 하나를 고른다.

권장:

- 3개 지역 제시
- 1개 선택

지역 차별 요소:

- 등장 적
- 지역 이벤트
- 카드 등장 경향
- 필드 발생 경향
- 지역 보스
- 위험/보상 성향

지역은 빌드를 유도하지만 클래스를 강제하지 않는다.

카드 보상 예시 비율:

- 공용/무소속 60~70%
- 지역 테마 30~40%

## 10. 런의 최종 정체성

최종 빌드는 다음의 조합으로 만들어진다.

`시작 카드군 + 시작 특성 + 공통지역 초기 보상 + 방문 지역 + 실제 카드/유물 획득`

즉 캐릭터가 빌드를 결정하는 것이 아니라 이번 런에서 지나온 선택과 획득이 빌드를 결정한다.

## 11. 지역 길이 권장안

초기 목표:

- 공통지역: 3~5노드
- 지역 1: 6~8노드 + 지역 보스
- 지역 2: 7~9노드 + 지역 보스
- 최종지역: 4~6노드
- 최종 보스

노드 종류는 우선 다음만 유지한다.

- 일반 전투
- 엘리트
- 이벤트
- 캠프
- 상점
- 보스

필드는 별도 맵 노드가 아니며 적/카드/이벤트/보스가 발생시키는 특수 규칙이다.

## 12. 카드 보상과 골드

전투 종료 후 기본 보상:

- 골드
- 카드 보상

카드는 보통 3장 제시하며 1장 선택 또는 건너뛰기가 가능하다.

덱 압축이 중요하므로 카드 획득을 강제하지 않는다.

자원 구분:

- 칩 = 전투 중 자원
- 골드 = 런 전체 상점 화폐

## 13. 캠프 / 상점 / 강화

초기 완성 버전은 단순하게 유지한다.

캠프:

- 회복
- 카드 강화

상점:

- 카드 구매
- 유물 구매
- 카드 제거

카드 강화는 우선 1단계만 사용한다. 분기 강화는 후순위다.

## 14. 메타 성장

영구 공격력 증가 같은 수치형 성장보다 해금 중심으로 설계한다.

해금 후보:

- 시작 카드군
- 특성
- 네임드 카드
- 유물
- 지역
- 이벤트
- 필드

플레이어의 기본 수치가 영구적으로 강해지는 것이 아니라 선택지가 넓어진다.

## 15. 쇼다운 슬롯 조작

쇼다운에 놓인 카드는 기본적으로 고정된다.

슬롯 조작은 공용 행동이 아니라 특정 카드 효과로만 허용한다.

용어:

- 이동: 이미 놓인 쇼다운 카드의 슬롯 위치를 변경. 일반적으로 두 슬롯 교환.
- 철회: 이미 놓인 카드를 손으로 되돌림. 효과를 발생시킨 카드가 빈 슬롯을 대신 채우는 형태 권장.
- 교체: 쇼다운 카드와 손패/다른 카드를 맞바꿈.
- 폐기: 쇼다운 카드를 버림 더미로 보내고 일반적으로 같은 효과 안에서 새 카드로 해당 슬롯 보충.

강도 기준:

`이동 < 철회 < 교체 < 폐기/대체`

슬롯 조작이 흔해져 처음 5트릭의 선택을 무효화하지 않게 한다.

## 16. 슬롯 고정 상태

슬롯 조작 대응 상태를 둘 수 있다.

예: `족쇄`

- 해당 쇼다운 카드는 이동/철회/교체 불가

자신의 카드를 일부러 고정하고 보상을 받는 효과도 가능하다.

슬롯 조작은 예약/기억/표식/상태 시스템과 연결할 수 있다.

## 17. 폴드 — 테스트 권장안

폴드는 게임 포기가 아니라 현재 세트 손실을 확정하고 다음 세트를 준비하는 손절 행동이다.

기본 권장 시점:

- 3장을 이미 낸 뒤
- 4번째 트릭 카드를 선택하기 전부터 가능

폴드 시:

- 현재 세트 즉시 종료
- 내 쇼다운 공격 없음
- 적 정상 쇼다운 공격도 없음
- 작은 고정 페널티
- 현재 세트 쇼다운 카드 → 버림 더미
- 남은 손패 유지
- 다음 세트 진행

초기 테스트 후보:

- 최대 체력의 8% 피해
- 칩 2 손실

수치는 아직 확정 규칙이 아니다.

1~2트릭 폴드는 좋은 세트만 고르는 리롤이 되기 쉽고, 5번째 카드 확인 후 폴드는 결과 취소가 되므로 기본 허용하지 않는다.

카드/유물이 폴드 피해 감소, 다음 세트 강화, 늦은 폴드 허용, 폴드하지 않았을 때 보상 등을 만들 수 있다.

## 18. 경쟁 콘텐츠 — 장기 확장

초기 코어 완성의 필수 항목이 아니다.

직접 PvP보다 동일/유사 시드에서 런 점수를 비교하는 비동기 경쟁을 우선 검토한다.

평가 후보:

- 클리어
- 최고 쇼다운 피해
- 압승/대압승
- 리버 적중
- 위험 계약
- 세트 수
- 고난도 조건

고점형 덱도 경쟁할 수 있도록 최고 기록, 최고 몇 회 평균, 최고 단일 쇼다운, 위험도 배율 같은 별도 평가를 고려한다.

## 19. 첫 완성 버전의 검증 목표

첫 완성 버전에서 모든 카드군/지역을 만들지 않는다.

먼저 검증할 것:

1. 손패 3장이 재미있는가
2. 트럼프 +3이 적절한가
3. 트릭 승리 → 칩 → 손패 조정 순환이 재미있는가
4. 족보를 의도적으로 만들 수 있는가
5. 5트릭 뒤 쇼다운이 기대되는가
6. 시작 카드군 선택이 실제 플레이 차이를 만드는가
7. 지역 선택이 빌드 성장에 의미가 있는가

## 20. 개발 순서 — 플레이 가능한 세로 슬라이스 우선

기존 8단계 `저장 / 디버그 / E2E`를 바로 확장하기보다, 먼저 최신 런 구조로 플레이 가능한 세로 슬라이스를 만든다.

### 8-A 시작 정체성

- 캐릭터 선택 제거
- 시작 카드군 선택
- 무소속 스타터
- 특성 3개 제시 → 1개 선택
- 런 상태에 `starterId + traitId` 저장

### 8-B 공통지역 / 지역 선택

- 공통지역 3~5노드
- 공통지역 종료 후 지역 3개 제시
- 지역 선택을 런 상태에 기록
- 지역별 적/이벤트/보상 가중치 기반

### 8-C 보상 / 캠프 / 상점 세로 슬라이스

- 전투 후 골드 + 카드 3장/건너뛰기
- 캠프 회복/1단계 강화
- 상점 카드/유물/제거

### 8-D 쇼다운 슬롯 조작 기반

- 이동/철회/교체/폐기 공통 효과 API
- 족쇄 등 조작 제한 상태 기반
- 기본 공용 행동으로는 노출하지 않음

### 8-E 폴드 실험

- 4번째 트릭 시작 전부터 폴드
- 세트 공격 생략 + 고정 페널티
- 손패 유지/쇼다운 카드 버림/다음 세트
- 수치는 플레이테스트 대상으로 분리

### 8-F 저장 / 디버그 / 결정적 재현 / E2E

- 최신 런 상태 직렬화
- 저장/불러오기와 버전 마이그레이션
- 결정적 시드
- 디버그 패널
- 새 게임부터 지역 보스까지 주요 E2E

## 21. 최우선 원칙

- 기본 전투 규칙은 단순하게 유지한다.
- 복잡성은 카드/유물/적/필드에서 만든다.
- 카드군은 클래스가 아니라 시너지 패키지다.
- 무소속/순수 카드를 충분히 유지한다.
- 시작 카드군이 최종 빌드를 고정하지 않는다.
- 지역 선택은 빌드를 유도하되 강제하지 않는다.
- 슬롯 조작은 카드 효과에서만 허용한다.
- 이미 낸 카드를 너무 쉽게 수정하지 못하게 한다.
- 폴드는 무료 리셋이 아니라 손실 최소화 선택이다.
- 경쟁 콘텐츠는 코어 완성 이후 확장한다.
