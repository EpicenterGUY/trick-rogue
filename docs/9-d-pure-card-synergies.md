# 9-D 순수 카드 시너지 확장

## 목표

순수 카드를 단순한 효과 없는 카드가 아니라 덱 구성과 쇼다운에서 의도적으로 유지할 가치가 있는 빌드 축으로 확장한다.

순수 카드는 기존 정의대로 고유 효과가 없는 표준 카드다. 강화로 트릭 숫자 보정이 붙더라도 고유 효과가 새로 생기지 않으면 순수 카드 분류는 유지한다.

## 시너지

### 정석 편성

- 조건: 런 덱 8장 이상, 순수 카드 8장 이상, 순수 비율 70% 이상
- 효과: 세트 시작 시 보호막 +2
- 기본 12장 덱의 순수 8/12는 66.7%이므로 자동 활성되지 않는다.

### 정석 압축

- 조건: 런 덱 10장 이하, 순수 카드 7장 이상, 순수 비율 70% 이상
- 효과: 세트 시작 시 칩 +1
- 상점 카드 제거와 순수 카드 보상을 활용하는 압축형 보상이다.

### 무첨가 승부

- 조건: 런 덱의 순수 카드 9장 이상, 순수 비율 70% 이상
- 효과: 쇼다운 5장 중 순수 카드가 3장 이상이면 쇼다운 위력 +4

### 순수 5장

- 조건: 런 덱의 순수 카드 10장 이상, 순수 비율 75% 이상
- 효과: 쇼다운 5장이 모두 순수 카드면 쇼다운 위력 +8
- 무첨가 승부 조건도 만족하면 두 덧셈 보너스가 함께 적용된다.

## 구현 원칙

- 별도 순수 자원이나 저장 상태를 추가하지 않는다.
- 현재 `run.deck`을 기준으로 매번 순수 장수와 비율을 계산한다.
- 카드 획득/제거 뒤 시너지 활성 상태가 자동으로 변한다.
- `CombatEffects.activeEffectOwners()`의 기존 `passive` 소유자 경로를 사용한다.
- 쇼다운 순수 카드 수 조건도 공통 `CardEffects.conditions`에 등록해 기존 효과 실행기를 사용한다.
- 순수 카드 판정은 기존 `CardEffects.isPureCard()`를 그대로 사용한다.
- 새 시너지는 쇼다운 위력의 덧셈 단계만 사용하며 배율 합산 규칙을 우회하지 않는다.

## UI

- 맵에서 현재 `순수 장수/덱 크기`와 활성 시너지 수를 배지로 확인할 수 있다.
- 전투 중 활성 순수 시너지가 있으면 별도 배지가 표시된다.
- 상세 모달에서 4개 시너지의 조건과 현재 활성 여부를 확인할 수 있다.

## 금지 규칙 유지

- 별도 전술 덱/전술 손패를 만들지 않는다.
- 트럼프 자동 승리를 만들지 않는다.
- 자동 무늬 우세를 만들지 않는다.
- 특수 인쇄 숫자/무늬를 추가하지 않는다.
