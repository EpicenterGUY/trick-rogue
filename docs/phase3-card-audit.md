# Phase 3 카드 효과 감사

## 구현 현황

- 전체 네임드 카드: 50장
- 데이터/handler로 구현됨: 20장
- 설명만 있고 미구현(`implemented: false`): 30장

미구현 목록: 빙결 수정, 그림자 단검, 강철 톱니, 심연 거울, 황금 망원경, 얼음 여왕, 촛불, 새벽 깃털, 약초 주머니, 연심 나침반, 축복의 종, 장미 여왕, 별 병약, 탐험 지도, 메모리 패치, 학원비 영수증, 최종수정본_v7_진짜최종, 빚쟁이의 계약, 만능 열쇠, 흑왕관, 루비 성배, 장미 봉인, 익살 광대, 묶음 서류, 황혼 패스, 푸른 포털, 황금 메달, 연쇄 사슬, 응시의 눈, 황동 의수.

## 설명과 기존 동작의 불일치

- **예약 발송**: 기존 코드는 카드를 낸 바로 그 트릭에서 이기면 예약 피해가 발동했다. 설명대로 다음 트릭부터 발동하도록 수정했다.
- **매복한 관측자**: 기존 코드에는 설명에 없는 3번 슬롯 쇼다운 위력 +4가 있었다. 밸런스 보존을 위해 효과 데이터에는 유지했으며, 카드 문구 정비가 필요하다.
- **태엽 상자**: 설명은 “전술을 사용하지 않았다면”이지만 기존 판정은 전술 사용 이력이 아니라 현재 modifier만 확인했다. 기존 계산을 보존해 `no_tactic_modifier` 조건으로 옮겼다.
- **무첨가(전술)**: 설명은 다음 순수 카드 승리 시 칩 +2지만 기존 코드는 사용 즉시 칩 +1이었다. 카드 효과 엔진 범위 밖인 전술 동작이므로 이번 단계에서는 변경하지 않았다.
