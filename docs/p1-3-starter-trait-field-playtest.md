# P1-3 스타터 × 특성 × 필드 대표 체감 검증

기준: 2026-08-27

목적은 4 × 8 × 8 = 256개 조합을 전수 플레이하는 것이 아니라, 현재 노출된 스타터 4종·특성 8종·필드 8종이 최소 한 번씩 포함되도록 8개 대표 조합을 고정해 체감 문제를 찾는 것이다.

자동 테스트 `test/p1-3-representative-combinations.test.js`가 아래 조합의 ID 존재, 전체 요소 커버리지, 스타터 12장 구성, 손패 -1 필드 범위, 낮은 값 승리 반전, 트럼프 보너스 0/1/2/4/5/6 범위를 먼저 검증한다. 이 문서의 체감 판정은 실제 DEV 플레이 후에만 기록한다.

## 대표 조합

| 케이스 | 스타터 | 특성 | 필드 | 집중 관찰 |
| --- | --- | --- | --- | --- |
| C1 | 정석 | 선행 관측 | 좁은 테이블 | 손패 -1에서도 첫 세트 선택지가 막히지 않는지, 예측 정보가 과도하게 정답을 주지 않는지 |
| C2 | 승부사 | 악착같은 패배 | 뒤집힌 세계 | 낮은 값 승리 규칙과 패배 보상이 모순 없이 읽히는지, 적 AI/예측 표시가 실제 판정과 맞는지 |
| C3 | 변칙 | 수트 수집가 | 무법지대 | 트럼프 +0에서 변칙 스타터의 카드 가치가 붕괴하지 않는지, 4무늬 쇼다운 목표가 자연스러운지 |
| C4 | 생존자 | 빈손주의 | 감쇠 지대 | 트럼프 +1에서 생존 운영이 지나치게 길어지지 않는지, 칩 0 유지가 의미 있는 선택인지 |
| C5 | 정석 | 불완전주의 | 넓은 테이블 | 손패 +1이 하이카드 의도와 충돌하지 않는지, 선택지 증가가 일방적 상향이 아닌지 |
| C6 | 승부사 | 역경 축적 | 과열 테이블 | 손패 -1과 트럼프 +4가 함께 있을 때 막힘 없이 위험/보상이 생기는지 |
| C7 | 변칙 | 우세 추종자 | 과충전 구역 | 트럼프 +5가 우세·쇼다운 보상을 과도하게 증폭하지 않는지 |
| C8 | 생존자 | 순수주의 | 왕실 중계소 | 트럼프 +6에서 순수 카드 3장 유지의 가치가 남는지, 특정 무늬 카드가 사실상 자동 선택이 되지 않는지 |

## 공통 절차

각 케이스는 `?dev=1`에서 일반전 1회와 강전투 또는 엘리트 1회를 최소 범위로 진행한다. 첫 세트는 가능한 한 정상 플레이하고, 두 번째 관찰이 필요하면 DEV 조작으로 카드/필드/적 HP만 보정한다. DEV 조작 자체를 밸런스 판정 근거로 삼지 않는다.

각 케이스에서 다음을 기록한다.

- 첫 3트릭 동안 실제로 고민되는 선택지가 몇 번 있었는지
- 손패가 부족하거나 동일 선택 반복으로 진행이 사실상 막히는 순간이 있었는지
- 특성 발동 조건을 플레이 중 기억할 수 있었는지
- 필드 규칙을 보지 않고도 결과가 납득됐는지
- 적 예측 UI와 실제 트릭 승패가 어긋난 순간이 있었는지
- 스타터/특성/필드 중 하나가 나머지 둘을 무시하게 만들 정도로 강했는지
- 순수 카드와 효과 카드 중 한쪽이 거의 자동 선택이 됐는지

## 판정 기준

각 요소는 `유지 / 수치 수정 / 효과 수정 / UI 설명 수정 / 추가 검증` 중 하나로 기록한다. 한 번의 대표 조합만으로 삭제 판정을 내리지 않는다. 다음 중 하나가 재현되면 P1 버그로 올린다.

- 합법적인 플레이 선택이 없어 진행 불가
- 예측 UI와 실제 판정이 같은 상태에서 불일치
- 필드 설명과 실제 `rulesOverride` 불일치
- 특정 특성이 조건을 만족해도 발동하지 않거나 반대로 조건 없이 발동
- 필드 예약/소모 후 다음 전투에도 의도치 않게 잔류
