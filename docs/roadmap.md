# 7.5 최신 통합 규칙 재정렬

## 현재 상태

- 7.5-A 완료: 상시 쇼다운 우세 제거 + 명시적 우세 기반
- 7.5-B 기반 완료: 트릭 승리 칩 +1 / 기본 최대 5 / 공용 손패 교환 기반
- 7.5-C 기반 완료: 족보 기본 위력 → 덧셈 → 배율 → 피해 계산 뼈대
- 7.5-D 폐기: 구버전 5번째 카드 사후 리버 판정. **7.5-M에서 최신 리버 후보/적중 구조로 교체 완료**
- 7.5-E 완료: 일반전/엘리트/보스 체력 및 세트 템포
- 7.5-F 완료: 필드 없음 기본화 / 명시적 출처 기반 필드 생성
- 7.5-G 완료: 트럼프 자동 승리 폐기 / 트럼프 적용 숫자 +3
- 7.5-H 완료: 무늬 변경 → 트럼프 → 숫자 → 상태/필드 → 최종 적용값 단일 계산 파이프라인
- 7.5-I 완료: 2칩 손패 교환 / 드로우 덱 맨 아래 반환 / 트릭당 1회 / 전투 종료 초기화
- 7.5-J 완료: 실제 시작 덱 10~12장 / 5번째 트릭 포함 즉시 손패 보충 / 쇼다운 5장만 버림 / 손패·드로우 덱 세트 유지
- 7.5-K 완료: 기본 적 카드 부분 예고 / 제출 뒤 실제 공개 / 정찰 정확 공개 / 적 AI 비공개 손패 차단
- 7.5-L 완료: 양측 쇼다운 독립 공격 / 플레이어 선공 / 적 사망 시 반격 취소 / 위력 차이 피해 제거
- 7.5-M 완료: 4번째 트릭 종료 리버 후보 스냅샷 / 5번째 카드 후보 적중 판정 / 후보 UI / 사후 재계산 제거
- 7.5-N 완료: 일반 추가 배율 합산 / 1회 적용 / 기본 ×2.5 상한 / 명시적 상한 예외
- 7.5-O 완료: 트럼프 +5/+1/0 필드 / 최대 손패 -1 / 최종 적용값 비교 반전 / 필드 해제 시 기본값 복원
- 7.5-P 완료: 자동 무늬 우세/+3 제거 / 명시적 우세 조건 통일 / 순수 카드 분류·시너지·시작 덱 보존
- **다음 작업: 7.5-Q 압승 / 고점 연출**

## 기존 단계 중 유지되는 기준

### 7.5-A 우세

- 자동 무늬 비교로 우세 생성 금지
- 우세는 특정 조건으로만 획득
- 최신 의미는 `이번 쇼다운 추가 배율 +25%`
- 쇼다운 종료 후 제거
- 트럼프와 우세는 별개

### 7.5-B 칩

- 트릭 승리 시 칩 +1
- 무승부/패배 기본 칩 없음
- 기본 최대 칩 5
- 같은 전투에서는 세트 사이 유지
- 전투 종료 시 초기화
- 런 화폐와 별개

### 7.5-C 쇼다운 기본 위력 뼈대

테스트용 족보 위력:

- 하이카드 5
- 페어 10
- 투페어 14
- 트리플 18
- 스트레이트 24
- 플러시 26
- 풀하우스 32
- 포카드 42
- 스트레이트 플러시 60

양측 피해 순서는 7.5-L에서, 배율 중첩 방식은 7.5-N에서 최신 규칙으로 교체 완료했다.

### 7.5-E 전투 템포

목표:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

현재 테스트용 HP 곡선:

- 초반 일반전 24
- 강한 일반전 36
- 엘리트 64
- 보스 120

피해 체감 목표:

- 평범한 쇼다운 10~30
- 잘 풀린 쇼다운 30~50
- 강한 시너지 50~80
- 고점 100+

### 7.5-F 필드 존재 방식

- 필드 없음이 정상 전투 상태
- 일반/엘리트/보스 모두 자동 기본 필드 없음
- 카드/적/엘리트/보스/이벤트 등 명시적 출처가 있을 때만 필드 생성
- 필드와 적 고유 규칙/보스 페이즈는 별도

### 7.5-G 트럼프 +3 — 완료

- `트럼프면 자동 승리` 제거
- 현재 트럼프 무늬는 트릭 적용 숫자 +3
- 적용 숫자는 14 초과 가능
- 플레이어와 적에 대칭 적용
- 쇼다운 원래값에는 트럼프 +3이 남지 않음

# 신규 보완 이정표

## 7.5-H 최종 적용값 계산 파이프라인 고정 — 완료

정식 트릭 계산 순서:

1. 원래 숫자 / 원래 무늬 확인
2. 카드 효과에 의한 무늬 변경
3. 최종 무늬로 트럼프 여부 판정
4. 트럼프라면 적용 숫자 +3
5. 기타 숫자 변화 효과
6. 상태 / 필드 보정
7. 최종 적용 숫자 비교
8. 같으면 무승부

구현 결과:

- `BattleCore.resolveTrickValue()`를 최종 적용 숫자 정식 계산기로 사용
- `trickValue()`와 `compareTrick()`이 같은 계산기를 사용
- 플레이어/적 모두 동일한 계산 파이프라인을 사용하며 각자 상태/필드 보정 가능
- `effectiveRank`, `effectiveSuit`, `treatedAsTrump`를 인쇄값과 분리해 추적
- 무늬 변경을 트럼프 판정보다 먼저 반영
- 트럼프 +3 뒤 기타 숫자 보정, 마지막에 상태/필드 보정을 합산
- 적용 숫자 14 초과 허용
- 쇼다운 원래값은 트릭 적용값과 분리 유지
- 브라우저 카드 상세에서 단계별 계산선을 확인 가능

## 7.5-I 칩 손패 교환 정합성 — 완료

구현 결과:

- 칩 2 소비
- 손패 카드 1장을 드로우 덱 맨 아래로 보낸 뒤 1장 드로우
- 트릭 미소비, 트릭당 최대 1회
- 드로우 덱이 비었으면 기존 버림 더미를 먼저 재순환하고 교환 카드를 맨 아래에 배치
- 교환한 카드의 같은 행동 즉시 재드로우 방지
- `세트:트릭` 키로 같은 트릭 두 번째 교환 차단
- 새 트릭/새 세트에서 다시 교환 가능
- 같은 전투의 세트 사이 칩 잔액 유지
- 전투 승리/패배 종료 시 칩과 교환 추적 상태 초기화

## 7.5-J 전투 덱 / 손패 / 세트 경계 재정렬 — 완료

구현 결과:

- 카드 레지스트리의 52개 규격 슬롯과 실제 시작 런 덱을 분리
- 기본 시작 덱 목표 12장, 설정 범위 10~14장
- 기본 손패 3장
- 1~5번째 모든 트릭에서 카드 사용 직후 손패 보충
- 5번째 트릭도 쇼다운 전에 먼저 보충
- 사용 카드는 세트 동안 쇼다운 적재 공간에 유지
- 쇼다운 종료 뒤 사용한 5장만 버림 더미로 이동
- 손패와 드로우 덱은 다음 세트에 그대로 유지
- 드로우 덱이 완전히 비었을 때만 버림 더미 재순환
- 현재 세트의 쇼다운 5장은 쇼다운 전 재순환 대상에서 제외

## 7.5-K 적 부분 정보 / 정찰 시스템 — 완료

구현 결과:

- 기본 적 카드 정확한 숫자/무늬 공개 제거
- 기본 강도 구간을 낮음 2~6 / 중간 7~10 / 높음 J~A로 통일
- 부분 예고에서 정확한 무늬 대신 현재 카드의 트럼프 여부 공개 가능
- 플레이어 카드 제출 전에는 현재 적 카드 아트를 숨김
- 플레이어 제출 확정 뒤 양측 실제 카드 공개
- 다음 적 카드 정보는 예측 수준에 따라 숨김 → 부분 → 근사 → 정확 공개로 증가
- 정찰 효과는 예측 수준과 별개로 다음 카드의 정확한 숫자와 무늬를 공개
- 정찰로 정확히 본 카드는 현재 카드가 된 뒤에도 해당 공개 기억 유지
- 적 내부 선택 근거와 플레이어 공개 인텐트를 분리
- 적 AI 전투 맥락에 플레이어 손패를 전달하지 않는 회귀 테스트 유지

완료 조건:

트릭이 완전 계산 문제도, 완전 운 게임도 되지 않는 중간 정보 구조를 가진다.

## 7.5-L 양측 쇼다운 공격 순서 재구현 — 완료

최신 피해 순서:

1. 플레이어와 적이 각각 자신의 5장으로 쇼다운 계산
2. 플레이어 쇼다운 공격을 적에게 적용
3. 적 사망 여부 확인
4. 적이 사망하면 적 쇼다운 공격 취소
5. 적이 살아 있으면 적 쇼다운 공격을 플레이어에게 적용
6. 이후 세트 종료

구현 결과:

- 플레이어/적 최종 쇼다운 위력을 각각 독립 공격값으로 사용
- `플레이어 위력 - 적 위력` 차이 피해 제거
- 플레이어 최종 위력이 더 낮아도 플레이어 공격부터 처리
- 양측 위력이 같아도 각각 자신의 위력으로 공격
- 플레이어 선공으로 적이 사망하면 적 반격 완전 취소
- 양측 공격에 별도 피해 출처 메타데이터 부여
- 기존 보호막/취약/피해 훅 경로를 각 공격이 독립적으로 통과
- 쇼다운 기록에 예정 피해, 실제 피해, 반격 취소 사유 저장
- 위력 차이 단일 피해 계산의 재유입을 정적 회귀 테스트로 차단

완료 조건:

좋은 쇼다운으로 적의 반격 자체를 끊는 것이 명확한 보상으로 작동한다.

## 7.5-M 리버 후보 / 리버 적중 전면 재작성 — 완료

최신 정의:

- 4번째 트릭 종료 시 현재 4장으로 리버 후보를 계산
- 후보는 실제 일반 52장 규격의 구체적인 숫자/무늬 카드 목록으로 스냅샷 저장
- 5번째 카드가 저장된 후보와 정확히 일치할 때만 `리버 적중`
- 리버 적중은 일반 추가 배율 +25%로 7.5-N 합산 풀에 전달

구현 결과:

- 4장 기준으로 가능한 5번째 카드 전체를 시뮬레이션해 현재 족보보다 개선되는 카드만 후보로 기록
- 후보를 최종 족보별로 그룹화해 UI용 설명 생성
- `6/7/8/9`에서는 `스트레이트 가능: 5 / 10` 표시
- 같은 무늬 4장에서는 `♥가 들어오면 플러시` 형태 표시
- 5번째 트릭 시작 직전에 리버 후보 스냅샷 고정
- 스냅샷에 세트 번호와 원본 4장 규격을 기록해 다른 세트의 낡은 후보 사용 차단
- 5번째 카드가 슬롯에 들어온 뒤 **쇼다운 전 효과보다 먼저** 후보 적중 여부 고정
- 이후 쇼다운 효과가 1~4번째 카드 또는 5번째 카드 쇼다운 값을 바꿔도 리버 여부를 재계산하지 않음
- 5번째 트릭 HUD에 리버 후보 배지 표시
- 쇼다운 기록에 리버 적중/불발 및 적중 대상 족보 기록
- 구버전 `detectRiverCompletion` / `addRiverCompletionMultiplier` 사후 판정 API 제거
- 구버전 사후 리버 판정 재유입을 회귀 테스트로 차단

완료 조건:

리버가 `마지막 카드 보너스`가 아니라 `4장 시점에서 보인 아웃을 실제로 적중시킨 보상`으로 작동한다.

## 7.5-N 배율 합산 / 상한 시스템 — 완료

최신 방식:

- 기본 배율 ×1
- 리버 +25%
- 우세 +25%
- 계약 +50% 등
- 일반 추가 배율을 모두 합산
- 합산한 최종 배율을 한 번만 적용

예:

`+25% +25% +50% = +100% → 최종 ×2.0`

구현 결과:

- 모든 일반 쇼다운 배율을 `bonus` 기반 추가 배율 데이터로 정규화
- 기존 `factor: 1.25` 입력도 호환용으로 `bonus: +0.25`로 변환
- 리버 +25%, 우세 +25%, 5전 전승 +50%를 같은 일반 추가 배율 풀에 통합
- 배율 등록 순서와 무관하게 합계를 먼저 계산하고 최종 위력에 단 한 번 적용
- 배율별 중간 반올림 및 `1.25 × 1.25 × 1.5` 연쇄 곱셈 제거
- 일반 배율 기본 상한을 공통 `×2.5`로 관리하며 breakdown 단위로 설정 가능
- 일반 풀은 상한 적용 후 확정하고, `bypassCap`이 명시된 희귀 효과만 상한 밖 추가 배율로 허용
- breakdown에 일반 추가 배율 합계, 상한 예외 합계, 원시 배율, 상한 적용 여부, 최종 배율을 기록
- UI/추적 로그에 각 출처를 `+25%` 형식으로 표시하고 합산된 `최종 ×N`을 함께 표시
- 구버전 연쇄 곱셈 계산식 재유입을 정적 회귀 테스트로 차단

완료 조건:

배율이 많이 겹쳐도 계산 순서가 결과를 바꾸지 않고, 일반 고점이 예측 가능한 상한 안에서 작동한다.

## 7.5-O 트럼프 연동 필드 리워크 — 완료

최신 필드:

- 과충전 구역: 트럼프 +3 → +5
- 감쇠 지대: 트럼프 +3 → +1
- 무법지대: 트럼프 무늬는 유지하되 트릭 보너스 0
- 좁은 테이블: 기본 최대 손패 -1
- 뒤집힌 세계: 낮은 최종 적용 숫자가 승리

구현 결과:

- O 전용 필드 규칙 계층을 H의 `resolveTrickValue()` / `compareTrick()` 정식 파이프라인에 연결
- 기본 트럼프 보너스는 `BattleCore.DEFAULT_TRUMP_BONUS`의 +3을 중앙 기준으로 사용
- 과충전/감쇠/무법 필드가 같은 파이프라인의 트럼프 보너스만 +5/+1/0으로 덮어씀
- 플레이어와 적이 동일한 필드 트럼프 보너스를 대칭 적용
- 필드 교체/해제 시 새 필드 값 또는 기본 +3으로 즉시 복원
- 좁은 테이블은 기본 최대 손패를 3→2로 낮추고 초과 손패를 드로우 덱 위로 반환
- 다음 트릭 한정 손패 증가 같은 임시 효과는 필드가 조정한 기본치 위에서 정상 합산
- 뒤집힌 세계는 트럼프 여부 분기를 만들지 않고 모든 보정이 끝난 최종 적용 숫자 비교만 반전
- 뒤집힌 세계에서도 같은 최종 적용 숫자는 정확히 무승부 0으로 유지
- 브라우저 트럼프 HUD, 카드 상세 계산선, 용어 설명이 현재 필드의 +5/+1/0을 같은 값으로 표시
- 기존 `resonance_floor` / `thin_signal` / `inversion_zone` 내부 ID는 그대로 재사용해 기존 런 필드 보유/예약 상태와 호환
- O 최신 필드 레지스트리에서는 `advantageMargin`, `showdownAdvantagePower` 같은 자동 우세 의존 규칙을 사용하지 않음
- 저장 호환용으로 남은 구식 우세 내부 코드/테스트와 상시 우세 기반 콘텐츠의 물리적 제거는 7.5-P에서 수행

완료 조건:

필드가 트럼프의 숫자 보너스와 최종 비교 규칙을 명시적으로 바꾸되, 트럼프 자동 승리나 상시 무늬 우세를 다시 만들지 않는다.

## 7.5-P 구식 우세 / 콘텐츠 / 순수 카드 정리 — 완료

구현 결과:

- `SHOWDOWN_ADVANTAGE_POWER +3` 상수와 자동 무늬 장수 비교 우세 계산을 `BattleCore`에서 제거
- `advantage_count_at_least`, 우세 무늬 목록/개수, 별도 `on_showdown_advantage` 점수 경로를 활성 효과 엔진에서 제거
- 명시적으로 획득한 우세만 이번 쇼다운 일반 추가 배율 `+25%`로 7.5-N 합산 풀에 등록
- 계약 `날 선 서약`, 금기 `열세 금기`, 시너지 `우세 장부`를 무늬 개수가 아니라 명시적 우세 활성 여부로 판정
- `더블다운`은 복수 우세 무늬 대신 이번 세트 트릭 3승 이상에서 쇼다운 위력 +6으로 재설계
- `기본에 충실`은 손패의 순수 카드, `무첨가`는 쇼다운 슬롯의 순수 카드를 직접 참조하는 연계 카드로 재설계
- Cards / Effects / DeckBoundaries의 순수 카드 판정을 하나의 의미로 통일
- 52개 표준 카드 규격 슬롯은 그대로 유지하고, 현재 기본 풀은 일반 효과 카드 12장 + 순수 카드 40장으로 분류
- 기본 12장 시작 덱은 최소 2장의 순수 카드를 보존해 네임드/효과 카드만으로 자동 압축되지 않도록 보장
- 재설계된 3장(`더블다운`, `기본에 충실`, `무첨가`)의 마이그레이션 단계를 `7.5-P`로 갱신
- 구식 자동 우세 식별자와 순수 카드 분류 회귀를 P 전용 정적/동작 테스트로 차단

완료 조건:

우세는 오직 명시적 조건부 +25% 추가 배율 상태로만 작동하고, 순수 카드는 시작 덱과 카드 시너지에서 실제 전략 자원으로 남는다.

## 7.5-Q 압승 / 고점 연출

압승 후보:

- 적 남은 체력의 150% 이상 피해 → 압승
- 200% 이상 → 대압승

주목적:

- 큰 피해 낭비감 감소
- 고점 달성 피드백 강화

보상은 소규모로 제한한다.

연출 순서 후보:

1. 쇼다운 5장 확정
2. 족보 표시
3. 리버 후보 적중 표시
4. 덧셈 보너스 표시
5. 우세/계약 등 추가 배율 표시
6. 합산된 최종 배율 표시
7. 플레이어 쇼다운 피해
8. 적 사망 여부
9. 생존 시 적 쇼다운 공격
10. 압승/대압승 마무리

## 7.5-R 최신 규칙 최종 회귀 / 금지 규칙 가드

저장 시스템으로 넘어가기 전에 최신 규칙을 자동 테스트로 고정한다.

### 카드 / 덱

- 모든 플레이 카드가 ♠/♥/♦/♣ + 2~A 규격
- 특수 인쇄 랭크/무늬 없음
- 순수 카드 실제 존재
- 시작 덱 10~14장 설정 가능, 기본 테스트값 약 12
- 별도 전술 카드 시스템 없음

### 트릭

- 기본 손패 3장
- 5트릭 = 1세트
- 세트마다 새 트럼프 공개
- 트럼프는 자동 승리권이 아님
- 트럼프는 기본 적용 숫자 +3
- 무늬 변경 뒤 트럼프 판정
- 최종 적용 숫자만 승패에 사용
- 적용 숫자 14 초과 가능
- 동률 무승부

### 칩

- 승리 시 칩 +1
- 기본 최대 5
- 2칩 손패 교환
- 교환 카드는 드로우 덱 맨 아래
- 트릭당 최대 1회
- 세트 사이 칩 유지
- 전투 종료 초기화

### 손패 / 세트 경계

- 사용한 5장만 쇼다운 종료 후 버림 더미
- 손패는 다음 세트까지 유지
- 드로우 덱도 유지
- 덱이 빌 때만 버림 더미 셔플

### 적 정보

- 기본은 부분 예고
- 카드 선택 전 정확한 적 카드 자동 공개 금지
- 정찰/예측으로만 정확 정보 추가 공개

### 쇼다운

- 원래값 중심 포커 족보
- 플레이어/적 쇼다운 독립 계산
- 플레이어 공격 먼저
- 적 사망 시 적 공격 없음
- 자동 상시 우세 없음
- 명시적 우세만 +25% 추가 배율
- 4장 시점 리버 후보를 5번째 카드로 맞혀야 리버 적중
- 일반 배율은 합산 후 1회 적용
- 일반 배율 기본 상한 ×2.5
- 명시적 희귀 상한 예외만 일반 상한 초과 가능
- 연쇄 곱셈 금지

### 필드

- 필드 없음이 기본
- 특정 출처에서만 생성
- 트럼프 보너스를 0/+1/+5 등으로 조정 가능

### 금지 규칙 정적 검사

- `한쪽만 트럼프면 즉시 승리` 코드 금지
- 자동 무늬 장수 우세 코드 금지
- 전술 덱/전술 손패 런타임 금지
- 특수 수트/랭크 기본 카드 금지
