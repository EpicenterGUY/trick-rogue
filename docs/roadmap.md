# 7.5 최신 통합 규칙 재정렬

## 목적

7단계까지 만든 기반 위에서 저장 시스템으로 넘어가기 전에, 2026-08-23 최신 통합 규칙과 충돌하는 기존 핵심 전투 규칙을 먼저 정리한다.

저장/직렬화를 먼저 구현하면 폐기할 규칙까지 저장 포맷에 굳어질 수 있으므로 **8단계보다 7.5를 우선**한다.

쇼다운의 목표는 상시 우세 계산을 제거하면서도 `족보 + 덧셈 시너지 + 희귀 배율 + 압승 연출`로 기존보다 더 강한 폭딜 쾌감을 만드는 것이다.

## 7.5-A 상시 쇼다운 우세 제거 + 희귀 우세 상태 전환

기본 전투 규칙에서 기존 무늬 수 비교 기반 상시 쇼다운 우세를 제거하고, 우세를 명시적 조건으로만 얻는 희귀 폭딜 상태로 재정의한다.

해야 할 일:

- 기본 쇼다운에서 무늬 수 비교로 우세를 자동 계산하지 않음
- 기본 우세 +3 같은 상시 위력 보너스 제거
- `on_showdown_advantage` 등 기존 우세 전용 경로를 기본 쇼다운 필수 단계에서 분리
- 우세가 필요한 카드/유물/보스/필드/계약만 명시적 조건으로 우세를 생성
- 우세 기본 권장 효과를 `이번 쇼다운 최종 위력 ×1.25`로 구현
- 쇼다운 종료 후 우세 제거
- 기존 우세 기반 계약/시너지/필드 효과는 최신 의미에 맞춰 리워크 또는 비활성화
- 트럼프와 우세를 완전히 별개 개념으로 유지

우세 획득 후보:

- 3트릭 연속 승리
- 5번째 트릭 승리
- 첫 2트릭 패배 후 이후 3트릭 전승
- 특정 열세 조건 극복

완료 조건:

- 우세 빌드를 전혀 사용하지 않는 런은 우세 시스템을 의식하지 않아도 됨
- 자동 무늬 비교가 쇼다운에 존재하지 않음
- 명시적 우세를 얻은 경우에만 최종 배율이 적용됨
- 우세는 해당 쇼다운 뒤 정상 제거됨

## 7.5-B 칩 기본 루프 확정

기본 전투 루프에 칩의 공용 역할을 명확하게 넣는다.

기준:

- 트릭 승리 시 칩 +1
- 기본 최대 칩 5
- 칩은 같은 전투에서 세트가 넘어가도 유지
- 전투 종료 시 초기화
- 런 화폐와 별개

공용 행동 `손패 교환`:

- 칩 2 소비
- 손패 카드 1장을 덱 맨 아래로 보냄
- 카드 1장 드로우
- 트릭 미소비
- 트릭당 최대 1회

완료 조건:

`트릭 승리 → 칩 획득 → 손패 조정 → 더 나은 쇼다운 준비` 순환이 기본 규칙만으로 성립해야 한다.

## 7.5-C 쇼다운 처리 / 폭딜 계산 구조 재정렬

최신 기본 순서:

1. 쇼다운 5장 확정
2. 쇼다운 전 카드 효과
3. 슬롯 / 숫자 / 무늬 변경
4. 포커 족보 판정 및 족보 기본 위력 생성
5. 카드 효과 / 상태 / 계약 / 조건의 덧셈 보너스 정산
6. 리버 완성 / 우세 / 전승 / 고난도 계약 등 희귀 배율 판정
7. 최종 위력 계산
8. 피해
9. 압승/대압승 판정
10. 세트 종료 효과
11. 적 생존 시 다음 세트

해야 할 일:

- 기존 구현에서 우세 판정이 족보와 쇼다운 효과 사이에 강제되어 있으면 제거/재배치
- 족보마다 기본 위력을 갖는 구조 마련
- 대부분의 카드/상태/계약 보너스는 덧셈으로 통합
- 배율은 별도 단계에서만 적용
- 적용된 덧셈과 배율을 결과 모델에서 각각 추적
- 최종 피해가 왜 해당 숫자가 되었는지 UI가 설명할 수 있는 breakdown 생성

밸런스 테스트용 족보 위력 후보:

- 하이카드 5
- 페어 10
- 투페어 14
- 트리플 18
- 스트레이트 24
- 플러시 26
- 풀하우스 32
- 포카드 42
- 스트레이트 플러시 60

위 수치는 확정값이 아니며 플레이테스트 대상이다.

완료 조건:

- 포커 족보 판정 전 쇼다운 전용 조작이 가능
- 족보 판정 이후 덧셈 정산이 가능
- 덧셈 정산 이후 희귀 배율이 적용됨
- 상시 우세 단계가 없어도 전체 쇼다운이 정상 작동
- 최종 위력 breakdown을 프로그램적으로 조회 가능

## 7.5-D 리버 완성 / 트릭 고점 배율

쇼다운의 마지막 한 장과 좋은 트릭 성적에 선택적 고점을 추가한다.

### 리버 완성

- 4장 시점에는 없던 포커 족보가 5번째 카드로 처음 완성되면 발동
- 권장 기본 효과: 최종 위력 ×1.25
- 5번째 트릭의 긴장감과 마지막 한 장의 완성 쾌감을 강화

### 트릭 성적

- 기본 보상은 여전히 승리당 칩 +1
- 3승/4승은 소규모 덧셈 보너스 후보
- 5전 전승은 고점 보상으로 최종 위력 ×1.5 후보
- 트릭 성적이 족보보다 항상 우선되는 밸런스는 금지

### 배율 사용 원칙

- 리버 완성: ×1.25
- 우세: ×1.25
- 어려운 계약 성공: ×1.25~1.5
- 5전 전승: ×1.5
- 극히 어려운 특수 조건: ×2

대부분의 일반 효과는 `+3 / +5 / +8` 같은 덧셈으로 유지한다.

완료 조건:

- 리버 완성을 4장 상태와 5장 상태 비교로 정확히 판정
- 리버 완성이 아닌 기존 족보 유지/단순 상향과 구분
- 여러 배율이 겹쳐도 적용 근거와 순서를 추적 가능
- 전승 배율은 명시적 고점 조건에서만 발생

## 7.5-E 일반전/장기전 템포 정리

최신 전투 길이 목표:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

해야 할 일:

- 일반 적 체력을 첫 쇼다운 처치가 가능한 수준으로 재조정
- 일반 적 난이도는 체력보다 간단한 기믹으로 차별화
- 엘리트/보스만 여러 세트가 특별하게 느껴지도록 조정
- `5트릭 = 전투 종료` 같은 잔여 가정을 모두 제거
- 적 생존 시 다음 세트로 자연스럽게 넘어가는 흐름 검증
- 평범한 쇼다운 10~30, 잘 풀린 쇼다운 30~50, 강한 시너지 50~80, 고점 100+가 체감되도록 적 HP와 위력 곡선 함께 조정

완료 조건:

- 일반전이 불필요하게 2~3세트로 늘어지지 않음
- 엘리트/보스에서는 장기전 빌드가 실제로 작동할 시간 확보
- 높은 족보/배율이 터졌을 때 일반 적을 확실히 압도하는 감각이 있음

## 7.5-F 필드 역할 재정리

최신 기준에서는 필드가 기본적으로 항상 존재하지 않는다.

해야 할 일:

- 모든 조우가 자동으로 필드를 가진다는 가정 제거
- 필드는 카드/보스/엘리트/이벤트 등 특정 출처가 만들 때만 존재
- 기존 런 보유 필드 구조는 최신 기준에 맞춰 `특수 룰 생성/활성` 개념으로 재검토
- 필드가 없을 때는 완전한 기본 전투 규칙이 작동해야 함

완료 조건:

- 필드 없음이 정상 상태
- 필드가 등장하면 룰이 바뀌는 특별한 상황으로 느껴짐

## 7.5-G 카드/콘텐츠 명칭 및 잔여 레거시 정리

규칙 변경으로 의미가 어긋난 기존 콘텐츠를 정리한다.

우선 검토 대상:

- 상시 우세를 전제로 한 카드/계약/시너지
- 기존 `우세 무늬 수`를 직접 참조하는 효과
- 기본 우세 +3을 전제로 한 위력 수치
- 전술 카드 드로우/전술 손패 같은 구버전 표현
- 카드명 후보
  - 검은 탄환 → 철갑탄
  - 비열한 승부사 → 야바위꾼
  - 날 선 유리 → 유리파편
  - 매복한 관측자 → 감시자
  - 응급 보호구 → 비상방패

이름 변경은 ID를 함부로 바꾸지 않고 표시 이름 중심으로 진행한다.

## 7.5-H 압승 / 쇼다운 폭딜 연출

큰 피해가 초반 일반 적에게 낭비되는 느낌을 줄이고 쇼다운의 성취감을 강화한다.

### 압승 판정 후보

- 적 남은 체력의 150% 이상 피해: 압승
- 적 남은 체력의 200% 이상 피해: 대압승

보상은 소규모로 제한한다.

후보:

- 소량 추가 골드
- 보상 선택지 소폭 개선
- 다음 전투 작은 보너스
- 기타 소규모 런 보상

### 쇼다운 연출 순서

1. 카드 5장 순차 점등
2. 족보 이름 크게 표시
3. 리버 완성 표시
4. 덧셈 보너스 표시
5. 우세/계약/전승 등의 배율 표시
6. 최종 피해 숫자 강조
7. 적 체력바 급감
8. 피해량 단계별 화면 흔들림/타격음
9. 압승/대압승 별도 마무리

완료 조건:

- 플레이어가 큰 피해 원인을 화면만 보고 이해 가능
- 평범한 쇼다운과 고점 쇼다운의 연출 강도가 명확히 다름
- 압승은 밸런스 핵심 보상이 아니라 성취감 보강 역할을 함

## 7.5-I 규칙 회귀 테스트

다음 항목을 자동 테스트로 고정한다.

- 기본 손패 3장
- 모든 플레이 카드가 ♠/♥/♦/♣ + 2~A 규격
- 5트릭 = 1세트
- 세트마다 새 트럼프 공개
- 트럼프는 트릭 판정에만 기본 영향
- 트릭 승리 시 칩 +1
- 칩 2 손패 교환
- 전투 중 세트 사이 칩 유지 / 전투 종료 초기화
- 쇼다운 족보는 기본적으로 원래 값 사용
- 상시 쇼다운 우세 없음
- 자동 무늬 비교로 우세를 만들지 않음
- 우세는 명시적 효과가 만들 때만 존재
- 우세는 기본적으로 해당 쇼다운 최종 위력 ×1.25 후 제거
- 리버 완성은 5번째 카드로 새 족보가 완성될 때만 판정
- 덧셈 보너스 후 희귀 배율을 적용
- 5전 전승 등 배율 조건은 명시적으로만 발생
- 압승/대압승은 적 남은 HP 대비 실제 최종 피해로 판정
- 별도 전술 카드 시스템 없음
- 필드 없음이 정상 전투 상태
- 적 생존 시 다음 세트 가능
