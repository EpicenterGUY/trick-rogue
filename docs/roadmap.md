# 트릭로그 개발 이정표

최신 규칙 기준 문서: [`docs/tricklog-latest-rules.md`](./tricklog-latest-rules.md)

과거 구현/설계와 최신 규칙이 충돌하면 최신 규칙 문서를 우선한다.

## 절대 되살리지 않는 구버전 규칙

- 트럼프 무조건 승리
- 자동 무늬 비교 기반 상시 우세
- 별도 전술 카드 시스템
- 특수 숫자 / 특수 무늬 기본 카드

# 7.5 최신 통합 규칙 재정렬

## 현재 상태

- 7.5-A 완료: 상시 쇼다운 우세 제거 + 명시적 우세 기반
- 7.5-B 기반 완료: 트릭 승리 칩 +1 / 기본 최대 5 / 공용 손패 교환 기반
- 7.5-C 기반 완료: 족보 기본 위력 → 덧셈 → 배율 → 피해 계산 뼈대
- 7.5-D 구버전 구현 완료: 5번째 카드 기반 리버 판정. **최신 규칙에 따라 7.5-M에서 교체 예정**
- 7.5-E 완료: 일반전/엘리트/보스 체력 및 세트 템포
- 7.5-F 완료: 필드 없음 기본화 / 명시적 출처 기반 필드 생성
- 7.5-G 완료: 트럼프 자동 승리 폐기 / 트럼프 적용 숫자 +3
- 7.5-H 완료: 무늬 변경 → 트럼프 → 숫자 → 상태/필드 → 최종 적용값 단일 계산 파이프라인
- 7.5-I 완료: 2칩 손패 교환 / 드로우 덱 맨 아래 반환 / 트릭당 1회 / 전투 종료 초기화
- 7.5-J 완료: 실제 시작 덱 10~12장 / 5번째 트릭 포함 즉시 손패 보충 / 쇼다운 5장만 버림 / 손패·드로우 덱 세트 유지
- **다음 작업: 7.5-K 적 부분 정보 / 정찰 시스템**

## 기존 단계 중 유지되는 기준

### 7.5-A 우세

- 자동 무늬 비교로 우세 생성 금지
- 우세는 특정 조건으로만 획득
- 최신 의미는 `이번 쇼다운 추가 배율 +25%`
- 쇼다운 종료 후 제거
- 트럼프와 우세는 별개

### 7.5-B 칩

- 트릭 승리 시 칩 +1
- 무승부/패배 기본 칩 없음
- 기본 최대 칩 5
- 같은 전투에서는 세트 사이 유지
- 전투 종료 시 초기화
- 런 화폐와 별개

### 7.5-C 쇼다운 기본 위력 뼈대

테스트용 족보 위력:

- 하이카드 5
- 페어 10
- 투페어 14
- 트리플 18
- 스트레이트 24
- 플러시 26
- 풀하우스 32
- 포카드 42
- 스트레이트 플러시 60

구조 자체는 유지하되, **배율 중첩 방식과 양측 피해 순서는 최신 규칙에 맞춰 다시 구현한다.**

### 7.5-E 전투 템포

목표:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

현재 테스트용 HP 곡선:

- 초반 일반전 24
- 강한 일반전 36
- 엘리트 64
- 보스 120

피해 체감 목표:

- 평범한 쇼다운 10~30
- 잘 풀린 쇼다운 30~50
- 강한 시너지 50~80
- 고점 100+

### 7.5-F 필드 존재 방식

- 필드 없음이 정상 전투 상태
- 일반/엘리트/보스 모두 자동 기본 필드 없음
- 카드/적/엘리트/보스/이벤트 등 명시적 출처가 있을 때만 필드 생성
- 필드와 적 고유 규칙/보스 페이즈는 별도

### 7.5-G 트럼프 +3 — 완료

- `트럼프면 자동 승리` 제거
- 현재 트럼프 무늬는 트릭 적용 숫자 +3
- 적용 숫자는 14 초과 가능
- 플레이어와 적에 대칭 적용
- 쇼다운 원래값에는 트럼프 +3이 남지 않음

# 신규 보완 이정표

## 7.5-H 최종 적용값 계산 파이프라인 고정 — 완료

7.5-G에서 구현한 트럼프 +3을 최신 규칙의 정확한 보정 순서로 통합했다.

정식 트릭 계산 순서:

1. 원래 숫자 / 원래 무늬 확인
2. 카드 효과에 의한 무늬 변경
3. 최종 무늬로 트럼프 여부 판정
4. 트럼프라면 적용 숫자 +3
5. 기타 숫자 변화 효과
6. 상태 / 필드 보정
7. 최종 적용 숫자 비교
8. 같으면 무승부

구현 결과:

- `BattleCore.resolveTrickValue()`를 최종 적용 숫자 정식 계산기로 사용
- `trickValue()`와 `compareTrick()`이 같은 계산기를 사용
- 플레이어/적 모두 동일한 계산 파이프라인을 사용하며 각자 상태/필드 보정 가능
- `effectiveRank`, `effectiveSuit`, `treatedAsTrump`를 인쇄값과 분리해 추적
- 무늬 변경을 트럼프 판정보다 먼저 반영
- 트럼프 +3 뒤 기타 숫자 보정, 마지막에 상태/필드 보정을 합산
- 적용 숫자 14 초과 허용
- 쇼다운 원래값은 트릭 적용값과 분리 유지
- 브라우저 카드 상세에서 `원래값 → 무늬 → 트럼프 → 숫자 → 상태/필드 → 최종값` 계산선을 확인 가능

완료 조건:

- 실제 승패가 단 하나의 최종 적용 숫자 계산 함수에서 결정됨
- 트럼프 우선 분기나 별도 예외 비교가 없음

## 7.5-I 칩 손패 교환 정합성 — 완료

최신 공용 행동:

- 칩 2 소비
- 손패 카드 1장을 **드로우 덱 맨 아래**로 보냄
- 그 후 카드 1장 드로우
- 트릭 미소비
- 트릭당 최대 1회

구현 결과:

- 드로우 덱 방향을 `맨 위 = 배열 끝(pop)`, `맨 아래 = 배열 시작(unshift)`로 통일
- 선택한 손패 카드는 버림 더미가 아니라 드로우 덱 맨 아래로 이동
- 드로우 덱이 비었으면 기존 버림 더미를 먼저 재순환한 뒤 교환 카드를 맨 아래에 배치하고 위에서 1장 드로우
- 교환한 카드가 같은 행동에서 즉시 다시 뽑히지 않도록 순서를 고정
- `세트:트릭` 키로 같은 트릭의 두 번째 교환을 차단
- 새 트릭 또는 새 세트가 되면 별도 수동 초기화 없이 다시 교환 가능
- 손패 교환은 트릭 번호를 진행시키지 않음
- 칩 잔액은 같은 전투의 세트 사이에서 유지
- 전투 승리/패배 종료 시 칩 잔액과 교환 추적 상태를 0으로 초기화
- 교환 버튼 설명도 `덱 맨 아래 반환 / 트릭당 1회` 기준으로 갱신

완료 조건:

`트릭 승리 → 칩 획득 → 손패 조절 → 쇼다운 족보 개선` 순환이 코드와 UI에서 동일하게 동작한다.

## 7.5-J 전투 덱 / 손패 / 세트 경계 재정렬 — 완료

최신 기준은 `52장 카드 규격`과 실제 런에서 사용하는 시작 덱을 구분한다.

고정 기준:

- 모든 카드의 가능한 규격은 일반 52장
- 실제 시작 전투 덱은 약 10~14장으로 테스트
- 초기 권장값은 12장 전후
- 기본 손패 3장

구현 결과:

- 카드 레지스트리의 52개 슬롯은 그대로 유지하고 실제 시작 런 덱만 별도로 축소
- 기본 시작 덱 목표를 12장으로 두고 캐릭터 압축값에 따라 12/11/10장으로 시작
- 캐릭터 고유 네임드를 우선 보존하고 최소 2장의 효과 없는 일반 카드를 시작 덱에 유지
- 전투 시작 시 실제 런 덱을 셔플한 뒤 기본 손패 3장을 사용
- 1~5번째 모든 트릭에서 카드를 낸 직후 손패를 최대치까지 보충
- **5번째 트릭도 쇼다운 처리 전에 먼저 손패 보충**
- 사용한 카드는 즉시 버리지 않고 현재 세트의 쇼다운 적재 공간에 유지
- 쇼다운 종료 뒤 해당 세트에서 사용한 5장만 버린 카드 더미로 이동
- 손패는 다음 세트까지 그대로 유지하고 세트 시작 전체 재드로우를 하지 않음
- 드로우 덱도 세트 사이 그대로 유지
- 드로우 덱이 완전히 비었을 때만 기존 버린 카드 더미를 셔플해 재순환
- 아직 쇼다운이 끝나지 않은 현재 세트의 5장은 재순환 대상에서 제외
- 브라우저 부트스트랩에서 7.5-J 경계 런타임을 전투 템포 뒤, 최종 전투 레이아웃 전에 연결

완료 조건:

`이 카드를 다음 세트까지 들고 갈 것인가?`가 실제 손패·드로우 덱 흐름에서 전략으로 작동한다.

## 7.5-K 적 부분 정보 / 정찰 시스템

기본 적 카드 완전 공개를 폐지하고 부분 예고를 기본으로 한다.

기본 예고 후보:

- 낮음: 2~6
- 중간: 7~10
- 높음: J~A
- 현재 카드가 트럼프인지 여부

해야 할 일:

- 적 내부 선택 카드와 플레이어 공개 정보 모델 분리
- 기본 UI에서 정확한 숫자/무늬를 숨김
- 카드 선택 확정 뒤 양측 실제 카드 공개
- 정찰/예측 효과만 정확한 숫자와 무늬를 확인 가능
- 기존 `정찰` 카드가 새 공개 단계와 정확히 연결되도록 조정
- 적 AI가 플레이어 손패 같은 비공개 정보를 읽지 않게 회귀 테스트 유지

완료 조건:

트릭이 완전 계산 문제도, 완전 운 게임도 되지 않는 중간 정보 구조를 가져야 한다.

## 7.5-L 양측 쇼다운 공격 순서 재구현

현재의 `플레이어 위력 - 적 위력 차이만 피해` 계열 구현이 있다면 최신 규칙과 충돌한다.

최신 피해 순서:

1. 플레이어와 적이 각각 자신의 5장으로 쇼다운 계산
2. 플레이어 쇼다운 피해를 적에게 적용
3. 적 사망 여부 확인
4. 적이 사망하면 적 쇼다운 공격 취소
5. 적이 살아 있으면 적 쇼다운 피해를 플레이어에게 적용
6. 이후 세트 종료

해야 할 일:

- 플레이어/적 쇼다운 위력을 독립적인 공격값으로 계산
- 두 위력의 차이를 피해로 쓰는 기본 규칙 제거
- 보호막/취약/피해 훅이 각 공격에 독립 적용되도록 보장
- 플레이어 선공으로 적 처치 시 적 공격 완전 취소
- 동시 사망 기본 상황 제거

완료 조건:

좋은 쇼다운으로 `적의 반격 자체를 끊는 것`이 명확한 보상이 되어야 한다.

## 7.5-M 리버 후보 / 리버 적중 전면 재작성

기존 `5번째 카드로 이전보다 높은 족보가 생기면 리버` 구현은 폐기한다.

최신 정의:

- 4번째 트릭 종료 시 현재 4장으로 리버 후보를 계산
- 5번째 카드가 그 후보 조건을 실제로 만족시킬 때만 `리버 적중`
- 리버 적중은 일반 추가 배율 +25%

예:

- 6/7/8/9 → 5 또는 10
- ♥ 4장 → ♥ 카드

해야 할 일:

- 4장 시점에서 후보 조건 스냅샷 저장
- 5번째 카드 판정 때 새로 후보를 재계산하지 않음
- 후보를 랭크/무늬/족보 조건으로 표현할 수 있는 데이터 모델 설계
- UI에 `스트레이트 가능: 5 / 10`, `♥가 들어오면 플러시` 식으로 표시
- 5번째 카드가 단순히 족보를 만들었다는 이유만으로 리버 처리 금지

완료 조건:

리버가 `마지막 카드 보너스`가 아니라 `4장 시점에서 보인 아웃을 실제로 적중시킨 보상`이어야 한다.

## 7.5-N 배율 합산 / 상한 시스템

기존 희귀 배율의 연쇄 곱셈을 최신 규칙에 맞춰 교체한다.

최신 방식:

- 기본 배율 ×1
- 리버 +25%
- 우세 +25%
- 계약 +50% 등
- 일반 추가 배율을 모두 합산
- 최종 배율을 한 번만 적용

예:

`+25% +25% +50% = +100% → 최종 ×2.0`

금지:

`1.25 × 1.25 × 1.5`

해야 할 일:

- 모든 일반 배율을 `추가 배율` 데이터로 통일
- 배율 출처별 breakdown 제공
- 일반 배율 상한을 공통 상수/설정으로 관리
- 초기 테스트 상한은 ×2.5로 두되 ×2.0~×2.5 범위에서 조정 가능하게 설계
- 상한 초과가 허용되는 희귀 효과는 명시적인 예외 플래그 필요
- 기존 5전 전승 같은 고점 효과를 유지한다면 `기본 규칙`이 아니라 명시적 조건부 효과로 취급하고 추가 배율 풀에 넣음

완료 조건:

배율이 많이 겹쳐도 계산이 예측 가능하고 폭주하지 않아야 한다.

## 7.5-O 트럼프 연동 필드 리워크

7.5-F에서 필드의 존재 방식은 정리했지만 내용은 최신 트럼프 구조에 맞춰 다시 다듬는다.

기준 필드 후보:

- 과충전 구역: 트럼프 +3 → +5
- 감쇠 지대: 트럼프 +3 → +1
- 무법지대: 이번 세트 트럼프 보너스 0
- 좁은 테이블: 최대 손패 -1
- 뒤집힌 세계: 특정 조건에서 낮은 최종 적용 숫자가 승리

해야 할 일:

- `공명 바닥`, `희박 신호` 등 구식 자동 우세 의존 필드 제거/리워크
- 필드가 트럼프 보너스 값을 명시적으로 덮어쓸 수 있는 공통 규칙 추가
- 기본 트럼프 보너스 +3을 중앙 값으로 관리
- 필드 종료/교체 시 기본값 복원
- 낮은 숫자 승리도 `최종 적용 숫자`를 뒤집는 방식으로만 구현

## 7.5-P 구식 우세 / 콘텐츠 / 순수 카드 정리

규칙 변경으로 의미가 어긋난 콘텐츠를 정리한다.

우선 대상:

- `우세 무늬 수`, `advantage_count` 같은 자동 우세 잔재
- `SHOWDOWN_ADVANTAGE_POWER +3` 같은 구식 기본 우세 코드
- 자동 무늬 비교 우세 함수/테스트
- 상시 우세를 전제로 한 계약/유물/시너지
- 트럼프 자동 승리를 전제로 한 카드/적 행동
- 전술 덱/전술 손패/전술 드로우 표현
- 특수 숫자 / 특수 무늬 기본 카드 정의

순수 카드 원칙:

- 효과 없는 일반 카드를 실제 덱에 유지
- 순수 카드 전용 시너지 가능
- 네임드 카드만 많은 덱이 자동 최적해가 되지 않게 함
- 네임드도 항상 일반 52장 숫자/무늬를 가짐

표시 이름 변경은 ID 마이그레이션과 분리하여 진행한다.

## 7.5-Q 압승 / 고점 연출

압승 후보:

- 적 남은 체력의 150% 이상 피해 → 압승
- 200% 이상 → 대압승

주목적:

- 큰 피해 낭비감 감소
- 고점 달성 피드백 강화

보상은 소규모로 제한한다.

연출 순서 후보:

1. 쇼다운 5장 확정
2. 족보 표시
3. 리버 후보 적중 표시
4. 덧셈 보너스 표시
5. 우세/계약 등 추가 배율 표시
6. 합산된 최종 배율 표시
7. 플레이어 쇼다운 피해
8. 적 사망 여부
9. 생존 시 적 쇼다운 공격
10. 압승/대압승 마무리

## 7.5-R 최신 규칙 최종 회귀 / 금지 규칙 가드

저장 시스템으로 넘어가기 전에 최신 규칙을 자동 테스트로 고정한다.

### 카드 / 덱

- 모든 플레이 카드가 ♠/♥/♦/♣ + 2~A 규격
- 특수 인쇄 랭크/무늬 없음
- 순수 카드 실제 존재
- 시작 덱 10~14장 설정 가능, 기본 테스트값 약 12
- 별도 전술 카드 시스템 없음

### 트릭

- 기본 손패 3장
- 5트릭 = 1세트
- 세트마다 새 트럼프 공개
- 트럼프는 자동 승리권이 아님
- 트럼프는 기본 적용 숫자 +3
- 무늬 변경 뒤 트럼프 판정
- 최종 적용 숫자만 승패에 사용
- 적용 숫자 14 초과 가능
- 동률 무승부

### 칩

- 승리 시 칩 +1
- 기본 최대 5
- 2칩 손패 교환
- 교환 카드는 드로우 덱 맨 아래
- 트릭당 최대 1회
- 세트 사이 칩 유지
- 전투 종료 초기화

### 손패 / 세트 경계

- 사용한 5장만 쇼다운 종료 후 버림 더미
- 손패는 다음 세트까지 유지
- 드로우 덱도 유지
- 덱이 빌 때만 버림 더미 셔플

### 적 정보

- 기본은 부분 예고
- 카드 선택 전 정확한 적 카드 자동 공개 금지
- 정찰/예측으로만 정확 정보 추가 공개

### 쇼다운

- 원래값 중심 포커 족보
- 플레이어/적 쇼다운 독립 계산
- 플레이어 공격 먼저
- 적 사망 시 적 공격 없음
- 자동 상시 우세 없음
- 명시적 우세만 +25% 추가 배율
- 4장 시점 리버 후보를 5번째 카드로 맞혀야 리버 적중
- 일반 배율은 합산 후 1회 적용
- 연쇄 곱셈 금지

### 필드

- 필드 없음이 기본
- 특정 출처에서만 생성
- 트럼프 보너스를 0/+1/+5 등으로 조정 가능

### 금지 규칙 정적 검사

- `한쪽만 트럼프면 즉시 승리` 코드 금지
- 자동 무늬 장수 우세 코드 금지
- 전술 덱/전술 손패 런타임 금지
- 특수 수트/랭크 기본 카드 금지
