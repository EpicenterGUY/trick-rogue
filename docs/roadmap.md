# 트릭로그 개발 이정표

최신 규칙 기준 문서: [`docs/tricklog-latest-rules.md`](./tricklog-latest-rules.md)

과거 구현/설계와 최신 규칙이 충돌하면 최신 규칙 문서를 우선한다.

## 완료된 큰 단계

- 0: 프로토타입
- 1: 핵심 전투 기반
- 1.5: 초기 규칙 정합성 정리
- 2: 공통 효과 엔진
- 3: 별도 전술 카드 시스템 제거 및 일반 카드 효과로 통합
- 4: 적 행동 시스템
- 5: 엘리트/보스/필드 기반
- 6: 유물/상태/계약·금기/빌드 시너지
- 7: 런 구조/경로 잠금/맵 생성/액트 전환/런 결과

# 7.5 최신 통합 규칙 재정렬

## 현재 상태

- 7.5-A 완료: 상시 쇼다운 우세 제거 + 명시적 우세 ×1.25
- 7.5-B 완료: 트릭 승리 칩 +1 / 최대 5 / 공용 손패 교환 기반
- 7.5-C 완료: 포커 기본 위력 → 덧셈 → 희귀 배율 → 피해 계산 구조
- 7.5-D 완료: 리버 완성 ×1.25 / 5전 전승 ×1.5
- 7.5-E 완료: 일반전/엘리트/보스 체력 및 세트 템포
- 7.5-F 완료: 필드 없음 기본화 / 명시적 출처 기반 필드 생성
- **다음 작업: 7.5-G 트럼프 +3 전면 개편**

2026-08-23 신규 통합 규칙에서 트럼프가 다시 개편되었다. 기존 `트럼프가 비트럼프를 무조건 이김` 규칙은 폐기하고, **현재 트럼프 무늬 카드의 트릭 적용 숫자 +3**으로 통일한다.

저장/직렬화로 넘어가기 전에 이 전투 의미를 코드 전체에서 완전히 통일해야 하므로 8단계보다 7.5를 우선한다.

## 7.5-A 상시 쇼다운 우세 제거 + 희귀 우세 상태 전환 — 완료

기본 무늬 수 비교 기반 상시 쇼다운 우세를 제거하고, 우세를 명시적 조건으로만 얻는 희귀 폭딜 상태로 전환했다.

고정 기준:

- 자동 무늬 비교로 우세 생성 금지
- 기본 우세 +3 제거
- 명시적으로 얻은 우세만 해당 쇼다운 최종 위력 ×1.25
- 쇼다운 종료 후 제거
- 트럼프와 우세는 별개 개념

## 7.5-B 칩 기본 루프 — 기반 완료 / 7.5-H에서 세부 재검증

고정 기준:

- 트릭 승리 시 칩 +1
- 기본 최대 칩 5
- 같은 전투에서는 세트 사이 유지
- 전투 종료 시 초기화
- 런 화폐와 별개

최신 손패 교환의 정확한 의미는 7.5-H에서 다시 고정한다.

## 7.5-C 쇼다운 계산 구조 — 완료

고정 순서:

1. 쇼다운 5장 확정
2. 쇼다운 전 효과
3. 슬롯 / 숫자 / 무늬 변경
4. 포커 족보 판정 및 기본 위력
5. 카드/상태/계약 등의 덧셈 보너스
6. 리버 완성 / 우세 / 전승 / 계약 등의 희귀 배율
7. 최종 위력
8. 피해
9. 압승/대압승 판정
10. 세트 종료
11. 적 생존 시 다음 세트

테스트용 족보 위력:

- 하이카드 5
- 페어 10
- 투페어 14
- 트리플 18
- 스트레이트 24
- 플러시 26
- 풀하우스 32
- 포카드 42
- 스트레이트 플러시 60

## 7.5-D 리버 완성 / 고점 배율 — 완료

고정 기준:

- 4장 시점에 없던 족보가 5번째 카드로 처음 완성되면 리버 완성
- 리버 완성 ×1.25
- 명시적 우세 ×1.25
- 5전 전승 ×1.5
- 대부분의 일반 효과는 덧셈 유지

## 7.5-E 일반전 / 장기전 템포 — 완료

현재 목표:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

현재 테스트용 HP 곡선:

- 초반 일반전 24
- 강한 일반전 36
- 엘리트 64
- 보스 120

피해 체감 목표:

- 평범한 쇼다운 10~30
- 잘 풀린 쇼다운 30~50
- 강한 시너지 50~80
- 고점 100+

## 7.5-F 필드 역할 재정리 — 완료

고정 기준:

- 필드 없음이 정상 전투 상태
- 일반/엘리트/보스 모두 자동 기본 필드 없음
- 카드/엘리트/보스/이벤트 등 명시적 출처가 있을 때만 필드 생성
- 필드와 적 고유 규칙/보스 페이즈는 별도
- 기존 상시 런 필드는 다음 전투 1회 예약 구조로 전환

# 신규 우선 이정표 — 트럼프 +3 개편

## 7.5-G 트럼프 +3 전면 개편 — 다음 작업

가장 높은 우선순위다.

폐기 규칙:

> 한쪽만 트럼프면 숫자와 상관없이 트럼프가 승리한다.

최신 확정 규칙:

> 현재 트럼프 무늬 카드의 트릭 적용 숫자 +3.

모든 트릭 승패는 최종 적용 숫자만 비교한다.

### 구현 순서

1. 기본 숫자 확인
2. 카드 효과에 따른 적용 숫자 변화
3. 현재 트럼프 무늬라면 +3
4. 상태/필드 등의 추가 보정
5. 최종 적용 숫자 비교
6. 높은 쪽 승리
7. 같으면 무승부

### 해야 할 일

- `battle-core.js` 등 핵심 트릭 비교에서 트럼프 우선 분기 제거
- 현재 트럼프 여부를 `적용 숫자 보정`으로 계산하도록 변경
- 플레이어/적 모두 같은 +3 규칙 사용
- 트럼프 + 카드 숫자 효과 + 상태 보정이 하나의 계산선에서 합산되도록 통일
- 트럼프 보정은 트릭에만 적용하고 쇼다운 원래 값에는 침범하지 않게 고정
- 적 AI가 `트럼프면 무조건 승리`를 가정하는 평가식을 제거
- 인텐트/예측/UI가 최종 적용 숫자를 올바르게 보여주도록 변경
- 기존 `lowRankWinsWhenSameTrumpState` 등 트럼프 상태 분기 기반 레거시를 재검토
- 문서/용어/UI에서 `트럼프 우선` 표현 삭제

### 필수 회귀 예시

현재 트럼프 ♠:

- ♠3 → 6, ♥K → 13 → ♥K 승리
- ♠10 → 13, ♥Q → 12 → ♠10 승리
- ♠J + 카드 효과 +3 → 17
- 비트럼프 Q + 효과 +3 → 15
- 양쪽 최종 적용 숫자가 같으면 무승부

### 완료 조건

- 코드 어디에도 `한쪽만 트럼프면 자동 승리`가 실제 전투 규칙으로 남지 않음
- 트럼프 +3이 플레이어와 적에게 대칭적으로 적용됨
- 쇼다운 족보는 기본적으로 인쇄값을 유지함
- 카드 숫자 강화가 트럼프와 정상 경쟁함

## 7.5-H 칩 손패 교환 세부 정합성

7.5-B에서 만든 기본 칩 루프를 신규 기준에 정확히 맞춘다.

최신 공용 행동:

- 칩 2 소비
- 손패 카드 1장을 **덱 맨 아래**로 보냄
- 그 후 카드 1장 드로우
- 트릭 미소비
- 트릭당 최대 1회

해야 할 일:

- 현재 구현이 카드를 버림 더미로 보내는지 확인하고, 그렇다면 덱 맨 아래 이동으로 변경
- 덱이 비었을 때 재순환과 `맨 아래` 의미가 깨지지 않게 처리
- 한 트릭에서 2회 이상 교환 불가
- 세트가 넘어가면 교환 횟수 제한은 새 트릭 기준으로 정상 초기화
- 적/카드 효과가 최대 칩을 바꿔도 기본 사용처가 깨지지 않게 유지

완료 조건:

`트릭 승리 → 칩 획득 → 손패 조절 → 쇼다운 족보 개선` 순환이 문서와 코드에서 동일해야 한다.

## 7.5-I 트럼프 연동 필드 리워크

7.5-F에서 필드의 존재 방식은 정리했지만, 필드 내용은 구식 우세/트럼프 규칙을 참조하는 것이 남아 있다.

새 필드 설계 기준:

- 무법지대: 이번 세트 트럼프 보너스 0
- 과충전 구역: 트럼프 보너스 +5
- 감쇠 지대: 트럼프 보너스 +1
- 뒤집힌 세계: 낮은 최종 적용 숫자가 승리
- 좁은 테이블: 최대 손패 -1

해야 할 일:

- `공명 바닥`, `희박 신호` 등 구식 자동 우세 기반 필드 제거/리워크
- 필드가 트럼프 보너스 수치를 명시적으로 덮어쓸 수 있는 공통 규칙 추가
- 기본 트럼프 보너스 +3을 하나의 중앙 값으로 관리
- 필드 없음에서는 항상 +3
- 필드 종료/교체 시 기본값으로 정상 복원

## 7.5-J 카드 / 계약 / 시너지 / 명칭 레거시 정리

규칙 변경으로 의미가 어긋난 콘텐츠를 정리한다.

우선 대상:

- `우세 무늬 수`를 참조하는 카드
- 상시 우세 +3을 전제로 한 계약/유물/시너지
- `트럼프면 자동 승리`를 전제로 한 카드 효과
- 기존 트럼프 우선 분기를 전제로 한 적 행동
- 전술 카드 드로우/전술 손패 같은 구버전 표현
- 순수 카드와 네임드 카드 구분이 흐려진 부분

순수 카드 원칙:

- 효과가 없는 일반 트럼프 카드는 계속 유지
- 특정 순수 카드 시너지의 대상이 될 수 있음
- 네임드 카드만 많은 덱이 항상 최적이 되지 않게 설계

표시 이름 후보:

- 검은 탄환 → 철갑탄
- 비열한 승부사 → 야바위꾼
- 날 선 유리 → 유리파편
- 매복한 관측자 → 감시자
- 응급 보호구 → 비상방패

ID는 함부로 바꾸지 않고 표시 이름 중심으로 진행한다.

## 7.5-K 압승 / 쇼다운 폭딜 연출

압승 판정 후보:

- 적 남은 체력의 150% 이상 피해 → 압승
- 200% 이상 → 대압승

보상은 소규모로 제한하고 주목적은 성취감 강화로 둔다.

연출 순서:

1. 쇼다운 카드 5장 확정
2. 족보 이름 표시
3. 리버 완성 표시
4. 덧셈 보너스 표시
5. 우세/계약/전승 배율 표시
6. 최종 피해 강조
7. 적 체력 감소
8. 피해 단계별 흔들림/타격음
9. 압승/대압승 마무리

## 7.5-L 최신 규칙 최종 회귀 테스트

저장 시스템으로 넘어가기 전 다음을 자동 테스트로 고정한다.

### 카드/손패

- 기본 손패 3장
- 모든 플레이 카드가 ♠/♥/♦/♣ + 2~A 규격
- 순수 카드가 실제로 존재
- 별도 전술 카드 시스템 없음

### 세트/트럼프

- 5트릭 = 1세트
- 세트마다 새 트럼프 공개
- **트럼프는 자동 승리권이 아님**
- **현재 트럼프 카드의 트릭 적용 숫자 +3**
- 플레이어와 적의 트럼프 보정이 대칭
- 트릭 승패는 최종 적용 숫자만 비교
- 동률이면 무승부
- 쇼다운에서는 기본적으로 인쇄값 사용

### 칩

- 트릭 승리 시 칩 +1
- 기본 최대 5
- 칩 2 손패 교환
- 교환한 카드는 덱 맨 아래
- 트릭당 최대 1회
- 세트 사이 칩 유지
- 전투 종료 시 초기화

### 쇼다운

- 포커 족보 중심
- 상시 쇼다운 우세 없음
- 자동 무늬 비교 우세 없음
- 명시적 우세만 ×1.25
- 쇼다운 종료 후 우세 제거
- 리버 완성은 5번째 카드로 새 족보가 생길 때만
- 덧셈 뒤 희귀 배율
- 전승 등 고점은 명시적 조건에서만
- 압승/대압승은 실제 최종 피해와 남은 HP로 판정

### 필드/장기전

- 필드 없음이 정상 상태
- 필드는 특정 출처에서만 생성
- 필드가 트럼프 보너스를 0/+1/+5 등으로 조정 가능
- 적 생존 시 다음 세트 진행
- 일반전은 대부분 짧고 엘리트/보스는 장기전 가능
