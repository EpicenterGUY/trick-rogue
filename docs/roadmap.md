# 7.5 최신 통합 규칙 재정렬

## 목적

7단계까지 만든 기반 위에서 저장 시스템으로 넘어가기 전에, 2026-08-23 최신 통합 규칙과 충돌하는 기존 핵심 전투 규칙을 먼저 정리한다.

저장/직렬화를 먼저 구현하면 폐기할 규칙까지 저장 포맷에 굳어질 수 있으므로 **8단계보다 7.5를 우선**한다.

## 7.5-A 상시 쇼다운 우세 제거

기본 전투 규칙에서 기존 무늬 수 비교 기반 상시 쇼다운 우세를 제거한다.

해야 할 일:

- 기본 쇼다운에서 무늬 수 비교로 우세를 자동 계산하지 않음
- 기본 우세 +3 같은 상시 위력 보너스 제거
- `on_showdown_advantage` 등 기존 우세 전용 경로를 기본 쇼다운 필수 단계에서 분리
- 우세가 필요한 카드/유물/보스/필드는 별도 상태 또는 명시적 효과로만 우세를 만들도록 변경
- 기존 우세 기반 계약/시너지/필드 효과는 최신 규칙에 맞춰 리워크 또는 비활성화
- 트럼프와 우세를 완전히 별개 개념으로 유지

완료 조건:

- 우세 빌드를 전혀 사용하지 않는 런은 우세 시스템을 의식하지 않아도 됨
- 포커 족보가 쇼다운의 기본 중심축이 됨

## 7.5-B 칩 기본 루프 확정

기본 전투 루프에 칩의 공용 역할을 명확하게 넣는다.

기준:

- 트릭 승리 시 칩 +1
- 기본 최대 칩 5
- 칩은 같은 전투에서 세트가 넘어가도 유지
- 전투 종료 시 초기화
- 런 화폐와 별개

공용 행동 `손패 교환`:

- 칩 2 소비
- 손패 카드 1장을 덱 맨 아래로 보냄
- 카드 1장 드로우
- 트릭 미소비
- 트릭당 최대 1회

완료 조건:

`트릭 승리 → 칩 획득 → 손패 조정 → 더 나은 쇼다운 준비` 순환이 기본 규칙만으로 성립해야 한다.

## 7.5-C 쇼다운 처리 순서 재정렬

최신 기본 순서:

1. 쇼다운 5장 확정
2. 쇼다운 전 카드 효과
3. 슬롯 / 숫자 / 무늬 변경
4. 포커 족보 판정
5. 정산 효과 처리
6. 최종 위력 계산
7. 피해
8. 세트 종료 효과
9. 적 생존 시 다음 세트

기존 구현에서 우세 판정이 족보와 쇼다운 효과 사이에 강제되어 있다면 제거/재배치한다.

완료 조건:

- 포커 족보 판정 전 쇼다운 전용 조작이 가능
- 족보 판정 이후 정산 효과가 가능
- 상시 우세 단계가 없어도 전체 쇼다운이 정상 작동

## 7.5-D 일반전/장기전 템포 정리

최신 전투 길이 목표:

- 초반 일반 적: 대부분 1세트
- 강한 일반 적: 1~2세트
- 엘리트: 2~3세트
- 보스: 3세트 이상 가능

해야 할 일:

- 일반 적 체력을 첫 쇼다운 처치가 가능한 수준으로 재조정
- 일반 적 난이도는 체력보다 간단한 기믹으로 차별화
- 엘리트/보스만 여러 세트가 특별하게 느껴지도록 조정
- `5트릭 = 전투 종료` 같은 잔여 가정을 모두 제거
- 적 생존 시 다음 세트로 자연스럽게 넘어가는 흐름 검증

완료 조건:

- 일반전이 불필요하게 2~3세트로 늘어지지 않음
- 엘리트/보스에서는 장기전 빌드가 실제로 작동할 시간 확보

## 7.5-E 필드 역할 재정리

최신 기준에서는 필드가 기본적으로 항상 존재하지 않는다.

해야 할 일:

- 모든 조우가 자동으로 필드를 가진다는 가정 제거
- 필드는 카드/보스/엘리트/이벤트 등 특정 출처가 만들 때만 존재
- 기존 런 보유 필드 구조는 최신 기준에 맞춰 `특수 룰 생성/활성` 개념으로 재검토
- 필드가 없을 때는 완전한 기본 전투 규칙이 작동해야 함

완료 조건:

- 필드 없음이 정상 상태
- 필드가 등장하면 룰이 바뀌는 특별한 상황으로 느껴짐

## 7.5-F 카드/콘텐츠 명칭 및 잔여 레거시 정리

규칙 변경으로 의미가 어긋난 기존 콘텐츠를 정리한다.

우선 검토 대상:

- 상시 우세를 전제로 한 카드/계약/시너지
- 전술 카드 드로우/전술 손패 같은 구버전 표현
- 카드명 후보
  - 검은 탄환 → 철갑탄
  - 비열한 승부사 → 야바위꾼
  - 날 선 유리 → 유리파편
  - 매복한 관측자 → 감시자
  - 응급 보호구 → 비상방패

이름 변경은 ID를 함부로 바꾸지 않고 표시 이름 중심으로 진행한다.

## 7.5-G 규칙 회귀 테스트

다음 항목을 자동 테스트로 고정한다.

- 기본 손패 3장
- 모든 플레이 카드가 ♠/♥/♦/♣ + 2~A 규격
- 5트릭 = 1세트
- 세트마다 새 트럼프 공개
- 트럼프는 트릭 판정에만 기본 영향
- 트릭 승리 시 칩 +1
- 칩 2 손패 교환
- 전투 중 세트 사이 칩 유지 / 전투 종료 초기화
- 쇼다운 족보는 기본적으로 원래 값 사용
- 상시 쇼다운 우세 없음
- 우세는 명시적 효과가 만들 때만 존재
- 별도 전술 카드 시스템 없음
- 필드 없음이 정상 전투 상태
- 적 생존 시 다음 세트 가능
