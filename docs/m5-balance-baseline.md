# M5 밸런스 기준선 기록

기준일: 2026-08-27

이 문서는 지역 확장 전에 현재 3지역 런의 기준선을 기록하기 위한 플레이테스트 시트다. 자동 계측은 판단을 대신하지 않고, 실제 플레이 체감 판정에 필요한 수치를 빠뜨리지 않기 위한 보조 장치로 사용한다.

## 자동 기록되는 항목

런을 새로 시작하면 `run.balanceTelemetry`가 생성된다. 저장/불러오기 시 일반 런 상태와 함께 보존된다.

- 실제 진입 노드 수: 일반 전투 / 이벤트 / 캠프 / 상점 / 엘리트 / 보스
- 완료 전투 수와 전투 유형별 횟수
- 실제 전투 시간 합계와 런 종료 시 평균 전투 시간
- 트릭 수와 승리 / 패배 / 동점 수
- 쇼다운 횟수, 쇼다운 최종 위력 차이 평균 / 최대
- 사용한 순수 카드 / 효과 카드 횟수
- 손패 교환 횟수와 교환에 쓴 칩
- 한 전투에서 관측된 최대 칩 잔액
- 기존 `foldStats`와 연결한 폴드 횟수 / 잃은 HP
- 방문 / 완료 지역 수와 선택한 지역 분기 수

런 종료 결과에는 `run.runResult.balance`로 같은 요약이 남고, 결과창에도 M5 요약 행이 표시된다.

## 자동 수치로 완료 처리하면 안 되는 항목

아래는 반드시 실제 플레이 후 사람이 판정한다.

- 쇼다운 차이 피해가 너무 폭발적이거나 무의미하지 않은가
- 순수 카드와 효과 카드 중 한쪽이 항상 정답처럼 느껴지지 않는가
- 칩 5 / 교환 비용 2가 실제 선택을 만들고 있는가
- 폴드 HP 8이 너무 싸거나 사실상 쓰지 못할 만큼 비싼가
- 첫 번째와 두 번째 지역 선택이 플레이 경험을 실제로 바꾸는가
- 스타터 / 특성 / 필드 / 네임드가 하나의 빌드 방향으로 읽히는가
- 반복해서 고르는 카드, 이벤트, 보상 또는 피하는 선택이 있는가

## M5 판정 규칙

1. 한 번의 런에서 나온 극단값만 보고 즉시 수치를 패치하지 않는다.
2. 동일 문제가 여러 스타터 / 지역에서 반복되는지 먼저 본다.
3. 자동 수치와 체감이 충돌하면 원시 플레이 기록을 다시 확인한다.
4. M4 12장 중 특정 카드가 반복해서 무조건 선택되거나 사실상 선택되지 않을 때 최종 카드 판정에 반영한다.
5. M5의 세 완료 조건은 실제 정상 런 표본과 체감 기록이 채워진 뒤에만 완료 처리한다.
