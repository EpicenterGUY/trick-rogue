# 8-C 보상 / 캠프 / 상점 세로 슬라이스 — 완료

> 기준: 2026-08-23 최신 런 구조

8-B에서 만든 공통지역/지역 선택 흐름에 실제 덱빌딩 경제 루프를 연결한다.

## 전투 보상

- 전투 종료 골드는 기존 전투 등급 값을 유지한다.
  - 일반전: 20G
  - 엘리트: 40G
  - 보스: 70G
- 카드 보상은 3장을 제시한다.
- 플레이어는 1장 선택 또는 건너뛰기가 가능하다.
- 카드 보상 건너뛰기는 추가 골드나 다른 자원으로 변환되지 않는다.
- 같은 노드의 카드 보상 후보는 런 시드 기준으로 고정된다.
- 보상 후보에는 네임드/일반 효과 카드뿐 아니라 순수 카드도 포함된다.

## 지역 카드 경향

8-B에서 저장한 지역 보상 가중치를 실제 후보 생성에 사용한다.

- 공용/무소속: 65%
- 지역 테마: 35%

이 값은 등장 경향일 뿐 클래스 제한이 아니다. 방문 지역이나 시작 카드군과 무관하게 다른 카드군/무소속/순수 카드를 계속 얻을 수 있다.

현재 세로 슬라이스용 지역 테마 후보는 기존 구현 카드만 재사용한다. 신규 카드 목록이나 신규 개별 카드 효과는 8-C 범위에서 추가하지 않는다.

## 엘리트 / 보스 보상 순서

엘리트와 보스는 기존 유물 보상을 유지한다.

`유물 선택 → 카드 3장 보상 → 노드 완료`

일반전은 바로 카드 3장 보상으로 이어진다.

## 캠프

한 번의 캠프에서 다음 중 하나를 선택한다.

### 휴식

- 최대 체력의 30% 회복
- 최대 체력을 넘지 않는다.

### 카드 강화

- 카드 1장을 1단계 강화한다.
- 현재 프로토타입 강화 효과: 해당 카드의 트릭 적용 숫자 +1
- 인쇄 숫자/무늬는 바꾸지 않는다.
- 쇼다운 원래값도 바꾸지 않는다.
- 고유 효과가 없는 카드의 순수 카드 판정도 그대로 유지한다.
- 같은 카드는 현재 1단계까지만 강화 가능하다.

강화 수치는 첫 완성 버전 플레이테스트용 값이며 추후 조정할 수 있다.

## 상점

현재 프로토타입 가격:

- 카드: 45G
- 유물: 80G
- 카드 제거: 45G

규칙:

- 카드 진열 3장은 같은 상점 노드에서 고정된다.
- 보유하지 않은 유물 중 하나를 판매한다.
- 구매 완료한 같은 항목은 다시 살 수 없다.
- 카드 제거는 상점당 1회다.
- 카드 제거 후 덱은 최소 5장을 유지해야 한다.
- 상점에서 나가기 전에는 서로 다른 카드/유물 등 여러 구매를 할 수 있다.

## 런 상태

8-C 관련 상태는 `run.economyState`에 저장한다.

- 노드별 카드 보상 후보
- 카드 보상 선택/건너뛰기 여부
- 상점별 진열과 구매 상태
- 카드 제거 사용 여부
- 경제 행동 이력

8-F 저장/불러오기 단계에서 이 상태도 직렬화 대상에 포함한다.

## 회귀 기준

8-C 완료 시 다음을 자동 검증한다.

- 지역 65/35가 실제 카드 후보 선택에 사용됨
- 다른 카드군/무소속 획득을 막지 않음
- 카드 보상은 3장, 중복 후보 없음
- 선택은 한 번만 가능하며 건너뛰기는 추가 골드 없음
- 1단계 강화가 트릭 적용값만 +1 하고 쇼다운/인쇄값을 보존
- 캠프 30% 회복 상한
- 상점 카드/유물 구매 비용과 중복 구매 차단
- 카드 제거 비용/1회/최소 5장 제한
- 엘리트/보스의 유물 → 카드 보상 순서
- 브라우저 로더가 `8-B 런 흐름 → 8-C 경제 → 전투 레이아웃` 순서를 유지
