# 8-D 쇼다운 슬롯 조작 기반 — 완료

기준: 2026-08-23

## 목표

쇼다운에 이미 놓인 카드를 수정하는 기능을 기본 공용 행동이 아니라 **카드/유물/적 등 명시적 효과가 호출하는 공통 API**로 제공한다.

슬롯 조작의 기본 강도는 다음 순서를 따른다.

`이동 < 철회 < 교체 < 폐기·대체`

## 공통 API

`showdown-slot-manipulation.js`가 다음 조작을 제공한다.

- `moveShowdownSlots`: 두 쇼다운 슬롯의 카드와 슬롯 결과 메타데이터를 함께 교환한다.
- `withdrawShowdownCard`: 쇼다운 카드를 손으로 되돌리고 같은 슬롯을 지정 대체 카드로 채운다.
- `exchangeShowdownCard`: 쇼다운 카드와 지정 손패 카드를 원자적으로 맞바꾼다.
- `discardReplaceShowdownCard`: 쇼다운 카드를 버림 더미로 보내고 같은 슬롯을 지정 대체 카드로 채운다.
- `applyShackle`: 특정 쇼다운 카드에 조작 제한을 부여한다.

모든 조작은 슬롯 수를 임의로 깨뜨리지 않으며 잘못된 대상이나 대체 카드에서는 영역을 변경하기 전에 실패한다.

## 족쇄

기본 `족쇄`는 슬롯 번호가 아니라 **카드 UID**를 추적한다. 따라서 허용된 다른 효과로 카드 위치가 바뀌어도 제한은 같은 카드를 따라간다.

기본 차단 대상:

- 이동
- 철회
- 교체

`폐기·대체`는 더 강한 조작이므로 기본 족쇄의 차단 목록에는 포함하지 않는다. 특정 효과가 이를 막아야 할 경우 `blockedOperations`에 `discard_replace`를 명시할 수 있다.

족쇄는 기본적으로 현재 세트 범위다. 새 세트가 시작되면 잠금 목록은 정리되며 전투 중 조작 이력은 유지한다.

## 공통 효과 엔진 연결

다음 액션을 `CardEffects`에 런타임 등록한다.

- `move_showdown_slots`
- `withdraw_showdown_card`
- `exchange_showdown_card`
- `discard_replace_showdown_card`
- `shackle_showdown_card`

이 기반은 향후 실제 카드 효과가 슬롯 번호, 자기 슬롯(`self`), 마지막 슬롯(`last`), 손패 대상을 지정해 같은 API를 재사용하도록 만든다.

## 리버 / 세트 경계

4번째 트릭에서 이미 확정된 `riverSnapshot`은 이후 슬롯 조작 때문에 다시 계산하지 않는다. 즉 슬롯 조작으로 최종 족보가 바뀌더라도 7.5-M의 리버 적중 규칙을 소급 변경하지 않는다.

새 세트에서는 족쇄만 정리하고 기존 7.5-J의 손패·드로우 덱·버림 더미 경계를 별도로 건드리지 않는다.

## UI 원칙

8-D는 `이동`, `철회`, `교체`, `폐기` 버튼을 기본 전투 UI에 추가하지 않는다.

슬롯 조작은 반드시 카드/유물/적/필드 등 명시적 효과를 통해서만 발생한다. 따라서 처음 5트릭 동안 내린 선택을 언제든 무료로 되돌리는 공용 행동이 생기지 않는다.

## 로더

`8-B 런 흐름 → 8-C 경제 → 8-D 쇼다운 슬롯 조작 → 최종 전투 레이아웃`
