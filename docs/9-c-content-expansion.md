# 9-C 유물 / 계약 / 상태 / 필드 콘텐츠 확장

## 목표

기존 전투 엔진을 새로 만들지 않고, 이미 검증된 공통 효과·계약·상태·필드 경로에 실제 선택지를 추가한다.

## 신규 유물 4종

- **원본 도장**: 인쇄값과 최종 트릭값이 같은 카드로 트릭 승리 시 칩 +1.
- **순수 왕관**: 쇼다운 슬롯에 순수 카드가 있으면 쇼다운 위력 +4.
- **잿빛 바늘**: 세트 시작 시 적에게 흉터 1.
- **추적 표찰**: 세트 시작 시 적에게 표식 2.

유물은 기존 엘리트/보스 유물 보상 풀에 자동 포함되며 런 지속 효과 소유자 경로를 그대로 사용한다.

## 신규 계약 / 금기 묶음 3종

### 강 건너기
- 리버 계약: 4트릭 스냅샷 후보를 실제 5번째 카드로 적중하면 쇼다운 위력 +8.
- 헛물 금기: 리버 후보가 있었지만 적중하지 못하면 쇼다운 위력 -3.

### 압도적 패
- 압도 계약: 세트 트릭 4승 이상이면 쇼다운 위력 +8.
- 역풍 금기: 세트 트릭 2패 이상이면 쇼다운 위력 -3.

### 동점 장부
- 동점 계약: 세트에 무승부가 하나 이상 있으면 쇼다운 위력 +5.
- 단조 금기: 세트에 무승부가 없으면 쇼다운 위력 -2.

리버 계약은 쇼다운 뒤 족보 변화를 추론하지 않고 7.5-M에서 이미 고정된 `riverSnapshot` / `riverHit`만 사용한다.

## 신규 상태 2종

- **흉터**: 최대 2. 트릭 종료 시 현재 수치만큼 피해. 자연 감소하지 않으며 전투 종료 시 사라진다.
- **표식**: 최대 5. 다음 양수 피해를 받을 때 보호막 계산 전에 현재 수치만큼 피해 증가 후 전부 소멸. 해제 가능.

둘 다 기존 `apply_status`, 상태 트리거, 상태 HUD 경로를 그대로 사용한다. 중독은 여전히 규칙 미확정 상태로 유지한다.

## 신규 필드 2종

- **과열 테이블**: 기본 최대 손패 -1, 트럼프 적용 숫자 보너스 +4.
- **넓은 테이블**: 기본 최대 손패 +1, 트럼프 적용 숫자 보너스 +2.

둘 다 트럼프 자동 승리권을 만들지 않으며 최종 적용 숫자 파이프라인만 바꾼다. 이벤트의 `필드 설계`에서 획득하면 보유 목록에 들어가고 다음 전투 한 번에 예약된다. 필드 없음이 기본이라는 원칙은 그대로 유지한다.

## 금지 규칙 유지

- 별도 전술 덱 / 전술 손패 없음.
- 트럼프 자동 승리 없음.
- 상시 무늬 우세 없음.
- 특수 인쇄 숫자·무늬 없음.
- 리버 사후 재계산 없음.
- 필드 자동 생성 없음.
